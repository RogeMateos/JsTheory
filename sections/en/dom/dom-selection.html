DOM Fundamentals in JavaScript

Element selection and essential methods

1️⃣ What is the DOM and why is it important?

Before touching code, we need a clear idea.

The DOM (Document Object Model) is an in-memory representation of HTML that the browser creates when loading a web page.

JavaScript doesn't interact directly with HTML, but with this intermediate model: the DOM.

Think of the DOM as a tree of nodes, where each HTML tag is an object that JavaScript can read and modify.

👉 Key conclusion:

If JavaScript wants to change text, a button, or a style, it first has to access that DOM node.

2️⃣ The document object: the gateway to the DOM

In the browser, JavaScript gives us access to the DOM through a global object called:

document
  • document represents the entire HTML page
  • From it we can:
    • Search for elements
    • Create new nodes
    • Modify content and attributes

⚠️ Important:

  • ✅ document only exists in the browser
  • ❌ It doesn't exist in Node.js, because there's no HTML or DOM

That's why, if you run JavaScript outside the browser and do:

console.log(document);

You'll get an error: document is not defined.

3️⃣ First real problem: selecting DOM elements

Before modifying anything, we always have to solve the same problem:

How do I access a specific HTML element from JavaScript?

That's what DOM selection methods are for.

4️⃣ Basic (classic) selection methods

🔹 getElementById

document.getElementById("my-id");

What it does:

  • Returns a single element
  • Searches by the id attribute

Why it returns only one:

  • An id must be unique within the HTML

What it returns:

  • An HTMLElement
  • Or null if it doesn't exist

When to use it:

  • Key elements: main buttons, root containers, forms
const button = document.getElementById("myButton");
console.log(button); // <button id="myButton">...</button>

🔹 getElementsByClassName

document.getElementsByClassName("my-class");

What it does:

  • Returns multiple elements
  • All that share that class

What it returns:

  • An HTMLCollection
  • It's not a real array
  • It updates automatically if the DOM changes
const elements = document.getElementsByClassName("card");
console.log(elements.length); // 3

// To iterate, you need to convert it to an array
Array.from(elements).forEach(el => {
  console.log(el);
});

👉 This reflects a good design practice:

  • IDs → unique elements
  • Classes → groups of elements

🔹 getElementsByTagName

document.getElementsByTagName("p");

What it does:

  • Selects elements by tag (div, p, li, etc.)
  • Returns a collection

Current usage:

  • Less and less common
  • Useful only in very generic cases
const paragraphs = document.getElementsByTagName("p");
console.log(paragraphs); // HTMLCollection of all <p>

5️⃣ Limitations of classic methods

The previous methods work, but have problems:

  • ❌ They're not very flexible
  • ❌ They don't use CSS selectors
  • ❌ They return collections that don't behave like arrays

That's why, with JavaScript's evolution, more modern methods appeared.

6️⃣ Modern methods: querySelector

🔹 querySelector

document.querySelector(".my-class");

Key idea:

querySelector uses CSS selectors.

You can use:

  • .class
  • #id
  • div p
  • ul > li
  • [data-id="123"]

What it returns:

  • The first element that matches
  • An Element or null
// By class
const card = document.querySelector(".card");

// By ID
const header = document.querySelector("#header");

// Complex selector
const firstLink = document.querySelector("nav ul li a");

console.log(firstLink); // First link inside nav > ul > li

👉 It's more flexible than getElementById and is used a lot nowadays.

🔹 querySelectorAll

document.querySelectorAll(".my-class");

What it does:

  • Returns all elements that match the selector

What it returns:

  • A NodeList
  • Can be iterated with forEach
const buttons = document.querySelectorAll(".btn");

buttons.forEach(button => {
  console.log(button.textContent);
});

This fits perfectly with modern JavaScript.

7️⃣ Important difference: Element vs Collection

When working with the DOM we can receive:

  • An element → we can modify it directly
  • A collection → we have to iterate through it

Quick mental summary:

Method What it returns
getElementById Element
getElementsByClassName HTMLCollection
getElementsByTagName HTMLCollection
querySelector Element
querySelectorAll NodeList

8️⃣ Current best practices

✅ In modern code:

  • Prioritize querySelector and querySelectorAll
  • Use clear CSS selectors
  • Reserve getElementById for very specific cases

❌ Avoid:

  • Mixing many different methods without criteria
  • Assuming collections are arrays
// ✅ Recommended
const header = document.querySelector("#header");
const cards = document.querySelectorAll(".card");

cards.forEach(card => {
  card.classList.add("active");
});

// ❌ Less recommended (less flexible)
const header = document.getElementById("header");
const cards = document.getElementsByClassName("card");

// You need to convert HTMLCollection to array
Array.from(cards).forEach(card => {
  card.classList.add("active");
});

9️⃣ Final idea to close the topic

Mastering element selection is mastering the foundation of web interaction.

If you know how to access DOM nodes, you already have 50% of the work done.

✅ Summary

  • document is the gateway to the DOM
  • Classic methods: getElementById, getElementsByClassName, getElementsByTagName
  • Modern methods: querySelector, querySelectorAll
  • querySelector uses CSS selectors (more flexible)
  • querySelectorAll returns a NodeList (can be iterated with forEach)
  • HTMLCollection ≠ Array (you need to convert it)
  • Prioritize modern methods in new code
