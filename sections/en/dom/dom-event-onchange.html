Handling the change Event in JavaScript

Listening for changes in form elements with addEventListener

🔄 What is the change event?

Context

In the previous lesson, we saw how to listen for the click event to detect when a user clicks a button. Now we're going to listen for the change event to see when the user changes the value of a <select>.

💡 When does it fire?

The change event fires when the user changes the selected value of a form element like a <select>, <input>, or <textarea>.

📝 The base HTML

Form with select

With HTML like this:

<form class="search-filters">
  <label for="filter-location">Location</label>
  <select id="filter-location">
    <option value="">All</option>
    <option value="remote">Remote</option>
    <option value="cdmx">Mexico City</option>
    <option value="guadalajara">Guadalajara</option>
  </select>
</form>

🎯 Listening for the change event

✅ Using addEventListener

We can listen for the change event to see when the user changes the select value:

const filterLocation = document.getElementById('filter-location')

filterLocation.addEventListener('change', function () {
  console.log('Selected location:', filterLocation.value)
})

⚠️ value vs visible text

Keep in mind that the select's value is the value of the selected option… not the option's display name!

So if the user selects "Mexico City", the value of filterLocation.value will be "cdmx".

Don't confuse the option's value with the text the user sees.

🔍 Understanding the difference

<option value="cdmx">Mexico City</option>
<!--          ^^^^    ^^^^^^^^^^^
         value (JS)    visible text (user) -->
filterLocation.value        // "cdmx" ← this is what you get with .value
filterLocation.selectedOptions[0].text  // "Mexico City" ← the visible text

♿ Accessibility note

🏷️ The label is mandatory

As you can see in the example, the <select> has an associated <label> through the for attribute pointing to the select's id.

This is essential for accessibility, as it allows screen readers to correctly identify the field's purpose.

<!-- ✅ Correct: label associated with the select -->
<label for="filter-location">Location</label>
<select id="filter-location">...</select>

<!-- ❌ Incorrect: select without label -->
<select id="filter-location">...</select>

In this course's examples we include labels when relevant to the context, but always make sure to use them in production.
