Introduction to the DOM (Document Object Model)

How JavaScript interacts with web pages

What is the DOM?

DOM stands for Document Object Model. It is the structured representation of a web page that allows JavaScript to interact with HTML content.

⚠️ Important note about this course

This is not a web development course as such. However, when we talk about JavaScript at an intermediate-advanced level, it's impossible to ignore one of its main missions since its creation: being a programming language for the web.

🌐 The three pillars of the web

A modern web page consists of three fundamental technologies:

1. HTML (Structure)

  • Defines the structure of the page
  • Creates elements: paragraphs, buttons, tables, forms, etc.
  • It's like the "skeleton" of the page
<p>Hello world</p>
<button>Click me</button>
<table>...</table>

2. CSS (Style)

  • Defines the visual appearance
  • Colors, sizes, positions, animations
  • It's like the "clothing" of the page
p {
  color: blue;
  font-size: 16px;
}

3. JavaScript (Interactivity)

  • Provides interactivity and behavior
  • Responds to user actions
  • Modifies content dynamically
  • It's like the "brain" of the page

🎯 JavaScript's original mission

30 years ago, when JavaScript was created, web pages were static. You could only read content, like a paper document.

The problem:

  • The web didn't do anything by itself
  • It didn't transform or modify
  • It didn't respond to user actions
  • It was simply "read mode"

The solution: JavaScript

JavaScript emerged to give web pages the ability to:

  • ✅ Respond to user actions (clicks, keys, scroll)
  • ✅ Modify content dynamically
  • ✅ Add or remove elements
  • ✅ Change styles and properties
  • ✅ Validate forms
  • ✅ Communicate with servers (APIs)

🔑 How does the DOM work?

The browser reads the HTML and creates a tree-like representation called the DOM. This representation is a JavaScript object that we can manipulate. 

<!-- Original HTML -->
<div id="app">
  <h1>Title</h1>
  <p>Paragraph text</p>
</div>

The browser converts it into a structure of objects accessible from JavaScript:

// JavaScript can access these elements
const app = document.getElementById('app');
const title = app.querySelector('h1');
const paragraph = app.querySelector('p');

// And modify them
title.textContent = 'New title';
paragraph.style.color = 'red';

📋 Classic examples of DOM manipulation

Example 1: Change paragraph text

<p id="myParagraph">Original text</p>
<button onclick="changeText()">Change text</button>
    
function changeText() {
  const paragraph = document.getElementById('myParagraph');
  paragraph.textContent = 'Text modified with JavaScript!';
}

Example 2: Respond to button click

<button id="myButton">Click me</button>
    
const button = document.getElementById('myButton');

button.addEventListener('click', () => {
  alert('Button clicked!');
});

Example 3: Add elements dynamically

const newElement = document.createElement('p');
newElement.textContent = 'Element created with JavaScript';

document.body.appendChild(newElement);

💡 JavaScript's native capability

Important: This ability to interact with the DOM is native to JavaScript.

  • ✅ You don't need additional libraries
  • ✅ You don't need frameworks
  • ✅ It's available directly in the browser
  • ✅ It's part of the web standard

Although nowadays there are frameworks like React, Vue, or Angular that make working with the DOM easier, understanding the native DOM is fundamental for any JavaScript developer.

🚀 JavaScript today

Today, JavaScript is such a widespread and powerful language that we can do practically anything with it:

  • Frontend (interactive web pages)
  • Backend (servers with Node.js)
  • Mobile applications (React Native)
  • Desktop applications (Electron)
  • IoT (Internet of Things)
  • Machine Learning (TensorFlow.js)

But one of its first and most important missions remains DOM manipulation to create interactive web experiences.

✅ Summary

  • DOM: structured representation of a web page
  • JavaScript: language that allows interaction with the DOM
  • HTML: page structure
  • CSS: visual styles
  • JS + DOM: interactivity and dynamic behavior
  • Native: you don't need libraries to manipulate the DOM
