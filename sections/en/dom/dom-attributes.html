DOM Attribute Manipulation (JavaScript)

Read, modify, check, and remove HTML attributes

Tutorial objective

Learn to read, modify, check, and remove HTML attributes from JavaScript using the DOM, understanding what really happens underneath and avoiding common mistakes.

1. What is an HTML attribute?

An attribute is additional information that lives inside an HTML tag.

Example:

<a href="/home" target="_blank">Home</a>

Here:

  • href → indicates the link URL
  • target → indicates how the link opens

From JavaScript we can read them, change them, check if they exist, or remove them.

2. Step 1: select the correct element

Before touching an attribute, you first need to select the element.

Select a single link

const link = document.querySelector('a');

⚠️ Important:

querySelector only returns the first element that matches.

Select all links

const links = document.querySelectorAll('a');

This returns a NodeList (a list of elements).

👉 Best practice: use specific selectors.

const link = document.querySelector('.nav-link');

3. Step 2: read an attribute (getAttribute)

To get the value of an HTML attribute, we use getAttribute.

const link = document.querySelector('.nav-link');
const hrefValue = link.getAttribute('href');

console.log(hrefValue);

🔹 This returns a string with the attribute value.

🔹 If the attribute doesn't exist → returns null.

⚠️ Watch out for the attribute name:

It's href, not hrf.

4. Step 3: modify or create an attribute (setAttribute)

With setAttribute we can create or overwrite an attribute.

link.setAttribute('href', 'https://example.com');

Mental rule:

  • If it exists → overwrites it
  • If it doesn't exist → creates it

Practical example:

link.setAttribute('target', '_blank');

5. Step 4: check if an attribute exists (hasAttribute)

Before touching an attribute, it's often useful to check if it exists.

const hasTarget = link.hasAttribute('target');
console.log(hasTarget); // true or false

Real example:

if (!link.hasAttribute('target')) {
  link.setAttribute('target', '_blank');
}

🔹 hasAttribute doesn't return the value, only a boolean.

6. Step 5: remove an attribute (removeAttribute)

If we want to return to default behavior:

link.removeAttribute('target');

This completely removes the attribute from HTML.

7. Attributes vs DOM Properties (VERY IMPORTANT)

This is where confusion often happens.

HTML Attribute

link.getAttribute('href');
  • Returns the value as it is in the HTML
  • Can be relative (/home)

DOM Property

link.href;
  • Returns the normalized, absolute URL
  • Reflects the real state of the element

Example:

<a href="/home"></a>
    
link.getAttribute('href'); // "/home"
link.href;                 // "https://yoursite.com/home"

👉 In practice:

  • Use attributes if you want to read the "original" HTML
  • Use properties if you want to work with the element's real state

8. Complete real example (very work-like)

Objective

All external links:

  • Open in a new tab
  • Are secure (rel="noopener noreferrer")
document.querySelectorAll('a').forEach(link => {
  const href = link.getAttribute('href');

  if (!href) return;
  if (href.startsWith('#')) return;
  if (href.startsWith('/')) return;

  link.setAttribute('target', '_blank');
  link.setAttribute('rel', 'noopener noreferrer');
});

💡 This pattern is used a lot in real projects.

9. Common mistakes to avoid

  • ❌ Assuming querySelector returns multiple elements
  • ❌ Not checking if the element exists (null)
  • ❌ Confusing href with hrf
  • ❌ Not understanding the difference between attribute and property

Safe example:

const link = document.querySelector('.nav-link');

if (link) {
  link.setAttribute('href', 'https://example.com');
}

13. Special case: boolean attributes

Some attributes are boolean (they exist or don't exist):

  • disabled
  • checked
  • selected
  • hidden
// Add boolean attribute
button.setAttribute('disabled', '');

// Better: use the property
button.disabled = true;

// Check
if (button.hasAttribute('disabled')) {
  console.log('Button is disabled');
}

// Remove
button.removeAttribute('disabled');
// or
button.disabled = false;

✅ Summary

  • getAttribute() reads attributes as they are in HTML
  • setAttribute() creates or modifies attributes
  • hasAttribute() checks existence (returns boolean)
  • removeAttribute() removes attributes
  • Attributes ≠ Properties: attributes are HTML, properties are DOM
  • Use properties for boolean attributes (disabled, checked)
  • Always verify the element exists before manipulating it
  • External links should have target="_blank" and rel="noopener noreferrer"
