Tutorial: Introduction to the DOM in JavaScript

Document Object Model - Fundamental concepts

1️⃣ Context: why are we talking about the DOM?

Before diving in, it's important to clarify something:

This is not a web development course, but it is an intermediate-level JavaScript course.

And here comes the key point:

👉 JavaScript was born for the web.

Although today we use it for many more things (APIs, servers, automation, etc.), one of its original missions was to interact with web pages.

We've already seen in the course:

  • ✅ How JavaScript communicates with servers (APIs)
  • ✅ How it handles data
  • ✅ How it works with asynchrony

The next natural step is to understand how JavaScript interacts with a web page, and that's where the DOM comes in.

2️⃣ What is the DOM (clear and direct explanation)

DOM stands for Document Object Model.

But more important than the name is the idea:

The DOM is an in-memory representation of the web page, created by the browser, that JavaScript can read and modify.

⚠️ Important point:

  • ❌ The DOM is not the HTML
  • ✅ The DOM is what the browser builds from the HTML

3️⃣ HTML, CSS, and JavaScript: clear roles

To understand the DOM, you first need to understand how a web page is divided:

🧱 HTML – Structure

Defines what exists on the page:

  • Texts
  • Buttons
  • Images
  • Forms
  • Tables

It's the skeleton of the web.

🎨 CSS – Styles

Defines how it looks:

  • Colors
  • Sizes
  • Positions
  • Animations

It's the appearance.

⚙️ JavaScript – Behavior

Defines what the page does:

  • Respond to clicks
  • Change text
  • Show or hide elements
  • React to events

And here's what's important:

JavaScript doesn't modify HTML directly.
JavaScript modifies the DOM.

4️⃣ The DOM as a tree (mental visualization)

The browser transforms HTML into a hierarchical structure, similar to a tree.

<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Title</h1>
    <p>Paragraph</p>
  </body>
</html>

It becomes:

document
  └── html
      ├── head
      │   └── title
      │       └── "My Page"
      └── body
          ├── h1
          │   └── "Title"
          └── p
              └── "Paragraph"

How to read this tree

  • document is the root node
  • Each HTML tag is a node
  • Elements are related to each other (parent, child, siblings)

📌 Useful analogy:

HTML is the blueprint of a house.
The DOM is the house already built, which you can interact with.

5️⃣ Why was the DOM so important?

Before the DOM

  • ❌ The web was static
  • ❌ To change something → reload the page
  • ❌ Very limited experience

With the DOM

  • ✅ Change content without reloading
  • ✅ Create dynamic interfaces
  • ✅ Respond to user actions

👉 The web stopped being just documents and became applications.

6️⃣ What JavaScript can do with the DOM

When working with the DOM, JavaScript usually does four main things:

1️⃣ Select elements

Search for specific elements within the document:

  • A paragraph
  • A button
  • An input
  • A list

2️⃣ Read or modify content

  • Change text
  • Change attributes
  • Update values

Conceptual example: Change the text of a paragraph when something happens.

3️⃣ Change styles or classes

  • Apply or remove CSS classes
  • Change colors, sizes, visibility

Example: Highlight an element when the user interacts with it.

4️⃣ Listen to events

  • Clicks
  • Keys
  • Mouse movement
  • Form submission

Example: Execute an action when the user clicks a button.

7️⃣ Practical example explained (no code yet)

Imagine a page with:

  • A paragraph
  • A button

We want:

When clicking the button, the paragraph text changes.

What really happens?

  1. The browser creates the DOM from the HTML
  2. JavaScript accesses the DOM
  3. JavaScript locates the paragraph
  4. JavaScript waits for an event (click)
  5. When the event occurs:
    • Modifies the paragraph node
    • The browser updates the screen

⚠️ Important:

  • ✅ The page doesn't reload
  • ✅ Only the DOM is modified

8️⃣ The DOM is NOT part of JavaScript (important detail)

This often confuses people at first, so it's worth clarifying:

The DOM is not part of the JavaScript language.

The DOM is:

  • A browser API
  • Exposed so JavaScript can use it

That's why:

  • ✅ document exists in the browser
  • ❌ In Node.js the DOM doesn't exist

This detail is key to understanding why JavaScript can run in so many different environments.

9️⃣ JavaScript today: much more than the DOM

Today JavaScript:

  • ✅ Consumes APIs
  • ✅ Handles data
  • ✅ Runs on servers
  • ✅ Is used in mobile and desktop apps

But still:

One of its most important functions remains interacting with the web through the DOM.

And something very important for the future:

Frameworks like React, Vue, or Angular don't replace the DOM.
What they do is organize and abstract its use.

🔚 Final summary

What you should take away from this lesson:

  • ✅ The DOM is the living representation of the web page
  • ✅ JavaScript interacts with the web through the DOM
  • ✅ The DOM allows modifying content without reloading
  • ✅ All modern frontend eventually interacts with the DOM
  • ✅ Understanding the DOM is key before using frameworks
