Create, Insert, and Remove HTML Elements with JavaScript (DOM)

Dynamic DOM element manipulation

Introduction

In this tutorial we'll learn how to dynamically create HTML elements with JavaScript, how to insert them in different positions of the DOM, and how to remove them, using both modern and traditional APIs.

The goal is to understand what really happens in the DOM, not just memorize methods.

1️⃣ Key idea: create ≠ insert

One of the most common mistakes when starting with the DOM is this:

"I created an element… why doesn't it appear on the page?"

The reason is simple:

  • document.createElement() creates a node in memory
  • It does NOT automatically add it to the DOM
  • Until you explicitly insert it, it doesn't render

Think of it as:

"I've manufactured it, but haven't placed it anywhere yet".

2️⃣ Create a new HTML element

Let's create a paragraph (<p>).

const newParagraph = document.createElement("p");

At this point:

  • ✅ Exists in memory
  • ❌ Not in the DOM
  • ❌ Not visible on the page

3️⃣ Configure the element (content, styles, classes)

Add text

The recommended way is textContent:

newParagraph.textContent = "This is a new paragraph created from JavaScript";

📌 Best practices

  • ✅ textContent is safe (doesn't interpret HTML)
  • ✅ Avoids security issues (XSS)
  • ⚠️ Use innerHTML only when you fully control the content

Add styles

newParagraph.style.padding = "8px";

💡 In real projects, it's ideal to use CSS classes, not inline styles:

newParagraph.classList.add("paragraph");

4️⃣ Insert the element into the DOM

Now yes: let's add it to the HTML.

const container = document.querySelector(".container");
container.append(newParagraph);

🎉 At this moment:

  • ✅ The node moves from memory → DOM
  • ✅ The browser renders it
  • ✅ The user sees it

5️⃣ Create and add elements to a list (ul > li)

Suppose we have this HTML:

<ul class="items-list">
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

Access the list

const itemsList = document.querySelector(".items-list");

Create a new <li>

const newItem = document.createElement("li");
newItem.textContent = "New element";

6️⃣ Insert at different positions

➕ At the end of the list (append)

itemsList.append(newItem);

⬆️ At the beginning (prepend)

itemsList.prepend(newItem);

7️⃣ Insert at a specific position

Access existing children

const secondItem = itemsList.children[1]; // index 1 = second element

📌 Important:

  • children → only HTML elements
  • childNodes → includes text nodes (spaces, line breaks)

Insert before the second element (classic way)

itemsList.insertBefore(newItem, secondItem);

Insert using modern APIs (before / after)

Cleaner and more readable:

secondItem.before(newItem); // before the second
// secondItem.after(newItem); // after the second

💡 Here you're no longer working from the parent, but from the reference element.

8️⃣ Move vs clone elements (important detail)

If you insert a node that already exists in the DOM:

itemsList.append(existingItem);

⚠️ It doesn't duplicate, it moves.

If you want to copy it:

const clone = existingItem.cloneNode(true);
itemsList.append(clone);

Note about cloneNode:

  • cloneNode(true) → clones element and all its children (deep clone)
  • cloneNode(false) → clones only the element without its children

9️⃣ Remove elements from the DOM

Modern way (recommended)

newParagraph.remove();

Simple, clear, and direct.

Traditional way (legacy)

const parent = newParagraph.parentElement;
parent.removeChild(newParagraph);

📌 Before it was necessary to:

  1. Go up to the parent
  2. Ask the parent to remove the child

Today, remove() does all that for you.

🔟 Performance: creating many elements (senior level)

If you need to create many elements, avoid inserting one by one.

Use DocumentFragment

const fragment = document.createDocumentFragment();

for (let i = 1; i <= 100; i++) {
  const li = document.createElement("li");
  li.textContent = `Item ${i}`;
  fragment.append(li);
}

itemsList.append(fragment);

Advantages:

  • ✅ Fewer repaints
  • ✅ Better performance
  • ✅ More professional code

1️⃣1️⃣ Summary of insertion methods

Method Position API
append() At the end of container Modern
prepend() At the beginning of container Modern
before() Before reference element Modern
after() After reference element Modern
insertBefore() Before a specific child Classic
appendChild() At the end (legacy) Classic

1️⃣2️⃣ Complete example (ready to test)

// Create element
const newItem = document.createElement("li");
newItem.textContent = "New dynamic item";
newItem.classList.add("item");

// Select container
const list = document.querySelector(".items-list");

// Verify it exists
if (list) {
  // Insert at the end
  list.append(newItem);

  // After 2 seconds, remove it
  setTimeout(() => {
    newItem.remove();
  }, 2000);
}

1️⃣3️⃣ Example with events: add and remove dynamically

const addButton = document.querySelector("#add-item");
const list = document.querySelector(".items-list");

if (!addButton || !list) return;

// Add new element
addButton.addEventListener("click", () => {
  const newItem = document.createElement("li");
  newItem.textContent = `Item ${list.children.length + 1}`;

  // Add delete button
  const deleteBtn = document.createElement("button");
  deleteBtn.textContent = "Delete";
  deleteBtn.addEventListener("click", () => {
    newItem.remove();
  });

  newItem.append(deleteBtn);
  list.append(newItem);
});

✅ Best practices checklist

  • ✔️ createElement creates in memory, not in DOM
  • ✔️ Use textContent by default
  • ✔️ Insert with append, prepend, before, after
  • ✔️ For specific positions, use children
  • ✔️ remove() is the modern way to delete
  • ✔️ For large lists, use DocumentFragment
  • ✔️ Verify elements exist before manipulating them
  • ✔️ Remember: inserting an existing element moves it, doesn't duplicate it

1️⃣4️⃣ Common errors

  • ❌ Creating an element and expecting it to appear automatically
  • ❌ Not verifying if container exists before inserting
  • ❌ Using innerHTML to add multiple elements (loses event listeners)
  • ❌ Forgetting that inserting an existing element moves it
  • ❌ Not using DocumentFragment when creating many elements

✅ Summary

  • createElement() creates elements in memory
  • textContent to add text safely
  • append() inserts at end, prepend() at beginning
  • before() and after() for relative positions
  • insertBefore() for specific positions (classic)
  • remove() removes elements (modern)
  • cloneNode(true) to copy elements
  • DocumentFragment to optimize multiple insertions
  • Inserting an existing element moves it, doesn't duplicate it
