DOM Manipulation with querySelector, CSS Classes, and Inline Styles

How to modify element appearance with JavaScript

Introduction

In this block we'll learn how to select DOM elements and modify their appearance using modern JavaScript.

This is one of the most common operations in any frontend application.

⚠️ This is not a CSS course, but we do need to understand how JavaScript interacts with CSS through the DOM.

1. Selecting elements with querySelector

Today, the most common way to work with the DOM is using CSS selectors.

JavaScript provides us with:

  • document.querySelector() → returns the first element that matches
  • document.querySelectorAll() → returns all elements that match

Basic example

const box = document.querySelector(".box");

Here we're saying:

  • Search in the document
  • The first element that has the class .box
  • Store it in the variable box

Most common selector types

  • .box → class
  • #main → id
  • button → HTML tag
  • [data-role="save"] → attribute (heavily used in modern apps)

⚠️ Important:

If the element doesn't exist, querySelector returns null.

if (!box) return; // avoids errors

2. Manipulate CSS classes with classList (recommended way)

Once we have an element, we can access its list of HTML classes using classList.

Classes usually represent visual states.

Main methods

box.classList.add("selected");    // adds a class
box.classList.remove("selected"); // removes a class
box.classList.toggle("selected"); // toggles the class

What does toggle really do?

  • If the class doesn't exist → adds it
  • If the class exists → removes it

It's like a switch (ON / OFF).

Advanced variant (very useful)

box.classList.toggle("selected", true);  // forces ON
box.classList.toggle("selected", false); // forces OFF

This prevents errors when you want to control the state, not blindly toggle it.

Other useful classList methods

// Check if it has a class
box.classList.contains("selected"); // true or false

// Replace one class with another
box.classList.replace("old-class", "new-class");

3. Connect logic with a real event (click)

Visual changes usually happen because something occurs: a click, a submit, a server response, etc.

Example with a button:

const box = document.querySelector(".box");
const button = document.querySelector("button");

if (!box || !button) return;

button.addEventListener("click", () => {
  box.classList.toggle("selected");
});

What's happening here

  1. We listen for a click on the button
  2. When it happens, we toggle the selected class
  3. CSS reacts and repaints the element

4. Change styles directly with style (inline styles)

Besides using classes, all HTML elements have the style property.

This modifies the inline style, as if you wrote: 

<button style="background-color: blue">

Example

button.style.backgroundColor = "blue";
button.style.color = "white";
button.style.padding = "10px";

CSS ↔ JavaScript relationship

In CSS we use kebab-case:

  • background-color
  • font-size
  • border-radius

In JavaScript we use camelCase:

  • backgroundColor
  • fontSize
  • borderRadius

⚠️ Values are usually strings with units:

button.style.padding = "10px"; // ✅ correct
button.style.padding = 10;     // ❌ incorrect

5. CSS classes or inline styles? (very important)

Use CSS classes when:

  • ✅ They represent states (is-active, is-open, has-error)
  • ✅ The style doesn't depend on dynamic calculations
  • ✅ You want to maintain separation between logic and design

Use inline style when:

  • ✅ The value is dynamic (position, size, percentage)
  • ✅ It comes from JS calculations (e.g., drag & drop, animations)

👉 General rule:

  • States → classes
  • Dynamic values → style

6. Complete example (demo ready)

HTML

<div class="box">Box</div>
<button data-action="toggle-box">Toggle</button>

CSS (conceptual)

.box {
  padding: 16px;
  border: 1px solid #ccc;
}

.box.selected {
  background: red;
  color: white;
}

JavaScript

const box = document.querySelector(".box");
const button = document.querySelector('[data-action="toggle-box"]');

if (!box || !button) return;

button.addEventListener("click", () => {
  box.classList.toggle("selected");
});

7. Example with dynamic styles

When you need to calculate values dynamically:

const slider = document.querySelector('input[type="range"]');
const box = document.querySelector('.box');

if (!slider || !box) return;

slider.addEventListener('input', (e) => {
  const value = e.target.value;

  // Dynamic style based on slider value
  box.style.width = `${value}%`;
  box.style.opacity = value / 100;
});

8. Combine classes and inline styles

Sometimes you need both approaches:

const card = document.querySelector('.card');

// Visual state with class
card.classList.add('is-loading');

// Dynamic position with style
card.style.transform = `translateY(${offset}px)`;

// After loading
setTimeout(() => {
  card.classList.remove('is-loading');
  card.classList.add('is-loaded');
}, 2000);

9. Common errors (pitfalls)

❌ Forgetting the . for classes

// ❌ Incorrect
querySelector("box")

// ✅ Correct
querySelector(".box")

❌ Not checking if element exists (null)

// ❌ Dangerous
const box = document.querySelector(".box");
box.classList.add("active"); // Error if box is null

// ✅ Safe
const box = document.querySelector(".box");
if (box) {
  box.classList.add("active");
}

❌ Confusing querySelectorAll with a single element

// ❌ Incorrect (returns a list, doesn't have classList directly)
const boxes = document.querySelectorAll(".box");
boxes.classList.add("active"); // Error

// ✅ Correct
const boxes = document.querySelectorAll(".box");
boxes.forEach(box => {
  box.classList.add("active");
});

❌ Using numbers without units in style

// ❌ Incorrect
element.style.width = 200;

// ✅ Correct
element.style.width = "200px";
element.style.width = "50%";

11. Bonus: Multiple classes at once

// Add multiple classes
element.classList.add("class1", "class2", "class3");

// Remove multiple classes
element.classList.remove("class1", "class2");

✅ Summary

  • querySelector() selects the first matching element
  • querySelectorAll() selects all matching elements
  • classList.add(), remove(), toggle() to manipulate classes
  • toggle(name, boolean) to force a specific state
  • element.style.property for dynamic inline styles
  • CSS uses kebab-case, JavaScript uses camelCase
  • Classes for states, style for dynamic values
  • Always verify the element exists before manipulating it
