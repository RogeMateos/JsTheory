Instances in JavaScript (new, instanceof, prototypes)

0) Objective

Understand two different things:

  • How instances (objects) are created
  • How to check if an object is an instance of a class (instanceof)

1) Create an instance with new

When you do new, 2 things happen:

  • ✅ A new object is created
  • ✅ The constructor() is executed

class Car {
  constructor(brand) {
    this.brand = brand;
  }
}

const car = new Car("BMW");
console.log(car); // Car { brand: "BMW" }

📌 Meaning

new Car() = "create a real car from the Car template".

2) Why car === Car is incorrect

This is a typical mistake:


console.log(car === Car); // false

Because you're comparing:

  • car → object (instance)
  • Car → class (constructor function / template)

🧠 Mental example

  • car is a cookie 🍪
  • Car is the mold 🧩

You can't compare them as if they were the same thing.

3) The correct check: instanceof

To know if car is a Car, use:


console.log(car instanceof Car); // true

✅ What does instanceof mean?

It means:

"Does Car.prototype exist within the prototype chain of car?"

4) The prototype chain (very important)

JavaScript inherits like this:


car → Car.prototype → Object.prototype → null

When you do this:


console.log(car instanceof Car);

JavaScript looks if Car.prototype is within that chain.

5) Create "instances" without new: Object.create

Now this is important:


const anotherCar = Object.create(Car.prototype);
  • ✅ Creates an object whose prototype is Car.prototype
  • ❌ Does NOT execute the constructor

Example:


class Car {
  constructor() {
    this.wheels = 4;
  }
}

const anotherCar = Object.create(Car.prototype);

console.log(anotherCar instanceof Car); // true ✅
console.log(anotherCar.wheels);         // undefined ❗️

📌 Why undefined?

Because the constructor was never executed.

6) Quick comparison: new vs Object.create

Method Creates object Links prototype Executes constructor
new Car() ✅ ✅ ✅
Object.create(Car.prototype) ✅ ✅ ❌

👉 Quick rule

  • I want a complete object → new
  • I want to create a clone / prototype → Object.create

7) "Stricter" check (exact prototype)

Sometimes you want to verify this:

✅ "Is exactly a Car (not just inheritance)"


console.log(Object.getPrototypeOf(car) === Car.prototype); // true

📌 Difference

  • instanceof → accepts inheritance
  • getPrototypeOf === prototype → exact

8) Real example with inheritance


class Vehicle {}
class Car extends Vehicle {}

const c = new Car();

console.log(c instanceof Car);     // true
console.log(c instanceof Vehicle); // true

✅ Result

Because Car inherits from Vehicle

✅ Summary

What you must remember

  • ✅ new creates complete instances
  • ✅ instanceof checks instances using prototypes
  • ✅ Object.create creates objects without constructor
  • ✅ The key is the prototype chain

Common Errors Checklist

⚠️ Typical errors to avoid

  • ❌ Comparing instance with class using ===
  • ❌ Confusing instanceof with typeof
  • ❌ Expecting Object.create to execute the constructor
  • ❌ Not understanding the prototype chain
