5 Modern JavaScript Operators

The operators that senior developers use in 2024

🎯 The 5 Key Operators

Operator What It Does Example
?. Prevents errors if not exists user?.name
?? Default value if null/undefined name ?? "Guest"
||= Assigns if falsy user ||= "default"
&&= Assigns if truthy user &&= true
??= Assigns if null/undefined user ??= "default"

1️⃣ Optional Chaining (?.)

Mental translation

?. = "if it exists, continue"

Basic example

const user = null

console.log(user?.name)  // undefined (no error)

// Without ?.:
console.log(user.name)   // ❌ Error: Cannot read properties of null

Real case

const username = data?.user?.name

// If data.user.name exists → returns the value
// If something doesn't exist → returns undefined

2️⃣ Nullish Coalescing (??)

Mental translation

?? = "if it's null or undefined, use this"

Basic example

const name = null

console.log(name ?? "Guest")  // "Guest"

const age = 0
console.log(age ?? 18)        // 0 (because 0 is not null/undefined)

Real case

const username = user?.name ?? "Anonymous"

// If user.name exists → uses its value
// If null/undefined → uses "Anonymous"

3️⃣ Logical OR Assignment (||=)

Mental translation

||= = "assign if falsy"

Falsy: false, 0, "", null, undefined

Basic example

let username = ""

username ||= "Guest"
console.log(username)  // "Guest"

// Because "" is falsy

Long equivalent

if (!username) {
  username = "Guest"
}

// Same result, but ||= is more elegant

Real case in applications

let timeout = config.timeout

timeout ||= 3000  // If timeout is 0, "", null → use 3000

4️⃣ Logical AND Assignment (&&=)

Mental translation

&&= = "assign only if truthy"

Basic example

let user = { logged: true }

user.logged &&= false
console.log(user.logged)  // false

// Only assigned because user.logged was true

Long equivalent

if (user.logged) {
  user.logged = false
}

// Same result, but &&= is more elegant

Real case

let isAdmin = user.role === "admin"

isAdmin &&= canManageUsers  // Only changes if admin

5️⃣ Nullish Assignment (??=)

Mental translation

??= = "assign if null or undefined"

Basic example

let username = null

username ??= "Guest"
console.log(username)  // "Guest"

// But look at this:
let username2 = ""

username2 ??= "Guest"
console.log(username2)  // ""

// Because "" is NOT null/undefined

The key difference

// ||= assigns if falsy (0, "", null, undefined, false)
let a = 0
a ||= 10  // → 10

// ??= assigns ONLY if null/undefined
let b = 0
b ??= 10  // → 0

Real case

let theme = config.theme

theme ??= "dark"  // Only if not defined

📊 Visual Comparison

||= (Falsy)
let value = ""

value ||= "default"
// → "default"

// Because "" is falsy
??= (Null/Undefined)
let value = ""

value ??= "default"
// → ""

// Because "" is NOT null

This is the most common confusion

Remember: ??= ONLY checks null/undefined

While ||= checks any falsy value

💡 Real Example: Modern Code

Typical in React/APIs

// Get data safely
const username = data?.user?.name ?? "Guest"

// Set default values
settings.theme ??= "dark"

// Configure timeouts
config.timeout ||= 3000

// Change state only if true
user.isAdmin &&= hasPermission

Complete mental translation

If data.user.name exists use it
If not, use "Guest"

If settings.theme doesn't exist use "dark"

If config.timeout is falsy use 3000

If user.isAdmin is true and hasPermission is true → true

🎯 When to Use Each One

?. (Optional Chaining)

  • Access properties that might not exist
  • Call methods that might not exist
  • Read arrays with indexes that might not exist
user?.name
user?.getAge()
items?.[0]

?? (Nullish Coalescing)

  • Provide safe default value
  • Differentiate null/undefined from other falsy values
price ?? 0      // If price is null/undefined
timeout ?? 5000 // If timeout doesn't exist

||= (Logical OR Assignment)

  • Initialize variables if empty/false
  • When you want to exclude 0 and "" too
username ||= "Guest"   // If username is ""
retries ||= 3          // If retries is 0

&&= (Logical AND Assignment)

  • Change value only if already true
  • Compact conditional operations
user.premium &&= checkPayment()
isValid &&= validateForm()

??= (Nullish Assignment)

  • Initialize variables that don't exist yet
  • Allow 0, "", false as valid values
config.theme ??= "dark"
settings.volume ??= 50

⚡ Common Patterns in React

Pattern 1: Safe data with default value

const avatar = user?.profile?.avatar ?? defaultAvatar

Pattern 2: Initialize state

let settings = loadSettings()
settings.theme ??= "light"
settings.language ??= "en"

Pattern 3: Conditional validation

user.hasPermission &&= validateToken()
data?.length &&= fetchMore()

Pattern 4: Safe default values

const timeout = config?.timeout || 3000
const theme = user?.settings?.theme ?? "default"

✅ Practical Summary

Learn these first:

  • ?. → prevents errors
  • ?? → safe default value (null/undefined)
  • || → default value (falsy)

The others (||=, &&=, ??=) are shortcuts for assignments.

💡 In professional code you'll see more

  • ?. - Super common
  • ?? - Super common
  • || - Very common (but try to avoid if you can)
  • ||= - Occasionally
  • &&= - Rare
  • ??= - Occasionally
