Var, Let, Const, Block Scope, Global Scope

var

var is function-scoped and allows redeclaration within the same scope. If you declare a variable using var within a function, it is accessible anywhere within that function. var does not have block-level scope.


      var x = 10;
      if (x === 10) {
          var x = 20;
          console.log(x); // Output: 20
      }
      console.log(x); // Output: 20

🔄 let - Variable that can be reassigned

let allows you to declare a variable whose value can change:


let age = 25
console.log(age) // 25

// You can reassign the value
age = 26
console.log(age) // 26

age = 27
console.log(age) // 27

Practical example with let


let counter = 0
console.log(counter) // 0

counter = counter + 1 // Increment
console.log(counter) // 1

counter = counter + 1
console.log(counter) // 2

let is block-scoped and cannot be redeclared within the same scope.


let y = 10;
if (y === 10) {
    let y = 20;
    console.log(y); // Output: 20
}
console.log(y); // Output: 10

🔒 const - Variable that CANNOT be reassigned

const declares a variable whose value cannot change (it's constant):


const PI = 3.14159
console.log(PI) // 3.14159

// ❌ This will cause an error
PI = 3.14 // TypeError: Assignment to constant variable

Practical example with const


const name = 'Miguel'
const lastName = 'Ángel'

console.log(name) // Miguel
console.log(lastName) // Ángel

// ❌ This will cause an error
name = 'Juan' // TypeError: Assignment to constant variable

const is block-scoped and doesn't allow reassigning the reference. However, objects/arrays can still be mutated internally.


const z = 10;
// z = 11; // Error

const obj = { name: 'Alice' };
obj.name = 'Bob'; // ok

const arr = [1, 2];
arr.push(3); // ok

📊 When to use let and when to use const?

Use const when:

  • The value won't change
  • It's a constant value (PI, configuration, etc.)
  • You want to prevent accidental reassignments

const MAX_USERS = 100
const API_URL = 'https://api.example.com'
const APP_NAME = 'MyApp'

Use let when:

  • The value will change
  • You need to reassign the variable
  • It's a counter, accumulator, etc.

let counter = 0
let sum = 0
let currentUser = null

🎯 Practical Rule

Use const by default. Only switch to let if you discover you need to reassign the value.


// ✅ Good practice: start with const
const name = 'Miguel'
const age = 25

// If you need to change the value, use let
let counter = 0
counter = counter + 1

Scope Comparison

var is function-scoped and can be redeclared within the same scope.

let and const are block-scoped and cannot be redeclared within the same scope.

const is used for constants that should not be reassigned, while let is used for variables that can be reassigned.

Understanding the differences between var, let, and const is crucial for writing clean and maintainable JavaScript code.
