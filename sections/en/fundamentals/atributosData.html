data-* Attributes in HTML and JavaScript

Store custom information in HTML elements that JavaScript can easily read

🎯 Simple Definition for Interviews

What are data-* attributes?

data-* attributes allow you to store custom information within HTML that JavaScript can easily access.

They don't display on the page, but JavaScript can access them using the dataset property.

💡 Key Concept

Think of them as small hidden information labels in HTML

HTML → stores data

JavaScript → reads it with dataset

They're commonly used for:

  • Filters: Store categories to filter elements
  • Modals: Store information about which modal to open
  • UI Components: Store component states or IDs
  • Dynamic Lists: Store user IDs, product IDs, etc.
  • Frameworks: React, Vue, Angular use them internally

1️⃣ What are data-* Attributes

Syntax in HTML

data-* attributes have this structure:

<div data-name="Miguel" data-age="25"></div>

Here the div stores two pieces of data:

Attribute Value
data-name Miguel
data-age 25

Important rules

  • Always start with data-
  • After that, you can use any name (kebab-case)
  • Values are always strings in HTML
  • They don't display visually on the page

2️⃣ How to Read data-* in JavaScript

Using the dataset property (modern way)

JavaScript has a special property called dataset that automatically converts data-* attributes into properties.

const div = document.querySelector('div')

console.log(div.dataset.name)  // "Miguel"
console.log(div.dataset.age)   // "25"

What happens internally

HTML: data-name="Miguel"

JavaScript: element.dataset.name

⚠️ Notice that the data- prefix is removed

3️⃣ Alternative: getAttribute

We can also read attributes using getAttribute

This method works for any attribute (not just data-*):

const div = document.querySelector('div')

console.log(div.getAttribute('data-name'))  // "Miguel"
console.log(div.getAttribute('data-age'))   // "25"

Method comparison

Method How it works
dataset Modern and more convenient way
getAttribute Generic way for any attribute

In modern JavaScript, we typically use: dataset

4️⃣ Real Example: Filtering a Job Listings

Practical use case

Imagine a website with job offers where we want to filter by work mode (remote, in-office, by city).

We store this information in data-modality.

5️⃣ HTML of Job Listings

HTML structure

<div class="jobs-listings">
  <article data-technology="react" data-modality="remote" class="job-listing-card">
    <h4>React Developer</h4>
    <p>Remote work</p>
  </article>

  <article data-modality="cdmx" class="job-listing-card">
    <h4>Frontend Developer</h4>
    <p>In-office in Mexico City</p>
  </article>

  <article data-modality="guadalajara" class="job-listing-card">
    <h4>Full Stack Developer</h4>
    <p>In-office in Guadalajara</p>
  </article>

  <article data-modality="remote" class="job-listing-card">
    <h4>Node.js Developer</h4>
    <p>Remote work</p>
  </article>
</div>

Each job offer stores its modality in:

data-modality

6️⃣ Select for Filtering

Select element with options

<select id="filter-modality">
  <option value="">All</option>
  <option value="remote">Remote</option>
  <option value="cdmx">Mexico City</option>
  <option value="guadalajara">Guadalajara</option>
</select>

7️⃣ JavaScript to Filter Jobs

Filtering code

const filter = document.querySelector('#filter-modality')
const jobs = document.querySelectorAll('.job-listing-card')

filter.addEventListener('change', function () {
  const selectedValue = filter.value

  jobs.forEach((job) => {
    const modality = job.dataset.modality

    if (selectedValue === '' || selectedValue === modality) {
      job.style.display = 'flex'
    } else {
      job.style.display = 'none'
    }
  })
})

8️⃣ How the Code Works

Step by step

  1. Listen for select change

    filter.addEventListener('change') - When the user changes the filter

  2. Get the selected value

    const selectedValue = filter.value - For example: "remote"

  3. Loop through all jobs

    jobs.forEach(job => {})

  4. Read the data-modality attribute

    const modality = job.dataset.modality - For example: "remote"

  5. Compare values

    selectedValue === modality - Do they match?

  6. Show / hide

    Show: job.style.display = 'flex'

    Hide: job.style.display = 'none'

9️⃣ Why We Use selectedValue === ''

The special case: "All"

When the user selects the "All" option, the select's value is an empty string: ''

Then we show all the jobs.

if (selectedValue === '' || selectedValue === modality) {
  // If empty OR matches → show
}

1️⃣1️⃣ When to Use data-* (Very Common in Front-end)

They're used extensively in:

  • UI Components: data-id, data-user, data-state
  • Tracking: data-analytics, data-event
  • Filters: data-category, data-modality
  • React / Frameworks: Many libraries use them internally

Example in a shopping cart

<button data-product-id="123" data-price="29.99" class="add-to-cart">
  Add to Cart
</button>
document.querySelector('.add-to-cart').addEventListener('click', (e) => {
  const productId = e.target.dataset.productId
  const price = e.target.dataset.price
  // Add to cart...
})

1️⃣3️⃣ Quick Exercise (Very Good for Learning)

Create buttons that change a div's color

HTML:
<button data-color="red">Red</button>
<button data-color="blue">Blue</button>
<button data-color="green">Green</button>

<div id="box" style="width: 100px; height: 100px; background: gray;"></div>
JavaScript:
const buttons = document.querySelectorAll('button')
const box = document.querySelector('#box')

buttons.forEach(button => {
  button.addEventListener('click', () => {
    const color = button.dataset.color
    box.style.backgroundColor = color
  })
})

How does it work?

  1. Each button has a different data-color
  2. When you click, the dataset.color is read
  3. The color is applied to the div

1️⃣4️⃣ data-* with Complex Attributes

You can store multiple pieces of data in one element

<div
  data-user-id="42"
  data-user-name="Juan"
  data-user-role="admin"
  data-user-status="active"
  class="user-card"
>
  User Profile
</div>
const card = document.querySelector('.user-card')

console.log(card.dataset.userId)     // "42"
console.log(card.dataset.userName)   // "Juan"
console.log(card.dataset.userRole)   // "admin"
console.log(card.dataset.userStatus) // "active"

⚠️ Important: Names in camelCase

In HTML you use: data-user-id

In JavaScript it becomes: dataset.userId (camelCase)

Hyphens are converted to uppercase letters.
