Currying in JavaScript

What is Currying?

Currying is a technique that transforms a function that receives multiple parameters into a series of functions that each receive one parameter.

Transformation

👉 Before:

function(a, b, c)

👉 After (curry):

function(a)(b)(c)

Example WITHOUT Currying (normal)

A normal function receives everything at once:


function sum(a, b, c) {
  return a + b + c;
}

sum(1, 2, 3); // 6

Here

  • I have to pass all 3 values always
  • I can't reuse "part" of the function

The SAME Example WITH Currying (step by step)


function sumCurry(a) {
  return function (b) {
    return function (c) {
      return a + b + c;
    };
  };
}

This function doesn't calculate anything yet
👉 It just saves values little by little

How to Use It (very clear)

Chained Form


sumCurry(1)(2)(3); // 6

Step by Step Form (most important to understand)


const stepB = sumCurry(1); // saves a = 1
const stepC = stepB(2);    // saves b = 2
const result = stepC(3);   // uses a + b + c

console.log(result); // 6

What's Really Happening? (key mental model)

Each function remembers what it received before

Example:

const stepB = sumCurry(1);

stepB is:

  • A function
  • With a backpack containing: a = 1

This is called a closure.

VERY CLEAR Real Example (multiply)


const multiply = (a) => (b) => a * b;

Usage:


const timesTwo = multiply(2); // saves a = 2

timesTwo(5);  // 10
timesTwo(8);  // 16
timesTwo(10); // 20

Here it's very clear

  • I create a special "timesTwo" function
  • I don't pass 2 again
  • I reuse the behavior

Another Everyday Example (greetings)


const greet = (greeting) => (name) => {
  return `${greeting}, ${name}`;
};

const hello = greet("Hello");
const goodbye = greet("Goodbye");

hello("Roge");   // Hello, Roge
hello("Ana");    // Hello, Ana
goodbye("Roge"); // Goodbye, Roge

Why Does Currying Exist?

It's used for

  • Reusing functions
  • Saving configurations
  • Creating more specific functions from a general one

👉 Instead of repeating:


sum(1, 2, 3);
sum(1, 2, 4);
sum(1, 2, 10);

You do:


const sum12 = sumCurry(1)(2);
sum12(3);  // 6
sum12(4);  // 7
sum12(10); // 13

More Practical Examples

Example 1: Store Discounts


const applyDiscount = (discount) => (price) => {
  return price - (price * discount / 100);
};

const discount10 = applyDiscount(10);
const discount20 = applyDiscount(20);

console.log(discount10(100)); // 90
console.log(discount10(50));  // 45
console.log(discount20(100)); // 80

Example 2: Validators


const createValidator = (minLength) => (text) => {
  return text.length >= minLength;
};

const validatePassword = createValidator(8);
const validateUsername = createValidator(3);

console.log(validatePassword("abc"));      // false
console.log(validatePassword("abc12345")); // true
console.log(validateUsername("Jo"));       // false
console.log(validateUsername("Joe"));      // true

Example 3: Message Formatting


const createMessage = (type) => (user) => (content) => {
  return `[${type}] User ${user}: ${content}`;
};

const error = createMessage("ERROR");
const info = createMessage("INFO");

const errorRoge = error("Roge");
const infoAna = info("Ana");

console.log(errorRoge("File not found"));
// [ERROR] User Roge: File not found

console.log(infoAna("Operation successful"));
// [INFO] User Ana: Operation successful

Currying vs Partial Functions

Key Difference

Currying: Each function receives exactly ONE parameter

const curry = (a) => (b) => (c) => a + b + c;

Partial Functions: You can fix multiple parameters at once


const partial = (a, b) => {
  return (c) => a + b + c;
};

Ultra Short Summary (to memorize)

Key Concepts

  • Currying = f(a, b, c) → f(a)(b)(c)
  • Each function receives a single parameter
  • Functions remember previous values (closure)
  • Used to reuse and specialize functions

Advantages

  • ✅ More reusable code
  • ✅ More specialized functions
  • ✅ Saved configurations
  • ✅ Easier function composition
