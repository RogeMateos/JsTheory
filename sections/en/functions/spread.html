Understanding Spread and Rest Operators in JavaScript

In JavaScript, the spread (...) and rest (...) operators use the same syntax but do opposite things depending on where they are used. Understanding this difference makes working with arrays and objects much easier and more readable.

Spread Operator

The spread operator (...) is used to expand an array or object into individual elements or properties.

👉 Think of spread as "taking things out of a box".

You commonly use spread to:

  • Copy arrays or objects
  • Merge arrays or objects
  • Pass array values as individual function arguments

Example: Spreading Arrays


    const arr1 = [1, 2, 3];
    const arr2 = [4, 5, 6];

    const combinedArray = [...arr1, ...arr2];
    console.log(combinedArray);
    // Output: [1, 2, 3, 4, 5, 6]

What's happening here:

  • ...arr1 expands to 1, 2, 3
  • ...arr2 expands to 4, 5, 6
  • These values are placed into a new array

So JavaScript sees: [1, 2, 3, 4, 5, 6]

Example: Spreading Objects


    const person = { name: 'Alice', age: 25 };
    const additionalInfo = { country: 'UK', job: 'Developer' };

    const mergedPerson = { ...person, ...additionalInfo };
    console.log(mergedPerson);
    // Output: { name: 'Alice', age: 25, country: 'UK', job: 'Developer' }

What's happening here:

  • ...person spreads each property (name, age)
  • ...additionalInfo spreads its properties
  • All properties are copied into a new object
⚠️ Important: If two objects have the same key, the last one wins.

🧠 Key Rule to Remember

Spread → expands values
Rest → collects values

Or simply:

  • Spread = take apart
  • Rest = put together

Rest Operator

The REST operator (...) is used to collect many values into a single variable (array).

The SIMPLEST example possible


    function sum(...numbers) {
      console.log(numbers);
    }

    sum(1, 2, 3);  // Prints: [1, 2, 3]
    sum(5, 10);    // Prints: [5, 10]

📌 ...numbers = "put all arguments into an array"

Clear difference: WITHOUT vs WITH rest operator


    // WITHOUT ... → you receive separate values
    function sum(a, b) {
      console.log(a, b);
    }
    sum(5, 10);  // Prints: 5 10

    // WITH ... → you receive an array with all values
    function sum(...numbers) {
      console.log(numbers);
    }
    sum(5, 10);  // Prints: [5, 10]
🧠 KEY phrase:
Without ... → you receive separate values
With ... → you receive an array with all values

Now let's sum without loops or magic


    function sum(...numbers) {
      return numbers[0] + numbers[1];
    }

    console.log(sum(5, 10));  // 15
    // No loops, no methods, no magic

Scenario without REST operator:


    // ❌ Limited function - only sums 3 numbers
    function sumThreeNumbers(a, b, c) {
      return a + b + c;
    }

    console.log(sumThreeNumbers(1, 2, 3)); // 6
    console.log(sumThreeNumbers(1, 2, 3, 4, 5)); // 6 (ignores 4 and 5!)
    // Problem: What if I want to sum 5 numbers? 10 numbers? 100 numbers?

Solution with REST operator:


    // ✅ Flexible function - sums any amount of numbers
    function sum(...numbers) {
      console.log(numbers); // numbers is an ARRAY

      let total = 0;
      for (const num of numbers) {
        total += num;
      }
      return total;
    }

    console.log(sum(1, 2, 3));           // 6
    console.log(sum(1, 2, 3, 4, 5));     // 15
    console.log(sum(10, 20, 30, 40, 50)); // 150

Example with reduce:


    function sum(...numbers) {
      return numbers.reduce((acc, curr) => acc + curr, 0);
    }

    console.log(sum(1, 2, 3, 4)); // Output: 10

Example: Rest in Object Destructuring


    const person = { name: 'Alice', age: 25, country: 'UK', job: 'Developer' };

    const { name, ...rest } = person;
    console.log(name); // Output: Alice
    console.log(rest); // Output: { age: 25, country: 'UK', job: 'Developer' }

Difference Between Spread and Rest Operators

Same symbol ..., but different timing:

1️⃣ REST → collects values and puts them in an array

👉 Used in function definition


    function show(...numbers) {
      console.log(numbers);
    }

    show(1, 2, 3);  // [1, 2, 3]
    show(5, 10);    // [5, 10]

    // What really happens:
    // show(1, 2, 3)  → numbers = [1, 2, 3]
    // show(5, 10)    → numbers = [5, 10]

📌 REST = many values → 1 array

2️⃣ SPREAD → extracts values from an array

👉 Used when calling the function


    function show(a, b, c) {
      console.log(a, b, c);
    }

    const nums = [1, 2, 3];
    show(...nums);  // 1 2 3

    // What really happens:
    // show(...nums)
    // → show(nums[0], nums[1], nums[2])
    // → show(1, 2, 3)

📌 SPREAD = 1 array → many values

🔍 Understanding: Why does this line exist?

// → show(nums[0], nums[1], nums[2])

This line is NOT code you write.
It is a mental translation of what SPREAD does internally.

Step 1️⃣ What nums really is
const nums = [1, 2, 3];

In memory, think of it like this:

index:  0   1   2
value:  1   2   3

So: nums[0] → 1, nums[1] → 2, nums[2] → 3

Step 2️⃣ What a function call needs
function show(a, b, c) { ... }

This function wants three separate values, not an array:

✅ show(a, b, c)
❌ show([1, 2, 3]) → It does not understand this

Step 3️⃣ What ...nums actually does

When JavaScript sees: show(...nums);

It does this internally:

  1. Looks at nums
  2. Takes values in order
  3. Passes them one by one as arguments

Which becomes:

show(nums[0], nums[1], nums[2]);

And since nums[0] = 1, nums[1] = 2, nums[2] = 3

It finally becomes:

show(1, 2, 3);
Step 4️⃣ Why JavaScript must do this

JavaScript functions do not magically unpack arrays.

Without spread: show(nums); → ONE argument
With spread: show(...nums); → THREE arguments

Step 5️⃣ Very important clarification ❗

This line: // show(nums[0], nums[1], nums[2])

  • ✔️ is conceptual
  • ✔️ is how spread behaves
  • ❌ is not something you normally write
  • ❌ is not a different feature
💡 One-sentence "click" moment

Spread (...) converts an array into separate arguments by passing each index as a parameter in order.

🎯 Final mental rule (keep this forever)
  • Arrays store values by index
  • Functions receive values by position
  • Spread bridges the two

3️⃣ SAME ... but different moment

Where is ... It's What it does
In parameters REST Collects values into an array
When calling SPREAD Separates an array into values

4️⃣ Minimal side-by-side example


    // REST - packs 📦
    function restExample(...args) {
      console.log(args);
    }
    restExample(1, 2, 3); // [1, 2, 3]

    // SPREAD - unpacks 🎁
    function spreadExample(a, b, c) {
      console.log(a, b, c);
    }
    const args = [1, 2, 3];
    spreadExample(...args); // 1 2 3

🧠 DEFINITIVE mental trick

👉 REST = packs 📦
👉 SPREAD = unpacks 🎁

Without ... → you receive separate values
With ... → you receive an array with all values
