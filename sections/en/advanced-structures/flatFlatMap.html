flat() and flatMap() in JavaScript

Topic Objective

Today you'll learn two array methods in JavaScript that are widely used when working with real data (APIs, UI, lists, etc.):

  • flat(depth): flattens (reduces levels) a nested array.
  • flatMap(fn): performs a map and then flattens 1 level.

⚠️ Important

Neither modifies the original array. They return a new one.

1) Practical Context (Why This Matters)

In real projects, data often comes nested:

  • An API returns categories with product lists
  • A post has comments (list) and each comment has replies (another list)
  • You group elements by sections and then need a "flat" list to render or filter

When that happens, you need to "flatten" to be able to:

  • Iterate through everything with a single UI .map()
  • Perform a global search
  • Calculate totals
  • Apply filters without nested loops

2) flat() — What It Does Exactly

2.1 Simple Definition

  • flat(depth) flattens an array up to a depth depth
  • depth is optional
  • If you don't specify anything, the default value is 1
  • Returns a new array

2.2 Base Example: Nested Array


const nested = [1, [2, [3, [4]]]];

Case A: flat() without parameter (depth = 1)


const flat1 = nested.flat();

console.log(flat1);  // [1, 2, [3, [4]]]
console.log(nested); // [1, [2, [3, [4]]]]  (doesn't change)

✅ What happened?

Only the first nesting level was removed.

2.3 Flatten More Levels with depth


console.log(nested.flat(2)); // [1, 2, 3, [4]]
console.log(nested.flat(3)); // [1, 2, 3, 4]

✅ Key Idea

depth is "how many levels" you want to go down.

2.4 When You Don't Know How Many Levels: Infinity


console.log(nested.flat(Infinity)); // [1, 2, 3, 4]

Useful if the array comes from outside (API) and you don't control how deep it is.

3) flatMap() — What It Is and Why It Exists

3.1 Correct Definition (The Mental Rule)

flatMap is equivalent to:


array.flatMap(fn) = array.map(fn).flat(1)

That is:

  1. Applies a function to each element (like map)
  2. The result is flattened only 1 level

4) Clear Example: From Sentences → Words

4.1 Data


const phrases = ["hello world", "goodbye world"];

4.2 With map (you get nested)


const mapped = phrases.map(p => p.split(" "));

console.log(mapped);
// [ ["hello", "world"], ["goodbye", "world"] ]

✅ What happened?

  • split(" ") returns an array
  • Since you do it with map, you end up with an array of arrays

4.3 With flatMap (flat result)


const words = phrases.flatMap(p => p.split(" "));

console.log(words);
// ["hello", "world", "goodbye", "world"]

✅ What did flatMap do?

  1. First generated: [["hello","world"],["goodbye","world"]]
  2. Then flattened it 1 level: ["hello","world","goodbye","world"]

5) Real Work Case (UI / API)

Imagine an API that gives you categories with items:


const categories = [
  { name: "Fruit", items: ["apple", "pear"] },
  { name: "Drink", items: ["water"] }
];

If you want to render all items in a single list:


const allItems = categories.flatMap(c => c.items);
console.log(allItems); // ["apple", "pear", "water"]

📌 This is typical for:

  • A global UI list
  • A search feature
  • A selector (dropdown)
  • Analytics ("how many items in total")

6) Important Warnings (Common Errors)

6.1 flatMap Only Flattens 1 Level

If you return something with more depth, it won't leave it completely flat:


const arr = [1, 2];

const result = arr.flatMap(x => [x, [x]]);
console.log(result);
// [1, [1], 2, [2]]

If you really want completely flat:


const fully = arr.flatMap(x => [x, [x]]).flat();
console.log(fully);
// [1, 1, 2, 2]

6.2 They Don't Mutate the Original (Very Important)


const original = [1, [2]];
const copy = original.flat();

console.log(original); // [1, [2]]
console.log(copy);     // [1, 2]

⚠️ Important

Both methods return a new array without modifying the original.

7) When to Use Each One (Quick Rule)

  • You just want to flatten → flat(depth)
  • You want to transform and flatten 1 level → flatMap(fn)
  • You don't know the depth → flat(Infinity)

8) Mini-Exercises (To Practice)

Exercise 1


const a = [1, [2, [3]]];
// Make it output: [1, 2, 3]

✅ Solution

a.flat(2);

Exercise 2


const names = ["Ana Lopez", "Juan Perez"];
// I want: ["Ana", "Lopez", "Juan", "Perez"]

✅ Solution

names.flatMap(n => n.split(" "));

9) Final Summary

Key Concepts

  • flat(depth) flattens nested arrays (default depth = 1)
  • flatMap(fn) is like map(fn) + flat(1)
  • Both return a new array: they don't mutate the original
  • Very useful for transforming API data and rendering UI lists
