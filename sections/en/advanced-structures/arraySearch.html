Array Search Operations in JavaScript

Introduction

When working with arrays, a very common need is to search for elements:

  • Know if a value exists
  • Find the first element that meets a condition
  • Get the position (index) of an element

Let's see how to do it correctly, why several methods exist, and when to use each one.

1️⃣ The "Old-Fashioned Way" Problem

Imagine this array:


const numbers = [1, 2, 3, 4, 6, 10];

If we want to know if the number 4 exists, without special methods we'd have to do something like this:


let exists = false;

for (let i = 0; i < numbers.length; i++) {
  if (numbers[i] === 4) {
    exists = true;
    break;
  }
}

👉 It works, but:

  • It's verbose
  • It's easy to make mistakes
  • It's not expressive

That's why JavaScript offers us search methods.

2️⃣ includes() – Does This Value Exist?

👉 What It Does

Checks if an array contains exactly a value.

👉 What It Returns

  • true → exists
  • false → doesn't exist

👉 Basic Example


const numbers = [1, 2, 3, 4, 6, 10];

console.log(numbers.includes(4)); // true
console.log(numbers.includes(5)); // false

👉 When to Use It

  • When you already know the exact value
  • Simple validations
  • Quick checks

👉 Useful Detail

You can specify from which index to start searching:


numbers.includes(4, 4); // starts from index 4

3️⃣ some() – Does SOMETHING Meet a Condition?

Here's a method many forget, but it's key.

👉 What It Does

Checks if any element meets a condition.

👉 What It Returns

true or false

👉 Example


const hasEven = numbers.some(n => n % 2 === 0);
console.log(hasEven); // true

👉 When to Use It

  • When you need a boolean
  • When the search depends on a condition
  • It's the logical equivalent of includes, but with conditions

4️⃣ find() – Give Me the FIRST Element That Meets

Now we take it a step further.

👉 What It Does

Iterates through the array and returns the first element that meets a condition.

👉 What It Returns

  • The found element
  • undefined if nothing is found

👉 Example: First Even Number


const firstEven = numbers.find(n => n % 2 === 0);
console.log(firstEven); // 2

⚠️ Key Point (Very Important)

find() depends on the current order of the array.

If we change the order:


const reversed = [...numbers].reverse();
console.log(reversed); // [10, 6, 4, 3, 2, 1]

const firstEven = reversed.find(n => n % 2 === 0);
console.log(firstEven); // 10

👉 "First" means first in that order, not the smallest or the original.

👉 Case: Nothing Found


const oddNumbers = [3, 7, 11];

const result = oddNumbers.find(n => n % 2 === 0);
console.log(result); // undefined

👉 Safe Pattern


if (result === undefined) {
  console.log("No element found");
}

👉 Realistic Example with Objects


const users = [
  { id: 1, name: "Ana" },
  { id: 2, name: "Roge" },
];

const user = users.find(u => u.id === 2);
console.log(user); // { id: 2, name: "Roge" }

✅ Important

find is perfect when you need the complete element.

5️⃣ findIndex() – What Position Is It At?

👉 What It Does

Works the same as find, but returns the index.

👉 What It Returns

  • A number ≥ 0 → index found
  • -1 → not found

👉 Example


const firstEvenIndex = numbers.findIndex(n => n % 2 === 0);
console.log(firstEvenIndex); // 1

👉 Case: Nothing Found


const oddNumbers = [3, 7, 11];

console.log(
  oddNumbers.findIndex(n => n % 2 === 0)
); // -1

💡 Important

findIndex always returns a number.

👉 Typical Use: Modify/Delete


const idx = numbers.findIndex(n => n === 4);

if (idx !== -1) {
  numbers.splice(idx, 1);
}

console.log(numbers); // [1, 2, 3, 6, 10]

6️⃣ Clear Differences (Mental Rule)

Need Method
Know if an exact value exists includes
Know if something meets a condition some
Get the element find
Get the position findIndex

7️⃣ ⚠️ Important: Mutation and Array Order

Methods that MODIFY the Original Array:

  • sort()
  • reverse()
  • splice()

Dangerous Example:


numbers.reverse(); // changes the original array

👉 This directly affects find and findIndex.

✅ Safe Solution:


const reversed = [...numbers].reverse();

8️⃣ Conclusion as a Senior Developer

Key Concepts

  • There's no "best" method, there are correct methods depending on context
  • Use:
    • includes for direct values
    • some for booleans with conditions
    • find when you need the data
    • findIndex when you need the position
  • Always consider the current array order
  • Watch out for methods that mutate
