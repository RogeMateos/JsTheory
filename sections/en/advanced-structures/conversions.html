Converting Between Data Structures in JavaScript

Arrays · Sets · Maps · Objects - How and when to convert between them

1️⃣ Why Convert Structures?

Because there's no perfect structure for everything.

👉 Each structure has different advantages:

Arrays → ideal for:

  • map, filter, reduce
  • sorting, iterating, rendering lists (React)

Sets → ideal for:

  • removing duplicates
  • set operations

Maps → ideal for:

  • working with key → value pairs
  • fast lookups
  • maintaining insertion order

Objects → ideal for:

  • API data (JSON)
  • simple data models
  • interoperability with libraries

📌 In practice

We constantly convert between these structures to leverage the best of each one.

2️⃣ Quick Reminder: What is a Map?

A Map is a collection of key → value pairs.


const userMap = new Map([
  ["name", "Mour"],
  ["age", 37]
]);

Characteristics:

  • Keys don't have to be strings
  • Maintains insertion order
  • Has its own methods (set, get, has, size)

3️⃣ Map → Array

Why Do It?

Because Arrays have very powerful methods like map, filter, reduce, sort.

🔸 Method 1: Array.from(map)


const userMap = new Map([
  ["name", "Mour"],
  ["age", 37]
]);

const arrayFromMap = Array.from(userMap);
console.log(arrayFromMap);
// [["name", "Mour"], ["age", 37]]

📌 Important

Each array element is a [key, value] pair.

🔸 Method 2: Spread Operator (very common)


const arrayFromMap = [...userMap];

✔️ Spread advantages:

  • Does exactly the same thing
  • Very common in modern JavaScript

🔸 Access Only Keys or Values


const keys = [...userMap.keys()];
console.log(keys);
// ["name", "age"]

const values = [...userMap.values()];
console.log(values);
// ["Mour", 37]

This is very common in real projects, especially in UI.

4️⃣ Map → Object (plain object)

Why Do It?

Because:

  • APIs work with objects
  • JSON only supports objects
  • Many libraries expect objects

🔸 Conversion with Object.fromEntries


const userMap = new Map([
  ["name", "Mour"],
  ["age", 37]
]);

const objectFromMap = Object.fromEntries(userMap);
console.log(objectFromMap);
// { name: "Mour", age: 37 }

📌 It works because:

  • Map is iterable
  • Each iteration returns [key, value]
  • Object.fromEntries expects exactly that

⚠️ Important Warning (Senior Level)

When converting to Object:

  • All keys are converted to strings
  • You can lose information

const map = new Map();
map.set(1, "number");
map.set("1", "string");

const obj = Object.fromEntries(map);
console.log(obj);
// { "1": "string" }  ❌ overwritten

👉 Don't convert to Object if you need non-string keys.

5️⃣ Object → Map

When Does It Make Sense?

When:

  • You want more flexible keys
  • You need size
  • You do many insertions/deletions
  • Insertion order matters

🔸 Step by Step Conversion


const userObject = {
  name: "Mour",
  age: 37
};

const mapFromObject = new Map(Object.entries(userObject));
console.log(mapFromObject);
// Map(2) { "name" => "Mour", "age" => 37 }

📌 Object.entries() returns:


[
  ["name", "Mour"],
  ["age", 37]
]

Exactly what new Map() needs.

6️⃣ Practical Examples (Real World)

🔹 Filter Data from a Map


const users = new Map([
  [1, { name: "Ana", active: true }],
  [2, { name: "Luis", active: false }],
  [3, { name: "María", active: true }]
]);

const activeUsers = [...users.values()].filter(u => u.active);
console.log(activeUsers);
// [{ name: "Ana", active: true }, { name: "María", active: true }]

✔️ Process:

  • Convert to array of values only
  • Apply filter

🔹 Prepare Data for UI (React)


const items = new Map([
  ["a1", { title: "Item 1" }],
  ["b2", { title: "Item 2" }]
]);

const list = [...items].map(([id, data]) => ({
  id,
  ...data
}));

console.log(list);
// [{ id: "a1", title: "Item 1" }, { id: "b2", title: "Item 2" }]

💡 Ideal for React:


list.map(item => <li key={item.id}>{item.title}</li>)

7️⃣ Relationship with Sets and Arrays (Global View)

Array → Set → Remove Duplicates


const array = [1, 2, 2, 3, 4, 4, 5];
const unique = [...new Set(array)];
console.log(unique);
// [1, 2, 3, 4, 5]

Set → Array → Use Advanced Methods


const set = new Set([1, 2, 3, 4, 5]);
const arr = [...set];

const doubled = arr.map(n => n * 2);
// [2, 4, 6, 8, 10]

Map ↔ Object → Data Model vs Collection


// Object → Map (for powerful operations)
const map = new Map(Object.entries(obj));

// Map → Object (for APIs/JSON)
const obj = Object.fromEntries(map);

Map → Array → Processing and Transformations


const map = new Map([["a", 1], ["b", 2]]);
const processed = [...map].map(([key, value]) => value * 2);
// [2, 4]

👉 The Key

Combine structures, don't choose just one.

8️⃣ Quick Conversion Table

From To Code
Map Array [...map] or Array.from(map)
Map Object Object.fromEntries(map)
Object Map new Map(Object.entries(obj))
Array Set new Set(array)
Set Array [...set] or Array.from(set)
Map keys Array [...map.keys()]
Map values Array [...map.values()]

9️⃣ Final Summary (Very Important)

Key Concepts

Arrays

  • Data processing
  • map, filter, reduce

Sets

  • Unique values
  • Set operations

Maps

  • Powerful key → value
  • Non-string keys
  • Order + performance

Objects

  • Plain data
  • APIs and JSON

🎯 A good developer knows when to convert and why.
