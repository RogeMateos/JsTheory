Array Sorting in JavaScript

sort, reverse and comparison criteria

Introduction

Sorting data is one of the most common operations in JavaScript. However, sort() has behaviors that tend to confuse, especially when working with numbers.

In this tutorial we'll go through it step by step, understanding what happens inside, why it happens, and how to do it right.

1️⃣ The Simplest Case: Sorting an Array

Let's start with an unsorted array of numbers:


const unsorted = [3, 4, 1, 6, 10];
const sorted = unsorted.sort();

console.log(sorted);

❌ Unexpected Result

[1, 10, 3, 4, 6]

At first glance it seems wrong… why does 10 come before 3?

2️⃣ Why Doesn't sort() Work Well with Numbers?

By default, sort() converts elements to string and compares them as text.

That is, it compares like this:

"1" < "10" < "3"

That's why the order is lexicographic (alphabetical), not numeric.

3️⃣ When sort() DOES Work Without Configuration

If we use strings, the default behavior makes sense:


const letters = ["B", "A", "D", "P"];
const sortedLetters = letters.sort();

console.log(sortedLetters);

✅ Correct Result

["A", "B", "D", "P"]

This confirms something important:

🔑 sort() sorts strings well, but not numbers, if we don't specify a criterion.

4️⃣ How sort() Really Works: The Comparator Function

sort() can receive a comparison function that decides the order.


array.sort((a, b) => {
  // returns a number
});

📌 Fundamental Comparator Rule

  • If it returns a negative number → a goes before b
  • If it returns 0 → they are considered equal
  • If it returns a positive number → a goes after b

5️⃣ Sorting Numbers Correctly (Ascending)

For numbers, the simplest criterion is to subtract:


const numbers = [3, 4, 1, 6, 10];

const sortedNumbers = numbers.sort((a, b) => a - b);

console.log(sortedNumbers);

✅ Result

[1, 3, 4, 6, 10]

❌ Common Error

This does NOT work well:

numbers.sort((a, b) => a < b);

Why?
Because it returns true or false, and sort() needs a number, not a boolean.

6️⃣ ⚠️ Important: sort() MUTATES the Original Array

This is key and often causes bugs.


const nums = [3, 4, 1];
const sorted = nums.sort((a, b) => a - b);

console.log(nums);    // ⚠️ already sorted
console.log(sorted); // it's the same array

⚠️ Warning

👉 sort() doesn't create a new array, it modifies the original.

7️⃣ Correct and Safe Way (Without Mutating)

If you want to keep the original array intact:


const nums = [3, 4, 1, 6, 10];

const sorted = [...nums].sort((a, b) => a - b);

console.log(nums);   // original
console.log(sorted); // sorted

💡 Important

This is fundamental in React and functional programming.

8️⃣ Descending Order

Two valid options:

Option 1: Reverse the Subtraction


const desc = [...nums].sort((a, b) => b - a);

Option 2: reverse() (⚠️ mutates)


const asc = [...nums].sort((a, b) => a - b);
asc.reverse();

9️⃣ reverse(): What It Does Exactly


const arr = [1, 2, 3];
arr.reverse();

console.log(arr);

🔁 Result

[3, 2, 1]

⚠️ Warning

reverse() also mutates the array and returns the same reference.

🔟 Real Case: Sorting Arrays of Objects

This is the most common in real applications.


const users = [
  { name: "Ana", age: 30 },
  { name: "Luis", age: 25 },
  { name: "Eva", age: 25 },
];

const byAge = [...users].sort((a, b) => a.age - b.age);

Ordering with Secondary Criterion (Tiebreaker)


const byAgeThenName = [...users].sort((a, b) => {
  if (a.age !== b.age) return a.age - b.age;
  return a.name.localeCompare(b.name);
});

1️⃣1️⃣ Strings and Accents: localeCompare

For text in Spanish:


const words = ["ñu", "nube", "árbol", "avión"];

const sorted = [...words].sort((a, b) =>
  a.localeCompare(b, "es")
);

console.log(sorted);

✅ Result

This correctly respects the alphabetical order of the language.

1️⃣2️⃣ Modern Alternative (Without Mutating): toSorted() and toReversed()

Modern JavaScript versions:


const nums = [3, 4, 1, 6, 10];

const asc = nums.toSorted((a, b) => a - b);
const desc = nums.toSorted((a, b) => b - a);

console.log(nums); // intact

💡 Recommendation

👉 Highly recommended when available.

🧠 Mental Summary (For Interviews and Daily Use)

Key Concepts

  • sort() sorts as strings by default
  • For numbers → use a comparator (a, b) => a - b
  • sort() and reverse() mutate the array
  • Use [...array] if you want safety
  • For text → localeCompare
  • For objects → compare properties
  • Modern → toSorted()
