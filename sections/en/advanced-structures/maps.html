Maps in JavaScript: Key → Value Dictionaries

Comparison with Arrays and Sets, basic operations and iteration

1️⃣ What is a Map in JavaScript?

A Map is a collection of key → value pairs.

👉 Main characteristics:

  • Keys can be of any type (strings, numbers, objects, functions)
  • Maintains insertion order
  • Has explicit methods: get, set, has, delete
  • Knows its size with .size

const myMap = new Map([
  ["name", "moure"],
  ["age", 37]
]);

console.log(myMap);
// Map { 'name' => 'moure', 'age' => 37 }

2️⃣ Array vs Set vs Map (Key Differences)

Structure Duplicates Key-value Main use
Array ✅ ❌ Lists, transformations
Set ❌ ❌ Unique values
Map ❌ ✅ Dictionaries, lookup

👉 Mental Rule

  • Array → lists and transformations
  • Set → uniqueness
  • Map → key → value relationships

3️⃣ Creating a Map

Creation Structure

A Map is created by passing an array of [key, value] pairs:


const myMap = new Map([
  ["name", "moure"],
  ["age", 37],
  ["country", "ES"]
]);

📌 Format:

  • [ … ] outer = array of elements
  • Each element is another array of 2 positions: [key, value]

Empty Map


const emptyMap = new Map();

4️⃣ Basic Map Operations

set() - Add or Update


const myMap = new Map();

myMap.set("name", "moure");
myMap.set("age", 37);
myMap.set("country", "ES");

console.log(myMap);
// Map { 'name' => 'moure', 'age' => 37, 'country' => 'ES' }

get() - Get Value


console.log(myMap.get("name")); // "moure"
console.log(myMap.get("age"));  // 37

has() - Check Existence


console.log(myMap.has("age"));     // true
console.log(myMap.has("city"));    // false

delete() - Remove


myMap.delete("age");
console.log(myMap.has("age")); // false

size - Size


console.log(myMap.size); // 2

clear() - Empty


myMap.clear();
console.log(myMap.size); // 0

5️⃣ Iteration with forEach (⚠️ VERY IMPORTANT)

⚠️ Parameter Order

In Map.forEach, the callback receives value first and then key:


myMap.forEach((value, key) => {
  console.log(`${key}: ${value}`);
});

This is the opposite of what many expect.

Complete Example


const myMap = new Map([
  ["name", "moure"],
  ["age", 37],
  ["country", "ES"]
]);

myMap.forEach((value, key) => {
  console.log(`${key}: ${value}`);
});

// name: moure
// age: 37
// country: ES

6️⃣ Iteration with for...of (Highly Recommended)

Simple Iteration


for (const [key, value] of myMap) {
  console.log(key, value);
}

// name moure
// age 37
// country ES

💡 Advantage

Here we use destructuring [key, value], very common in modern JS.

Explicit Iteration with .entries()


for (const [key, value] of myMap.entries()) {
  console.log(key, value);
}

Only Keys


for (const key of myMap.keys()) {
  console.log(key);
}

Only Values


for (const value of myMap.values()) {
  console.log(value);
}

7️⃣ Map vs Object (When to Use Each)

✔ Use Object when:

  • Your keys are simple strings
  • You want easy JSON
  • You need something quick and simple

✔ Use Map when:

  • You need keys that are NOT strings (objects, functions)
  • You want to know the size with .size
  • You'll be adding/removing a lot
  • Insertion order matters explicitly

8️⃣ Real Example: Cache by Object

Problem with Object

With objects, keys are converted to strings:


const cache = {};
const obj1 = { id: 1 };
const obj2 = { id: 2 };

cache[obj1] = "value1";
cache[obj2] = "value2";

console.log(cache);
// { '[object Object]': 'value2' }
// ❌ Both objects have the same key

Solution with Map


const cache = new Map();
const obj1 = { id: 1 };
const obj2 = { id: 2 };

cache.set(obj1, "value1");
cache.set(obj2, "value2");

console.log(cache.get(obj1)); // "value1"
console.log(cache.get(obj2)); // "value2"
// ✅ Each object maintains its own key

📌 Why It Works

Map can use objects as keys because it doesn't convert them to strings.

9️⃣ Real Example: Map ID → User


const users = [
  { id: 1, name: "Ana" },
  { id: 2, name: "Luis" },
  { id: 3, name: "María" }
];

// Create Map id → user
const userMap = new Map();

users.forEach(user => {
  userMap.set(user.id, user);
});

// Fast access by ID
console.log(userMap.get(2));
// { id: 2, name: "Luis" }

💡 Advantage

O(1) lookup instead of O(n) with array.find()

🔟 Real Example: Count Occurrences

Use a Map to count how many times each word appears:


const words = ["hello", "world", "hello", "javascript", "world", "hello"];

const wordCount = new Map();

words.forEach(word => {
  if (wordCount.has(word)) {
    wordCount.set(word, wordCount.get(word) + 1);
  } else {
    wordCount.set(word, 1);
  }
});

console.log(wordCount);
// Map { 'hello' => 3, 'world' => 2, 'javascript' => 1 }

More Elegant Version


words.forEach(word => {
  wordCount.set(word, (wordCount.get(word) || 0) + 1);
});

1️⃣1️⃣ Convert Map to Array and Vice Versa

Map → Array


const myMap = new Map([
  ["name", "moure"],
  ["age", 37]
]);

// Convert to array of pairs
const entries = [...myMap];
console.log(entries);
// [['name', 'moure'], ['age', 37]]

// Or using Array.from
const entries2 = Array.from(myMap);

Array → Map


const arr = [
  ["name", "moure"],
  ["age", 37]
];

const myMap = new Map(arr);
