Advanced Sets in JavaScript

Set operations: remove duplicates, union, intersection and difference

1. What is a Set and What is it For?

A Set in JavaScript is a collection of unique values.

👉 This means:

  • ❌ Does not allow repeated values
  • ✅ Ideal for checking if a value exists
  • ✅ Perfect for set operations (like in mathematics)

const mySet = new Set();

2. Array vs Set (Key Idea to Avoid Confusion)

Feature Array Set
Allows duplicates ✅ ❌
Has index ([0]) ✅ ❌
map/filter methods ✅ ❌
Check existence includes (slow) has (fast)
Main use Transform data Uniqueness / Sets

👉 Mental Rule

  • Array = transformation
  • Set = membership and sets

3. Create a Set from an Array (Remove Duplicates)

Real Problem

We have an array with duplicates:


const numbersArray = [2, 2, 3, 4, 5, 6];

Solution with Set


const numbersSet = new Set(numbersArray);

console.log(numbersSet);
// Set {2, 3, 4, 5, 6}

📌 Result

The Set automatically removes duplicates.

4. Convert Set Back to Array (Very Common)

We often need to continue working with an array.


const uniqueArray = [...numbersSet];

console.log(uniqueArray);
// [2, 3, 4, 5, 6]

What does the spread (...) do here?

  • "Extracts" each value from the Set
  • Places it inside a new array

Equivalent Alternative:


Array.from(numbersSet);

5. Basic Set Operations (Necessary)


const s = new Set();

s.add(1);        // add
s.has(1);        // true
s.delete(1);     // remove
s.size;          // number of elements
s.clear();       // empty

💡 Important

has is the equivalent of includes, but much more efficient.

5️⃣ Iterating a Set (Without Converting to Array)

Option 1: forEach


const numbers = new Set([2, 3, 4, 5, 6]);

numbers.forEach(n => {
  console.log(n * 2);
});
// 4, 6, 8, 10, 12

Option 2: for...of


for (const num of numbers) {
  console.log(num);
}

💡 Advantage

You don't need to convert to array to iterate through it.

6️⃣ What a Set DOESN'T Have (And Why)

⚠️ Set DOESN'T have:

  • map()
  • filter()
  • reduce()

Reason: A Set is not designed for transformations, but for uniqueness and membership.

👉 If you need to transform:

You must convert to Array first.

6. Set Operations (The Great Advantage of Sets)

Let's work with two sets:


const setA = new Set([1, 2, 3]);
const setB = new Set([2, 3, 4, 5]);

7. Union (A ∪ B)

What is it?

All elements from both sets, without duplicates.


const union = new Set([...setA, ...setB]);

console.log(union);
// Set {1, 2, 3, 4, 5}

Why it Works

  • [...] combines the values
  • new Set() automatically removes duplicates

8. Intersection (A ∩ B)

What is it?

The common elements between both sets.


const intersection = new Set(
  [...setA].filter(value => setB.has(value))
);

console.log(intersection);
// Set {2, 3}

Step by Step

  1. Convert setA to array
  2. Filter only values that exist in setB
  3. Create a new Set to maintain uniqueness

9. Difference (A − B)

What is it?

Elements that are in A but NOT in B


const difference = new Set(
  [...setA].filter(value => !setB.has(value))
);

console.log(difference);
// Set {1}

Important ⚠️

The difference doesn't return "the non-common ones",
it returns those from one set that are not in the other.

10. (Bonus) Symmetric Difference

Elements that are in one or the other, but not in both.


const symmetricDifference = new Set([
  ...[...setA].filter(x => !setB.has(x)),
  ...[...setB].filter(x => !setA.has(x))
]);

console.log(symmetricDifference);
// Set {1, 4, 5}

10️⃣ Using filter, map, reduce with Set

If you need to transform a Set, first convert it to Array.

Common Pattern:


const numbers = new Set([1, 2, 3, 4, 5, 6]);

// We want only even numbers, multiplied by 2
const result = new Set(
  [...numbers]
    .filter(n => n % 2 === 0)
    .map(n => n * 2)
);

console.log(result);
// Set {4, 8, 12}

Process:

  1. Set → Array: [...numbers]
  2. Filter: .filter(...)
  3. Transform: .map(...)
  4. Array → Set: new Set(...)

Example with reduce:


const sum = [...numbers].reduce((acc, n) => acc + n, 0);
console.log(sum); // 21

💡 Important

If the final result needs to be unique, convert it back to Set.

11. Important Cases You Should Know (Senior Level)

🔹 NaN is Unique in Set


new Set([NaN, NaN]).size; // 1

🔹 Objects are Compared by Reference


new Set([{a:1}, {a:1}]).size; // 2

⚠️ Important

Even though they "look the same", they are different objects.

12. Performance (Why Use Set)

  • array.includes(x) → O(n)
  • set.has(x) → O(1) average

👉 For frequent lookups, Set is much more efficient.

13. When to Use Set and When Array

✔ Use Set when:

  • You need uniqueness
  • Check existence quickly
  • Set operations

✔ Use Array when:

  • You need to transform data
  • Order and position matter
  • map, filter, reduce

13️⃣ Common Mistakes

❌ Mistake 1: Trying to access by index


const s = new Set([1, 2, 3]);
console.log(s[0]); // undefined ❌

✅ Solution:

Convert to array first:


const arr = [...s];
console.log(arr[0]); // 1 ✅

❌ Mistake 2: Expecting Set to filter "equal" objects


const s = new Set([
  { id: 1 },
  { id: 1 }
]);

console.log(s.size); // 2 (not 1)

⚠️ Reason:

Objects are compared by reference, not by content.

❌ Mistake 3: Using .map() directly


const s = new Set([1, 2, 3]);
s.map(x => x * 2); // ❌ TypeError

✅ Solution:


const doubled = new Set([...s].map(x => x * 2)); // ✅
