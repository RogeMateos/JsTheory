Tutorial: Async/Await in JavaScript 🚀

Introduction

Let me explain clearly how asynchrony works in JavaScript, especially async/await, which is the most modern and easy way to work with asynchronous code.

What Problem Are We Solving?

Imagine you have code that needs to wait (like calling an API, reading a file, or querying a database). JavaScript normally executes everything line by line without waiting, but sometimes we need it to wait.

Basic Example: Synchronous Code

Let's start with a normal function:

function process() {
  console.log("Start of process");
  console.log("End of process");
}

process();

Result:

Start of process
End of process

Everything executes in order, line by line. Simple, right?

The Problem: We Need to Wait

But... what happens if we need to wait 5 seconds between the start and the end? This is where async/await comes in.

The Solution: Async/Await

Step 1: Make the Function Asynchronous

To convert a normal function into an asynchronous one, you just need to add the word async before function: 

async function process() {
  console.log("Start of process");
  console.log("End of process");
}

It's already asynchronous! But it's not waiting for anything yet...

Step 2: Create Something to Wait For

First, we need to simulate an operation that takes time. We create a helper function: 

function wait(milliseconds) {
  return new Promise(resolve => {
    setTimeout(resolve, milliseconds);
  });
}

What does this do? It creates a "promise" that resolves after X milliseconds. It's like saying "wait this amount of time and then continue."

Step 3: Use await to Wait

Now yes, we use await to tell JavaScript: "Wait here!":

async function process() {
  console.log("Start of process");

  await wait(5000); // Wait 5 seconds!

  console.log("End of process - after 5 seconds");
}

process();

Result:

Start of process
(waits 5 seconds...)
End of process - after 5 seconds

More Complex Example: Multiple Waits

You can chain multiple operations with await:

async function process() {
  console.log("Start of process");

  await wait(5000);
  console.log("After 5 seconds");

  await wait(1000);
  console.log("After 1 more second");

  await wait(2000);
  console.log("After 2 more seconds");

  console.log("End of process");
}

Result:

Start of process
(waits 5 seconds)
After 5 seconds
(waits 1 second)
After 1 more second
(waits 2 seconds)
After 2 more seconds
End of process

Golden Rules 📝

  1. async converts a function into asynchronous
  2. await pauses execution until the promise completes
  3. You can only use await inside async functions
  4. Code with await looks and reads like normal code, but waits when needed!

Real Practical Example

Imagine you're calling an API:

async function getData() {
  console.log("Calling the API...");

  const response = await fetch('https://api.example.com/data');
  const data = await response.json();

  console.log("Data received:", data);
  return data;
}

Without async/await, you would have to use callbacks or .then() which are more complicated to read.

Why is async/await Better?

Before (with Promises):

fetch('url')
  .then(response => response.json())
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.error(error);
  });

Now (with async/await):

async function getData() {
  try {
    const response = await fetch('url');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

Much clearer and easier to understand! 🎉

Error Handling with try/catch

With async/await, error handling becomes much more intuitive using try/catch blocks: 

async function loadUserData(userId) {
  try {
    console.log(`Loading user ${userId}...`);

    const response = await fetch(`https://api.example.com/users/${userId}`);

    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }

    const userData = await response.json();
    console.log("User loaded:", userData);
    return userData;

  } catch (error) {
    console.error("Error loading user:", error.message);
    throw error; // Re-throw if needed
  }
}

Multiple Parallel Requests

If you have multiple independent async operations, you can run them in parallel using Promise.all(): 

async function loadMultipleUsers() {
  try {
    // These requests run in parallel, not sequentially
    const [user1, user2, user3] = await Promise.all([
      fetch('https://api.example.com/users/1').then(r => r.json()),
      fetch('https://api.example.com/users/2').then(r => r.json()),
      fetch('https://api.example.com/users/3').then(r => r.json())
    ]);

    console.log("All users loaded:", user1, user2, user3);
  } catch (error) {
    console.error("Error loading users:", error);
  }
}

Sequential vs Parallel Execution

Sequential (one after another):

async function sequential() {
  const result1 = await fetch('url1'); // Wait for this
  const result2 = await fetch('url2'); // Then wait for this
  const result3 = await fetch('url3'); // Then wait for this
  // Total time: time1 + time2 + time3
}

Parallel (all at once):

async function parallel() {
  const [result1, result2, result3] = await Promise.all([
    fetch('url1'),
    fetch('url2'),
    fetch('url3')
  ]);
  // Total time: max(time1, time2, time3)
}

Async/Await with Loops

You can use async/await inside loops:

async function processItems(items) {
  for (const item of items) {
    // Process each item sequentially
    const result = await processItem(item);
    console.log(`Processed ${item}:`, result);
  }
  console.log("All items processed!");
}

// Or process all items in parallel
async function processItemsParallel(items) {
  const results = await Promise.all(
    items.map(item => processItem(item))
  );
  console.log("All results:", results);
}

Key Points to Remember 🎯

  • async functions always return a Promise
  • await can only be used inside async functions
  • async/await makes asynchronous code look synchronous
  • Use try/catch for error handling
  • Use Promise.all() for parallel operations
  • Be careful with loops - understand sequential vs parallel execution

Common Mistakes to Avoid ❌

  1. Using await outside async functions 
    // ❌ Wrong
function getData() {
  const data = await fetch('url'); // Error!
}

// ✅ Correct
async function getData() {
  const data = await fetch('url');
}
  2. Forgetting to use await 
    // ❌ Wrong - returns a Promise, not the data
async function getData() {
  const data = fetch('url'); // Missing await!
  console.log(data); // Promise object, not data
}

// ✅ Correct
async function getData() {
  const data = await fetch('url');
  console.log(data); // Actual data
}
  3. Not handling errors 
    // ❌ Wrong - errors not handled
async function getData() {
  const data = await fetch('url');
}

// ✅ Correct
async function getData() {
  try {
    const data = await fetch('url');
  } catch (error) {
    console.error(error);
  }
}

Final Summary

async/await is like giving your functions superpowers to wait without blocking the entire program. It's the most modern, clean, and easy way to work with asynchronous code in JavaScript.
