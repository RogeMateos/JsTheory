The Two Sides of a Promise

Understanding the producer and consumer sides

Introduction

Think of a promise as a contract between two parties:

🏭 Side 1: THE ONE WHO CREATES the promise (The Producer)

const myPromise = new Promise((resolve, reject) => {
  // INSIDE here I am CREATING the promise
  // I decide what happens

  setTimeout(() => {
    const successful = true;

    if (successful) {
      resolve("It worked!"); // I notify it went well
    } else {
      reject("Error!"); // I notify it went wrong
    }
  }, 2000);
});

🛍️ Side 2: THE ONE WHO USES the promise (The Consumer)

myPromise
  .then((result) => {
    // Here I RECEIVE the notification it went well
    console.log(result);
  })
  .catch((error) => {
    // Here I RECEIVE the notification it went wrong
    console.log(error);
  })
  .finally(() => {
    // This ALWAYS executes
    console.log("Finished waiting");
  });

📝 Analogy: Food Order

Let me explain it with a real-world example:

👨‍🍳 THE RESTAURANT (Creates the promise)

function prepareFood(dish) {
  // The restaurant CREATES a promise
  return new Promise((resolve, reject) => {
    console.log(`Cooking ${dish}...`);

    setTimeout(() => {
      const ingredientsAvailable = true;

      if (ingredientsAvailable) {
        // The chef NOTIFIES it's ready
        resolve(`Your ${dish} is ready! 🍽️`);
      } else {
        // The chef NOTIFIES there's a problem
        reject(`We don't have ingredients for ${dish} 😞`);
      }
    }, 3000);
  });
}

On this side:

  • resolve = "✅ It's ready, here's your food"
  • reject = "❌ Sorry, we couldn't make it"

🙋‍♂️ THE CLIENT (Uses the promise)

prepareFood("pizza")
  .then((message) => {
    // The client RECEIVES the good news
    console.log(message); // "Your pizza is ready! 🍽️"
    console.log("Time to eat!");
  })
  .catch((error) => {
    // The client RECEIVES the bad news
    console.log(error);
    console.log("I'll have to order something else...");
  })
  .finally(() => {
    // Whatever happens, the client does this
    console.log("Thanks for the service");
  });

On this side:

  • .then() = "I receive my food and I'm happy"
  • .catch() = "I was notified there was a problem"
  • .finally() = "Either way, I thank the service"

🔄 Step by Step: Complete Flow

// STEP 1: Create the promise
function doSomething() {
  console.log("🏭 CREATING the promise...");

  return new Promise((resolve, reject) => {
    console.log("⏳ Working in the background...");

    setTimeout(() => {
      const randomNumber = Math.random();

      if (randomNumber > 0.5) {
        console.log("✅ RESOLVING the promise");
        resolve("Success! Number: " + randomNumber);
      } else {
        console.log("❌ REJECTING the promise");
        reject("Error! Number too low: " + randomNumber);
      }
    }, 2000);
  });
}

// STEP 2: Use the promise
console.log("🛍️ USING the promise...");

doSomething()
  .then((result) => {
    console.log("😊 RECEIVED success:", result);
  })
  .catch((error) => {
    console.log("😢 RECEIVED error:", error);
  })
  .finally(() => {
    console.log("🏁 FINISHED waiting");
  });

console.log("🚀 Synchronous code continues...");

📊 Output if it goes WELL (number > 0.5):

🛍️ USING the promise...
🏭 CREATING the promise...
⏳ Working in the background...
🚀 Synchronous code continues...
✅ RESOLVING the promise
😊 RECEIVED success: Success! Number: 0.7234
🏁 FINISHED waiting

📊 Output if it goes WRONG (number < 0.5):

🛍️ USING the promise...
🏭 CREATING the promise...

🚀 Synchronous code continues...
❌ REJECTING the promise
😢 RECEIVED error: Error! Number too low: 0.3421
🏁 FINISHED waiting

🎯 Direct Comparison

Inside new Promise Outside with .then/.catch
I CREATE the promise I USE the promise
I DECIDE what happens I WAIT to be notified
I call resolve() when it goes well I write .then() to receive success
I call reject() when it goes wrong I write .catch() to receive error
I am the PRODUCER I am the CONSUMER

🔗 Example with Both Sides Clear

// ============================================
// 🏭 PRODUCER SIDE: Create the promise
// ============================================
function verifyAge(age) {
  return new Promise((resolve, reject) => {
    console.log("Verifying age...");

    setTimeout(() => {
      if (age >= 18) {
        // I (producer) notify EVERYTHING'S FINE
        resolve({
          message: "Access granted",
          adult: true
        });
      } else {
        // I (producer) notify THERE'S A PROBLEM
        reject({
          message: "You are underage",
          adult: false
        });
      }
    }, 1000);
  });
}

// ============================================
// 🛍️ CONSUMER SIDE: Use the promise
// ============================================
verifyAge(20)
  .then((response) => {
    // I (consumer) receive the good news
    console.log("✅", response.message);
    console.log("You can enter the site");
  })
  .catch((response) => {
    // I (consumer) receive the bad news
    console.log("❌", response.message);
    console.log("You cannot enter");
  })
  .finally(() => {
    // I (consumer) do cleanup
    console.log("Verification completed");
  });

💡 Final Summary

  1. resolve and reject = Are INSIDE the promise. You call them to notify what happened
  2. .then() and .catch() = Are OUTSIDE the promise. You use them to receive the news
  3. They are complementary: One creates, the other consumes
  4. They always work together:
    • If you call resolve() → .then() executes
    • If you call reject() → .catch() executes
