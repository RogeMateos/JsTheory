JavaScript Promises Tutorial 🚀

What is a Promise?

A promise is an object that represents a value that may be available now, in the future, or never. It's like ordering food delivery: when you place the order, you get a "promise" that your food will arrive, but you don't have it yet.

Promise States

A promise can be in three states:

  1. Pending: The operation hasn't completed yet
  2. Fulfilled: The operation completed successfully
  3. Rejected: The operation failed

Creating Your First Promise

const myFirstPromise = new Promise((resolve, reject) => {
  // Simulate an operation that takes 2 seconds
  setTimeout(() => {
    const successful = true;

    if (successful) {
      resolve("Operation successful!"); // Everything went well
    } else {
      reject("An error occurred"); // Something failed
    }
  }, 2000);
});

Consuming a Promise

To work with a promise's result, we use .then(), .catch() and .finally(): 

myFirstPromise
  .then((result) => {
    console.log(result); // Executes if the promise resolves
  })
  .catch((error) => {
    console.log(error); // Executes if the promise is rejected
  })
  .finally(() => {
    console.log("This always executes"); // Executes regardless of result
  });

Practical Example: Pizza Order 🍕

function orderPizza(type) {
  return new Promise((resolve, reject) => {
    console.log(`Preparing your ${type} pizza...`);

    setTimeout(() => {
      const availablePizzas = ['pepperoni', 'margherita', 'hawaiian'];

      if (availablePizzas.includes(type)) {
        resolve(`Your ${type} pizza is ready! 🍕`);
      } else {
        reject(`Sorry, we don't have ${type} pizza 😢`);
      }
    }, 3000);
  });
}

// Using the promise
orderPizza('pepperoni')
  .then((message) => {
    console.log(message); // Your pepperoni pizza is ready! 🍕
  })
  .catch((error) => {
    console.log(error);
  });

Chaining Promises

One of the great advantages of promises is that we can chain them easily: 

function step1() {
  return new Promise((resolve) => {
    setTimeout(() => {
      console.log("Step 1 completed");
      resolve();
    }, 1000);
  });
}

function step2() {
  return new Promise((resolve) => {
    setTimeout(() => {
      console.log("Step 2 completed");
      resolve();
    }, 1000);
  });
}

function step3() {
  return new Promise((resolve) => {
    setTimeout(() => {
      console.log("Step 3 completed");
      resolve();
    }, 1000);
  });
}

// Chaining the promises
step1()
  .then(() => step2())
  .then(() => step3())
  .then(() => {
    console.log("All steps completed! 🎉");
  });

Output:

Step 1 completed
Step 2 completed
Step 3 completed
All steps completed! 🎉

Real Example: Loading User Data

function loadUser(id) {
  return new Promise((resolve, reject) => {
    console.log(`Searching for user ${id}...`);

    setTimeout(() => {
      const users = {
        1: { name: 'Ana', age: 25 },
        2: { name: 'Carlos', age: 30 },
        3: { name: 'Maria', age: 28 }
      };

      if (users[id]) {
        resolve(users[id]);
      } else {
        reject('User not found');
      }
    }, 2000);
  });
}

function loadOrders(user) {
  return new Promise((resolve) => {
    console.log(`Loading orders for ${user.name}...`);

    setTimeout(() => {
      resolve([
        { product: 'Laptop', price: 1200 },
        { product: 'Mouse', price: 25 }
      ]);
    }, 1500);
  });
}

// Chaining operations
loadUser(1)
  .then((user) => {
    console.log(`User found: ${user.name}`);
    return loadOrders(user);
  })
  .then((orders) => {
    console.log('Orders:', orders);
  })
  .catch((error) => {
    console.log('Error:', error);
  });

❌ Callback Hell vs ✅ Promises

Before (Callback Hell):

operation1(function(result1) {
  operation2(result1, function(result2) {
    operation3(result2, function(result3) {
      operation4(result3, function(result4) {
        // This is hard to read! 😵
      });
    });
  });
});

Now (With Promises):

operation1()
  .then(result1 => operation2(result1))
  .then(result2 => operation3(result2))
  .then(result3 => operation4(result3))
  .then(result4 => {
    // Much cleaner! 😊
  })
  .catch(error => console.log(error));

The Two Sides of a Promise

Think of a promise as a contract between two parties:

🏭 Side 1: THE CREATOR of the promise (The Producer)

const myPromise = new Promise((resolve, reject) => {
  // INSIDE here I'm CREATING the promise
  // I decide what happens

  setTimeout(() => {
    const successful = true;

    if (successful) {
      resolve("It worked!"); // I notify it went well
    } else {
      reject("Error!"); // I notify it went wrong
    }
  }, 2000);
});

🛍️ Side 2: THE USER of the promise (The Consumer)

myPromise
  .then((result) => {
    // Here I RECEIVE the notification it went well
    console.log(result);
  })
  .catch((error) => {
    // Here I RECEIVE the notification it went wrong
    console.log(error);
  })
  .finally(() => {
    // This ALWAYS executes
    console.log("Finished waiting");
  });

📝 Analogy: Food Order

Let me explain it with a real-world example:

👨‍🍳 THE RESTAURANT (Creates the promise)

function prepareFood(dish) {
  // The restaurant CREATES a promise
  return new Promise((resolve, reject) => {
    console.log(`Cooking ${dish}...`);

    setTimeout(() => {
      const ingredientsAvailable = true;

      if (ingredientsAvailable) {
        // The chef NOTIFIES it's ready
        resolve(`Your ${dish} is ready! 🍽️`);
      } else {
        // The chef NOTIFIES there's a problem
        reject(`We don't have ingredients for ${dish} 😞`);
      }
    }, 3000);
  });
}

On this side:

  • resolve = "✅ It's ready, here's your food"
  • reject = "❌ Sorry, we couldn't make it"

🙋‍♂️ THE CLIENT (Uses the promise)

prepareFood("pizza")
  .then((message) => {
    // The client RECEIVES the good news
    console.log(message); // "Your pizza is ready! 🍽️"
    console.log("Time to eat!");
  })
  .catch((error) => {
    // The client RECEIVES the bad news
    console.log(error);
    console.log("I'll have to order something else...");
  })
  .finally(() => {
    // Whatever happens, the client does this
    console.log("Thanks for the service");
  });

On this side:

  • .then() = "I receive my food and I'm happy"
  • .catch() = "I was notified there was a problem"
  • .finally() = "Either way, I thank the service"

🔄 Step by Step: Complete Flow

// STEP 1: Create the promise
function doSomething() {
  console.log("🏭 CREATING the promise...");

  return new Promise((resolve, reject) => {
    console.log("⏳ Working in the background...");

    setTimeout(() => {
      const randomNumber = Math.random();

      if (randomNumber > 0.5) {
        console.log("✅ RESOLVING the promise");
        resolve("Success! Number: " + randomNumber);
      } else {
        console.log("❌ REJECTING the promise");
        reject("Error! Number too low: " + randomNumber);
      }
    }, 2000);
  });
}

// STEP 2: Use the promise
console.log("🛍️ USING the promise...");

doSomething()
  .then((result) => {
    console.log("😊 RECEIVED success:", result);
  })
  .catch((error) => {
    console.log("😢 RECEIVED error:", error);
  })
  .finally(() => {
    console.log("🏁 FINISHED waiting");
  });

console.log("🚀 Synchronous code continues...");

🚀 Synchronous code continues...

🏁 FINISHED waiting

🎯 Direct Comparison

Inside new Promise Outside with .then/.catch
I CREATE the promise I USE the promise
I DECIDE what happens I WAIT to be notified
I call resolve() when it goes well I write .then() to receive success
I call reject() when it goes wrong I write .catch() to receive error
I am the PRODUCER I am the CONSUMER

🔗 Example with Both Sides Clear

// ============================================
// 🏭 PRODUCER SIDE: Create the promise
// ============================================
function verifyAge(age) {
  return new Promise((resolve, reject) => {
    console.log("Verifying age...");

    setTimeout(() => {
      if (age >= 18) {
        // I (producer) notify EVERYTHING'S FINE
        resolve({
          message: "Access granted",
          adult: true
        });
      } else {
        // I (producer) notify THERE'S A PROBLEM
        reject({
          message: "You are underage",
          adult: false
        });
      }
    }, 1000);
  });
}

// ============================================
// 🛍️ CONSUMER SIDE: Use the promise
// ============================================
verifyAge(20)
  .then((response) => {
    // I (consumer) receive the good news
    console.log("✅", response.message);
    console.log("You can enter the site");
  })
  .catch((response) => {
    // I (consumer) receive the bad news
    console.log("❌", response.message);
    console.log("You cannot enter");
  })
  .finally(() => {
    // I (consumer) do cleanup
    console.log("Verification completed");
  });

Key Points 🎯

  1. Promises are asynchronous: Code continues executing while they wait
  2. Use .then() for success: Handle the case when everything goes well
  3. Use .catch() for errors: Catch any error that occurs
  4. .finally() always executes: Useful for resource cleanup
  5. Promises can be chained: Avoid callback hell

💡 Final Summary

  1. resolve and reject = Are INSIDE the promise. You call them to notify what happened
  2. .then() and .catch() = Are OUTSIDE the promise. You use them to receive the news
  3. They are complementary: One creates, the other consumes
  4. They always work together:
    • If you call resolve() → .then() executes
    • If you call reject() → .catch() executes

Practical Exercise 💪

Try creating a function that simulates downloading a file:

function downloadFile(fileName) {
  return new Promise((resolve, reject) => {
    console.log(`Downloading ${fileName}...`);

    setTimeout(() => {
      const success = Math.random() > 0.3; // 70% success rate

      if (success) {
        resolve(`${fileName} downloaded successfully ✓`);
      } else {
        reject(`Error downloading ${fileName} ✗`);
      }
    }, 2000);
  });
}

// Try it!
downloadFile('document.pdf')
  .then(message => console.log(message))
  .catch(error => console.log(error));
