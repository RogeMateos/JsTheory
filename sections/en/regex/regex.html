Regular Expressions (RegEx) in JavaScript

Complete guide to search and validate text patterns

What is a Regular Expression?

A regular expression (regex) is a pattern used to search, validate, or extract information from text. It's like an advanced search with superpowers.

Step 1: Literal regex + test()

The most common way to define a regex is with slashes /pattern/:

const regex = /ABC/;
const text = "Hello, ABC JavaScript";

console.log(regex.test(text)); // true
console.log(/ABCD/.test(text)); // false
console.log(/AB/.test(text));   // true

💡 Key idea: .test() only answers: "is there a match? yes/no".

Step 2: RegExp Constructor (when to use it)

There are two ways to create regular expressions:

1. Literal (with slashes) - Most common

const regex = /ABC/;

2. RegExp Constructor - When the pattern is dynamic

const pattern = "ABC";
const regex2 = new RegExp(pattern);

console.log(regex2.test("Hello, ABC JavaScript")); // true

📌 When to use new RegExp():

  • When the pattern comes from a variable or configuration
  • When you need to build the pattern dynamically

⚠️ Important with RegExp constructor:

You must escape backslashes twice:

const digits = "\\d+";  // note the double backslash
const regex = new RegExp(digits);

Step 3: Character classes (\d) and quantifiers (+)

Important difference:

  • \d = "a digit" (0-9)
  • d = "the letter d"
const text2 = "My age is 37";

console.log(/\d/.test(text2));   // true (there's some digit)
console.log(/\d+/.test(text2));  // true (there's a sequence of digits)

What changes with +?

  • /\d/ → "there's at least 1 digit"
  • /\d+/ → "there's a sequence of 1 or more digits"

Extract what was found with .match()

console.log(text2.match(/\d+/)); // ["37"]

Step 4: Ranges with brackets [ ]

Brackets define a set of allowed characters:

const text3 = "My age is 37";

console.log(/[0-2]/.test(text3)); // false (no 0,1,2)
console.log(/[3-6]/.test(text3)); // true  (there's a 3)
console.log(/[4-6]/.test(text3)); // false (no 4,5,6)

Important: [3-6] means "a character that is 3, 4, 5, or 6".

Step 5: Anchors (^ start, $ end)

⚠️ Be careful with ^: it has two different meanings

  • Outside [ ] → ^ is start-of-string anchor
  • Inside [ ] (at the beginning) → ^ means negation

^ as start anchor

console.log(/^\d/.test("37 years")); // true (starts with digit)
console.log(/^\d/.test("Age 37")); // false (doesn't start with digit)

$ as end anchor

console.log(/\d$/.test("Age 37")); // true (ends with digit)
console.log(/\d$/.test("37 years")); // false (doesn't end with digit)

^ inside [ ] as negation

console.log(/[^0-2]/.test("012")); // false (all are 0,1,2)
console.log(/[^0-2]/.test("013")); // true (there's a 3, which is NOT 0,1,2)

Step 6: The typical "trap" with flags (g) and .test()

⚠️ Senior note (very important):

With flag g, a regex maintains state with lastIndex and .test() can alternate true/false if you reuse it.

const r = /\d/g;
const s = "a1b2";

console.log(r.test(s)); // true
console.log(r.test(s)); // true
console.log(r.test(s)); // false  <-- because lastIndex advanced and reached the end
console.log(r.test(s)); // true   <-- starts over

📌 Recommendation:

  • For .test(), avoid g at first
  • Use g when you want "all matches" with .match()
console.log("a1b2".match(/\d/g)); // ["1","2"]

Main methods with RegEx

1. .test() - Returns boolean

const regex = /\d+/;
console.log(regex.test("There are 5 apples")); // true

2. .match() - Returns array or null

const text = "Order 12, box 7, batch 301";
console.log(text.match(/\d+/g)); // ["12", "7", "301"]

3. .replace() - Replaces matches

const text = "Hello    world    JS";
const cleaned = text.replace(/\s+/g, " ");
console.log(cleaned); // "Hello world JS"

4. .exec() - Match with groups (useful in loops with g)

const regex = /\d+/g;
const text = "a1b2c3";
let match;

while ((match = regex.exec(text)) !== null) {
  console.log(`Found: ${match[0]} at index ${match.index}`);
}
// Found: 1 at index 1
// Found: 2 at index 3
// Found: 3 at index 5

Practical use cases

1. Validate only numbers

function isNumber(str) {
  return /^\d+$/.test(str);
}

console.log(isNumber("123"));    // true
console.log(isNumber("12a3"));   // false
console.log(isNumber(""));       // false

2. Extract numbers from text

const input = "Total: 149€";
const amount = input.match(/\d+/)?.[0];
console.log(amount); // "149"

3. Validate email (simple)

function isSimpleEmail(email) {
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
}

console.log(isSimpleEmail("user@example.com")); // true
console.log(isSimpleEmail("user@"));            // false

⚠️ Important warning:

Regex is not for validating everything 100% (perfect emails are very complex). Use it for reasonable rules, not for critical security validations.

4. Clean multiple spaces

const text = "Hello     world    JS";
const cleaned = text.replace(/\s+/g, " ").trim();
console.log(cleaned); // "Hello world JS"

Most common character classes

Pattern Meaning Example
\d Digit (0-9) /\d+/ matches "123"
\w Word (a-z, A-Z, 0-9, _) /\w+/ matches "hello_123"
\s Whitespace /\s+/ matches " "
\D NOT digit /\D+/ matches "abc"
\W NOT word /\W+/ matches "!@#"
\S NOT whitespace /\S+/ matches "text"
. Any character (except \n) /a.c/ matches "abc", "a*c"

Quantifiers

Pattern Meaning Example
+ One or more times /\d+/ matches "123"
* Zero or more times /\d*/ matches "", "123"
? Zero or one time (optional) /colou?r/ matches "color", "colour"
{n} Exactly n times /\d{3}/ matches "123"
{n,} n or more times /\d{2,}/ matches "12", "123"
{n,m} Between n and m times /\d{2,4}/ matches "12", "123", "1234"

Flags (modifiers)

Flag Meaning Example
g Global (all matches) /\d/g
i Case insensitive /abc/i matches "ABC"
m Multiline (^ and $ per line) /^test/m

Practical exercises 💪

  1. Write a regex that detects if a string starts with "Hello"
  2. Extract all numbers from: "Order 12, box 7, batch 301"
  3. Check if a string is only digits (hint: ^ and $ + \d+)
  4. Replace multiple spaces with one in: "Hello world JS"
  5. Validate a phone number with format: 123-456-7890

Solutions

// 1. Starts with "Hello"
console.log(/^Hello/.test("Hello world")); // true

// 2. Extract all numbers
console.log("Order 12, box 7, batch 301".match(/\d+/g)); // ["12", "7", "301"]

// 3. Only digits
console.log(/^\d+$/.test("12345")); // true
console.log(/^\d+$/.test("123a5")); // false

// 4. Clean multiple spaces
console.log("Hello    world    JS".replace(/\s+/g, " ")); // "Hello world JS"

// 5. Validate phone
console.log(/^\d{3}-\d{3}-\d{4}$/.test("123-456-7890")); // true

Common mistakes

  • ❌ Confusing \d with d
  • ❌ Forgetting to escape special characters: . → \.
  • ❌ Using g with .test() without knowing about lastIndex
  • ❌ Not using ^ and $ for exact validations
  • ❌ Confusing ^ outside [ ] with ^ inside [ ]

✅ Summary

  • Regex are defined with /pattern/ or new RegExp()
  • .test() returns boolean, .match() returns array
  • \d, \w, \s are character classes
  • +, *, ? are quantifiers
  • ^ and $ are start/end anchors
  • Flag g with .test() maintains state (beware)
  • Use regex for reasonable rules, not for everything
