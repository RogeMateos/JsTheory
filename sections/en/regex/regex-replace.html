Tutorial: replace and Regular Expressions in JavaScript

Understanding text replacement with regex

🎯 Chapter objective

Understand how replace works, how it combines with regular expressions, and why sometimes it only replaces one match even though the regex seems to find several.

This is one of those points where many people get confused, so let's go slowly with clear examples.

1️⃣ What is replace?

replace is a method of strings, not of regular expressions.

Its job is:

Search for a match within a text and replace it with another value.

Basic syntax

text.replace(search, replacement)
  • search → can be a string or a RegExp
  • replacement → a string or a function

2️⃣ replace using a string literal

When you know exactly what text you want to change:

const text = "Hello, JavaScript";
const result = text.replace("JavaScript", "JS");

console.log(result);
// "Hello, JS"

📌 Important:

  • Only replaces the first match
  • Doesn't understand patterns, only exact text

3️⃣ replace using a regular expression

When you want to search for patterns, not fixed text:

const text = "Hello, JavaScript";
const result = text.replace(/JavaScript/, "JS");

console.log(result);
// "Hello, JS"

So far it looks the same, but now we have much more power.

4️⃣ First common error: ❌ "Why does it only replace one?"

Typical example:

const text = "I'm counting 1 2 3 4 5";

const result = text.replace(/\d/, "Number");
console.log(result);
// "I'm counting Number 2 3 4 5"

👉 The regex works, it finds a number…
👉 But replace only replaces the first match.

This is not a regex problem.

It's the default behavior of replace.

5️⃣ The g flag: global replacement

If you want all matches to be replaced, you need the g flag.

const text = "I'm counting 1 2 3 4 5";

const result = text.replace(/\d/g, "Number");
console.log(result);
// "I'm counting Number Number Number Number Number"

🧠 Key mental rule:

  • Without g → first match
  • With g → all matches

6️⃣ Quantifiers (+) ≠ global search

This is where confusion often comes.

/\d+/   // one or more consecutive digits

This doesn't mean "find all numbers in the text".

Example:

const text = "I have 12 dogs and 300 cats";

console.log(text.replace(/\d+/, "NUM"));
// "I have NUM dogs and 300 cats"

Why?

  • \d+ defines what a match is
  • g defines how many matches to search for

✅ Correct version:

console.log(text.replace(/\d+/g, "NUM"));
// "I have NUM dogs and NUM cats"

7️⃣ Greedy (+) vs Global (g) — clear difference

Concept What it controls
+ / * / {} How much text a match captures
g How many matches are searched in the string

👉 They are different and complementary things.

8️⃣ What about replaceAll?

replaceAll exists, but has clear rules.

Works with strings

"1 2 3".replaceAll("1", "X");

With regex REQUIRES g

"1 2 3".replaceAll(/\d/g, "X"); // ✅
"1 2 3".replaceAll(/\d/, "X");  // ❌ TypeError

📌 If you use regex, better keep using replace + g.

9️⃣ Advanced replacement: using a function

Here we level up 🚀

const text = "I'm counting 1 2 3";

const result = text.replace(/\d/g, (match) => {
  return `Number(${match})`;
});

console.log(result);
// "I'm counting Number(1) Number(2) Number(3)"

👉 match is the exact value the regex found.

This is widely used for:

  • formatting data
  • normalizing texts
  • dynamically transforming values

More advanced example: convert to uppercase

const text = "hello world js";

const result = text.replace(/\b\w/g, (match) => {
  return match.toUpperCase();
});

console.log(result);
// "Hello World Js"

Example: format numbers

const text = "Price: 1000 EUR";

const result = text.replace(/\d+/g, (match) => {
  return parseInt(match).toLocaleString();
});

console.log(result);
// "Price: 1,000 EUR"

🔟 Final summary (to fix it well)

  • replace is a String method
  • Accepts strings or regex
  • Without g → only replaces the first match
  • g makes the search global
  • Quantifiers (+, *) don't replace g
  • replaceAll with regex requires g

🧠 Quick exercise (recommended)

Convert:

"Price: 20€, discount: 5€, total: 15€"

To:

"Price: X€, discount: X€, total: X€"

👉 Hint: \d+ + g in regex

Solution:

const text = "Price: 20€, discount: 5€, total: 15€";
const result = text.replace(/\d+/g, "X");
console.log(result);
// "Price: X€, discount: X€, total: X€"

Additional exercises 💪

  1. Replace all multiple spaces with a single one
  2. Convert "hello world" to "Hello World" (first letter uppercase)
  3. Replace all numbers with their value multiplied by 2
  4. Remove all special symbols from a text

Solutions

// 1. Replace multiple spaces
"Hello    world    JS".replace(/\s+/g, " ");
// "Hello world JS"

// 2. First letter uppercase
"hello world".replace(/\b\w/g, m => m.toUpperCase());
// "Hello World"

// 3. Numbers multiplied by 2
"I have 5 apples and 3 oranges".replace(/\d+/g, m => parseInt(m) * 2);
// "I have 10 apples and 6 oranges"

// 4. Remove special symbols
"Hello! How are you? #JavaScript".replace(/[^\w\s]/g, "");
// "Hello How are you JavaScript"

Common mistakes

  • ❌ Forgetting the g flag when you want to replace all matches
  • ❌ Confusing quantifiers (+) with global search (g)
  • ❌ Using replaceAll with regex without g
  • ❌ Not validating that replace returns a new string (doesn't modify the original)

✅ Key points

  • replace doesn't modify the original string, returns a new one
  • The g flag is essential for multiple replacements
  • You can use functions for complex transformations
  • Quantifiers control the size of each match
  • The g flag controls how many matches are searched
