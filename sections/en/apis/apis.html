APIs

What is an API?

An API (Application Programming Interface) is a communication interface that allows one application to talk to another in a controlled, secure, and predictable way.

Simply put:
👉 an API is a contract that defines how to request something and what you'll receive in return, without needing to know how the system behind it is built.

Why do we need APIs?

When we develop an application (web, mobile, desktop, video games, etc.), we almost always need to interact with external systems, for example:

  • A backend that manages users
  • A remote server
  • A payment service
  • A data provider
  • An AI service like ChatGPT

The problem is that we can't talk directly "raw" with those systems. Each one can be built with different languages, technologies, and architectures.

This is where the API comes in.

The API as a contract

An API acts as a communication contract between two parties:

  • 🟦 Client (frontend, mobile app, etc.)
  • 🟥 Server / external system

This contract defines, for example:

  • What actions I can perform
  • What data I need to send
  • In what format
  • What response I will receive
  • What errors can occur

Thanks to this contract:

  • ✅ The client doesn't need to know how the system works internally
  • ✅ The server controls what it exposes and how

Security and standardization

APIs exist so that communication is:

  • Secure → access control, authentication, permissions
  • Consistent → always responds in the same way
  • Predictable → you know what to expect if you make a correct or incorrect request

In most modern cases, this communication is done using common standards (like HTTP and JSON), which allows applications written in different technologies to understand each other without problems.

Practical example

Imagine that your application needs user data.

Instead of saying:

"Server, give me the user data"

The API defines something like:

  • What request you must make
  • What data to send
  • What format you will receive

If you follow that contract, the server returns the information.
If not, the request fails.

APIs in everyday life

When an application:

  • Gets data from a backend
  • Consumes external services
  • Connects with third-party platforms
  • Integrates advanced functionalities (like AI)

👉 It's using an API, even though we often don't notice it.

💡 Key idea of this lesson

An API is not the system itself,
it's the official and controlled way to communicate with it.

If this didn't exist, integrating modern applications would be practically impossible.
