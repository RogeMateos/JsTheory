Fetch from Scratch - Part 2

Load data and render elements dynamically in the DOM

🎯 What We'll Learn

In this part we'll see

How to load data with fetch and display it dynamically on the page.

This is the pattern that React, Vue, Angular and Next.js use internally:

  1. Request data with fetch
  2. Transform it
  3. Render the UI dynamically

1️⃣ What is fetch? (Quick Review)

fetch() is a JavaScript function

It allows you to request data from a server or file.

It works asynchronously, meaning the browser can keep running while data arrives.

Basic example

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {
    console.log('Jobs obtained:', jobs.length)
  })

What happens here?

  1. fetch('./data.json') - Makes a request to the file
  2. response.json() - Converts the response into usable JSON in JavaScript
  3. jobs - Now we have an array of jobs

<div class="jobs-listings">

4️⃣ Create HTML Elements Dynamically

Complete code

const container = document.querySelector('.jobs-listings')

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {

    jobs.forEach((job) => {

      const article = document.createElement('article')

      article.className = 'job-listing-card'

      article.dataset.modalidad = job.data.modalidad
      article.dataset.nivel = job.data.nivel
      article.dataset.technology = job.data.technology

      article.innerHTML = `
        <div>
          <h3>${job.titulo}</h3>
          <small>${job.empresa} | ${job.ubicacion}</small>
          <p>${job.descripcion}</p>
        </div>
        <button class="button-apply-job">Apply</button>
      `

      container.appendChild(article)
    })

  })

5️⃣ Step by Step: What Does This Code Do?

1️⃣ Loop through all jobs

jobs.forEach((job) => {})

Each job is an object from the JSON.

2️⃣ Create an HTML element

const article = document.createElement('article')

This dynamically creates: <article></article>

3️⃣ Add a CSS class

article.className = 'job-listing-card'

In HTML it looks like: <article class="job-listing-card"></article>

This allows us to apply CSS styles.

4️⃣ Add data-* attributes

article.dataset.modalidad = job.data.modalidad
article.dataset.nivel = job.data.nivel
article.dataset.technology = job.data.technology

This generates in the HTML:

<article data-modalidad="remote" data-nivel="mid" data-technology="react">

These attributes are very useful for filters.

5️⃣ Insert HTML content

article.innerHTML = `
  <h3>${job.titulo}</h3>
  <p>${job.descripcion}</p>
`

innerHTML allows us to insert HTML inside the element using template strings.

6️⃣ Add the element to the DOM

container.appendChild(article)

This makes the element appear on the page.

6️⃣ Improve Experience: Loading State

HTML - Show a message while loading data

<p id="jobs-loading">Loading jobs...</p>
<div class="jobs-listings"></div>

JavaScript - Select and hide the element after loading

const loading = document.querySelector('#jobs-loading')

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {
    // When data finishes loading, remove the message
    if (loading) loading.remove()

    // Rest of the code...
  })

What happens?

  1. At first: "Loading jobs..." is shown
  2. When data arrives, loading.remove() deletes it
  3. Jobs appear in the container

7️⃣ Handle Errors

If something goes wrong, show a message

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {
    if (loading) loading.remove()
    // Show jobs...
  })
  .catch((error) => {
    // If it fails, change the message
    if (loading) {
      loading.textContent = 'Could not load jobs'
    }
    console.error(error)
  })

Possible errors

  • File not found (404)
  • Network error
  • Invalid JSON
  • Server not responding

With .catch() we capture them all.

8️⃣ Special Case: No Jobs Available

Check if the array is empty

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {

    if (loading) loading.remove()

    // If there are no jobs
    if (jobs.length === 0) {
      container.innerHTML = '<p>No jobs available right now.</p>'
      return
    }

    // If there are jobs, show them
    jobs.forEach((job) => {
      // ... create elements ...
    })

  })

Why is this important?

It improves user experience. We don't want them to see an empty page without knowing what's happening.

9️⃣ Complete Program Flow

The process step by step


fetch data (./data.json)
      ↓
convert to JSON (.json())
      ↓
loop through array (.forEach())
      ↓
create HTML elements (createElement)
      ↓
insert them in the DOM (appendChild)
      ↓
Page updated

This is what React, Vue, Angular do internally

The only difference is that these frameworks optimize the process.

🔟 Final Simplified Code

Clean and functional version

const container = document.querySelector('.jobs-listings')
const loading = document.querySelector('#jobs-loading')

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {

    // Remove the loading message
    if (loading) loading.remove()

    // Check if there are jobs
    if (jobs.length === 0) {
      container.innerHTML = '<p>No jobs available</p>'
      return
    }

    // Loop and create elements
    jobs.forEach((job) => {
      const article = document.createElement('article')
      article.className = 'job-listing-card'

      article.innerHTML = `
        <h3>${job.titulo}</h3>
        <small>${job.empresa} | ${job.ubicacion}</small>
        <p>${job.descripcion}</p>
      `

      container.appendChild(article)
    })

  })
  .catch((error) => {
    console.error('Error loading jobs:', error)
  })

1️⃣1️⃣ Key Points to Remember

✅ fetch allows loading data from APIs or JSON files

Works with local and remote URLs.

✅ response.json() converts the response to JavaScript

Transforms JSON into objects and arrays we can use.

✅ JSON data arrives as arrays of objects

You'll almost always need to loop with .forEach()

✅ We can create HTML elements dynamically

createElement() creates elements, innerHTML adds content.

✅ appendChild adds elements to the DOM

Makes the created elements appear on the page.

✅ It's good practice to handle loading and errors

Greatly improves user experience.

1️⃣2️⃣ Important Concept: The Foundation of Modern Apps

💡 This is what React, Vue, Angular, Next.js do

Internally, all modern applications do exactly this:

  1. Request data with fetch or axios
  2. Transform it (optional)
  3. Render the UI dynamically

The difference

Frameworks optimize the process and provide tools to make it easier.

But the fundamental concept is the same as what you just learned.
