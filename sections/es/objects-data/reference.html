Referencia vs valor

Los primitivos se copian por valor; los objetos/arrays/funciones se copian por referencia.

Valor (primitivos)

Al asignar un primitivo, se copia el valor. Cada variable es independiente.


let a = 10;
let b = a; // copia del valor
b = 20;
console.log(a); // 10
console.log(b); // 20

Referencia (objetos)

Al asignar un objeto/array, se copia la referencia. Ambas variables apuntan al mismo lugar.


let obj1 = { name: 'Alice' };
let obj2 = obj1; // misma referencia
obj2.name = 'Bob';
console.log(obj1.name); // Bob
console.log(obj2.name); // Bob

Mutaciones compartidas

Cambiar propiedades desde una variable afecta a todas las referencias.
