Instancias en JavaScript (new, instanceof, prototipos)

0) Objetivo

Entender dos cosas diferentes:

  • Cómo se crean instancias (objetos)
  • Cómo comprobar si un objeto es instancia de una clase (instanceof)

1) Crear una instancia con new

Cuando haces new, pasan 2 cosas:

  • ✅ Se crea un objeto nuevo
  • ✅ Se ejecuta el constructor()

class Car {
  constructor(brand) {
    this.brand = brand;
  }
}

const car = new Car("BMW");
console.log(car); // Car { brand: "BMW" }

📌 O sea

new Car() = "crea un coche real a partir del molde Car".

2) Por qué car === Car es incorrecto

Esto es un error típico:


console.log(car === Car); // false

Porque estás comparando:

  • car → objeto (instancia)
  • Car → clase (función constructora / molde)

🧠 Ejemplo mental

  • car es una galleta 🍪
  • Car es el molde 🧩

No puedes compararlos como si fueran lo mismo.

3) La comprobación correcta: instanceof

Para saber si car es un Car, se usa:


console.log(car instanceof Car); // true

✅ ¿Qué significa instanceof?

Significa:

"¿Existe Car.prototype dentro de la cadena de prototipos de car?"

4) La cadena de prototipos (muy importante)

JavaScript hereda así:


car → Car.prototype → Object.prototype → null

Cuando haces esto:


console.log(car instanceof Car);

JavaScript busca si Car.prototype está dentro de esa cadena.

5) Crear "instancias" sin new: Object.create

Ahora esto es importante:


const anotherCar = Object.create(Car.prototype);
  • ✅ Crea un objeto cuyo prototipo es Car.prototype
  • ❌ NO ejecuta el constructor

Ejemplo:


class Car {
  constructor() {
    this.wheels = 4;
  }
}

const anotherCar = Object.create(Car.prototype);

console.log(anotherCar instanceof Car); // true ✅
console.log(anotherCar.wheels);         // undefined ❗️

📌 ¿Por qué undefined?

Porque el constructor nunca se ejecutó.

6) Comparación rápida: new vs Object.create

Método Crea objeto Enlaza prototipo Ejecuta constructor
new Car() ✅ ✅ ✅
Object.create(Car.prototype) ✅ ✅ ❌

👉 Regla rápida

  • Quiero un objeto completo → new
  • Quiero crear algo clon / prototipo → Object.create

7) Comprobación "más estricta" (prototipo exacto)

A veces quieres verificar esto:

✅ "Es exactamente un Car (no solo herencia)"


console.log(Object.getPrototypeOf(car) === Car.prototype); // true

📌 Diferencia

  • instanceof → acepta herencia
  • getPrototypeOf === prototype → exacto

8) Ejemplo real con herencia


class Vehicle {}
class Car extends Vehicle {}

const c = new Car();

console.log(c instanceof Car);     // true
console.log(c instanceof Vehicle); // true

✅ Resultado

Porque Car hereda de Vehicle

✅ Resumen

Lo que debes recordar

  • ✅ new crea instancias completas
  • ✅ instanceof comprueba instancias usando prototipos
  • ✅ Object.create crea objetos sin constructor
  • ✅ La clave es la cadena de prototipos

Checklist de Errores Comunes

⚠️ Errores típicos a evitar

  • ❌ Comparar instancia con clase usando ===
  • ❌ Confundir instanceof con typeof
  • ❌ Esperar que Object.create ejecute el constructor
  • ❌ No entender la cadena de prototipos
