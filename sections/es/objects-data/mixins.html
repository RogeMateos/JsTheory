Mixins en JavaScript (Composición vs Herencia) — Paso a paso

0) Objetivo

Aprenderás a:

  • Entender qué es un mixin
  • Aplicarlo bien (a prototype, no a la clase)
  • Reutilizar habilidades (volar, fuego...) en varias clases sin herencia extra

Paso 0) Contexto rápido: ¿por qué mixins?

Con herencia, si quieres "volar" en varias clases, acabas creando jerarquías raras:


Animal -> FlyingAnimal -> Bird
Animal -> FlyingAnimal -> Dragon

Problema

Eso escala mal.

✅ Solución: Mixins

Con mixins, tú haces "habilidades" sueltas y se las das a quien quieras.

Eso es composición.

Paso 1) Creamos el "mixin" (la habilidad)

Un mixin suele ser un objeto con métodos.


const FlyMixin = {
  fly() {
    console.log(`${this.name} está volando`);
  },
};

📌 Nota pro

Usamos this.name porque asumimos que el objeto/clase donde lo apliquemos tendrá name.

Paso 2) Creamos una clase base (Animal)

Ahora definimos una clase que tenga el name.


class Animal {
  constructor(name) {
    this.name = name;
  }

  makeSound() {
    console.log("Sonido genérico");
  }
}

Paso 3) Creamos clases concretas (Bird y Dragon)

De momento, sin volar.


class Bird extends Animal {}
class Dragon extends Animal {}

Paso 4) El error típico (para que lo entiendas)

Si haces esto:


Object.assign(Bird, FlyMixin);

🚨 Problema

Estás metiendo fly en la clase Bird, no en sus instancias.

O sea:

  • ✅ Bird.fly() podría existir
  • ❌ new Bird().fly() NO existe

Paso 5) La forma correcta: aplicar el mixin al prototype ✅

Esto es lo que se hace en la vida real cuando quieres que lo tenga cada instancia:


Object.assign(Bird.prototype, FlyMixin);

Ahora probamos:


const bird = new Bird("Mour Bird");
bird.fly(); // Mour Bird está volando

✅ Funciona

Porque bird busca métodos en Bird.prototype.

Paso 6) Reutilizar la habilidad en otra clase (Dragon)

Aquí está la magia del mixin: misma habilidad, otra clase.


Object.assign(Dragon.prototype, FlyMixin);

const dragon = new Dragon("Mour Dragon");
dragon.fly(); // Mour Dragon está volando

Paso 7) Añadimos otro mixin para ver composición real

Ahora creamos otra habilidad: fuego.


const FireMixin = {
  breatheFire() {
    console.log(`${this.name} lanza fuego 🔥`);
  },
};

La aplicamos SOLO al dragón:


Object.assign(Dragon.prototype, FireMixin);

dragon.breatheFire(); // Mour Dragon lanza fuego 🔥

✅ Resultado

  • Bird vuela
  • Dragon vuela + lanza fuego

Sin crear más clases intermedias.

Paso 8) Regla de oro (lo que tienes que recordar)

✅ Si quieres que el método exista en la instancia:

Usa:


Object.assign(Clase.prototype, Mixin);

❌ Si lo haces en la clase:


Object.assign(Clase, Mixin);

Eso NO va a tus instancias.

Paso 9) Pitfall importante: "pisado" de métodos

Si dos mixins traen el mismo nombre de método, gana el último:


Object.assign(Dragon.prototype, MixinA, MixinB);
// Si ambos tienen fly(), gana MixinB.fly

✅ Buen hábito

Nombres claros o composición controlada.

Código final completo (todo junto)


const FlyMixin = {
  fly() {
    console.log(`${this.name} está volando`);
  },
};

const FireMixin = {
  breatheFire() {
    console.log(`${this.name} lanza fuego 🔥`);
  },
};

class Animal {
  constructor(name) {
    this.name = name;
  }

  makeSound() {
    console.log("Sonido genérico");
  }
}

class Bird extends Animal {}
class Dragon extends Animal {}

Object.assign(Bird.prototype, FlyMixin);
Object.assign(Dragon.prototype, FlyMixin, FireMixin);

const bird = new Bird("Mour Bird");
bird.fly();

const dragon = new Dragon("Mour Dragon");
dragon.fly();
dragon.breatheFire();

Mini ejercicios (para practicar)

Ejercicio 1

Crea un SwimMixin con swim() y aplícalo a Fish.


const SwimMixin = {
  swim() {
    console.log(`${this.name} está nadando`);
  },
};

class Fish extends Animal {}
Object.assign(Fish.prototype, SwimMixin);

const fish = new Fish("Nemo");
fish.swim(); // Nemo está nadando

Ejercicio 2

Haz que Bird tenga fly() pero también un sing() con un SingMixin.


const SingMixin = {
  sing() {
    console.log(`${this.name} está cantando 🎵`);
  },
};

Object.assign(Bird.prototype, FlyMixin, SingMixin);

const bird = new Bird("Tweety");
bird.fly();  // Tweety está volando
bird.sing(); // Tweety está cantando 🎵

Ejercicio 3

Crea un mixin LoggerMixin que tenga logInfo() y muestre el nombre + la clase.


const LoggerMixin = {
  logInfo() {
    console.log(`[${this.constructor.name}] ${this.name}`);
  },
};

Object.assign(Dragon.prototype, LoggerMixin);

const dragon = new Dragon("Smaug");
dragon.logInfo(); // [Dragon] Smaug

✅ Resumen

Lo que debes recordar

  • Mixin: objeto con métodos que se pueden "mezclar" en clases
  • Composición > Herencia: más flexible, menos jerarquías
  • Aplicar al prototype: Object.assign(Clase.prototype, Mixin)
  • Reutilización: misma habilidad en múltiples clases sin herencia
  • Colisión de métodos: el último mixin gana si hay nombres duplicados

Checklist de Errores Comunes

⚠️ Errores típicos a evitar

  • ❌ Aplicar el mixin a la clase en vez del prototype
  • ❌ No considerar colisiones de nombres entre mixins
  • ❌ Olvidar que los mixins dependen de propiedades como this.name
  • ❌ Usar mixins cuando herencia simple sería más clara
