Operadores spread y rest

Ambos usan .... Spread expande, rest agrupa. Ayudan a escribir código más limpio con arrays y objetos.

Spread Operator

Expande elementos de un array/objeto. Útil para copiar, mezclar o pasar argumentos.

Ejemplo: arrays


    const arr1 = [1, 2, 3];
    const arr2 = [4, 5, 6];
    
    const combinedArray = [...arr1, ...arr2]; 
    console.log(combinedArray); // Output: [1, 2, 3, 4, 5, 6]

Ejemplo: objetos


    const person = { name: 'Alice', age: 25 };
    const additionalInfo = { country: 'UK', job: 'Developer' };

    const mergedPerson = { ...person, ...additionalInfo };
    console.log(mergedPerson);
    // Output: { name: 'Alice', age: 25, country: 'UK', job: 'Developer' }

Rest Operator

Agrupa múltiples valores en un array/objeto. Útil en argumentos variables o para extraer el resto.

Ejemplo: argumentos variables


    function sum(...numbers) {
      return numbers.reduce((acc, curr) => acc + curr, 0);
    }

    console.log(sum(1, 2, 3, 4)); // Output: 10

Ejemplo: rest en objetos


    const person = { name: 'Alice', age: 25, country: 'UK', job: 'Developer' };

    const { name, ...rest } = person;
    console.log(name); // Output: Alice
    console.log(rest); // Output: { age: 25, country: 'UK', job: 'Developer' }

Difference Between Spread and Rest Operators

La diferencia es el contexto:

  • Spread: expande en literales de array/objeto o llamadas.
  • Rest: agrupa en parámetros de función o destructuring.

Summary:

Mismo ..., pero spread separa y rest reúne.
