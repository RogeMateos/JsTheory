JSON vs Object Literals

¿En qué se diferencian?

JSON se inspira en los literales de objeto, pero es un formato de datos más estricto para enviar información. No es lo mismo que el literal de objeto en JS.

Claves entre comillas, sin funciones ni undefined. Solo datos serializables.


  // JavaScript Object Literal
  const person = {
      firstName: 'Mary',
      isProgrammer: true
  };
  
  // Convert to JSON string
  const jsonString = JSON.stringify(person);
  console.log(jsonString); 
  // Output: {"firstName":"Mary","isProgrammer":true}
  
  // Convert JSON string back to object
  const jsonValue = JSON.parse(jsonString);
  console.log(jsonValue);
  // Output: { firstName: 'Mary', isProgrammer: true }

JSON es compacto y estándar para intercambio de datos (navegador y Node.js).
