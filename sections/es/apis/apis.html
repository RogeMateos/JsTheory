APIs

¿Qué es una API?

Una API (Application Programming Interface) es una interfaz de comunicación que permite que una aplicación hable con otra de forma controlada, segura y predecible.

Dicho de forma simple:
👉 una API es un contrato que define cómo pedir algo y qué vas a recibir a cambio, sin necesidad de saber cómo está construido el sistema que hay detrás.

¿Por qué necesitamos APIs?

Cuando desarrollamos una aplicación (web, móvil, escritorio, videojuegos, etc.), casi siempre necesitamos interactuar con sistemas externos, por ejemplo:

  • Un backend que gestiona usuarios
  • Un servidor remoto
  • Un servicio de pagos
  • Un proveedor de datos
  • Un servicio de IA como ChatGPT

El problema es que no podemos hablar directamente "a lo bruto" con esos sistemas. Cada uno puede estar hecho con lenguajes, tecnologías y arquitecturas diferentes.

Aquí es donde entra la API.

La API como contrato

Una API actúa como un contrato de comunicación entre dos partes:

  • 🟦 Cliente (frontend, app móvil, etc.)
  • 🟥 Servidor / sistema externo

Ese contrato define, por ejemplo:

  • Qué acciones puedo realizar
  • Qué datos tengo que enviar
  • En qué formato
  • Qué respuesta recibiré
  • Qué errores pueden ocurrir

Gracias a este contrato:

  • ✅ El cliente no necesita saber cómo funciona el sistema por dentro
  • ✅ El servidor controla qué expone y cómo

Seguridad y estandarización

Las APIs existen para que la comunicación sea:

  • Segura → control de acceso, autenticación, permisos
  • Consistente → siempre responde de la misma forma
  • Predecible → sabes qué esperar si haces una petición correcta o incorrecta

En la mayoría de los casos modernos, esta comunicación se hace usando estándares comunes (como HTTP y JSON), lo que permite que aplicaciones escritas en tecnologías distintas puedan entenderse sin problemas.

Ejemplo práctico

Imagina que tu aplicación necesita los datos de un usuario.

En lugar de decir:

"Servidor, dame los datos del usuario"

La API define algo como:

  • Qué petición debes hacer
  • Qué datos enviar
  • Qué formato recibirás

Si sigues ese contrato, el servidor te devuelve la información.
Si no, la petición falla.

APIs en el día a día

Cuando una aplicación:

  • Obtiene datos de un backend
  • Consume servicios externos
  • Se conecta con plataformas de terceros
  • Integra funcionalidades avanzadas (como IA)

👉 Está usando una API, aunque muchas veces no lo notemos.

💡 Idea clave de esta lección

Una API no es el sistema en sí,
es la forma oficial y controlada de comunicarse con él.

Si esto no existiera, integrar aplicaciones modernas sería prácticamente imposible.
