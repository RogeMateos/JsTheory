Fetch desde cero - Parte 2

Cargar datos y renderizar elementos dinámicamente en el DOM

🎯 Qué vamos a aprender

En esta parte veremos

Cómo cargar datos con fetch y mostrarlos dinámicamente en la página.

Este es el patrón que usan React, Vue, Angular y Next.js internamente:

  1. Pedir datos con fetch
  2. Transformarlos
  3. Renderizar la UI dinámicamente

1️⃣ ¿Qué es fetch? (Repaso rápido)

fetch() es una función de JavaScript

Permite pedir datos a un servidor o archivo.

Funciona de forma asíncrona, lo que significa que el navegador puede seguir funcionando mientras llegan los datos.

Ejemplo básico

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {
    console.log('Empleos obtenidos:', jobs.length)
  })

¿Qué ocurre aquí?

  1. fetch('./data.json') - Hace una petición al archivo
  2. response.json() - Convierte la respuesta en JSON usable en JavaScript
  3. jobs - Ahora tenemos un array de empleos

2️⃣ Ejemplo de Archivo JSON

Imagina que nuestro archivo data.json contiene esto:

[

Cuando lo cargamos con fetch

Obtenemos un array de objetos que podemos recorrer y manipular.

3️⃣ Seleccionar el Contenedor

Primero, seleccionamos dónde van los empleos

const container = document.querySelector('.jobs-listings')

En el HTML tenemos:

<div class="jobs-listings">
  <!-- Aquí aparecerán los empleos dinámicamente -->
</div>

4️⃣ Crear Elementos HTML Dinámicamente

Código completo

const container = document.querySelector('.jobs-listings')

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {

    jobs.forEach((job) => {

      const article = document.createElement('article')

      article.className = 'job-listing-card'

      article.dataset.modalidad = job.data.modalidad
      article.dataset.nivel = job.data.nivel
      article.dataset.technology = job.data.technology

      article.innerHTML = `
        <div>
          <h3>${job.titulo}</h3>
          <small>${job.empresa} | ${job.ubicacion}</small>
          <p>${job.descripcion}</p>
        </div>
        <button class="button-apply-job">Aplicar</button>
      `

      container.appendChild(article)
    })

  })

5️⃣ Paso a Paso: ¿Qué Hace Este Código?

1️⃣ Recorremos todos los empleos

jobs.forEach((job) => {})

Cada job es un objeto del JSON.

2️⃣ Creamos un elemento HTML

const article = document.createElement('article')

Esto crea dinámicamente: <article></article>

3️⃣ Añadimos una clase CSS

article.className = 'job-listing-card'

En HTML se vería: <article class="job-listing-card"></article>

Esto permite aplicar estilos CSS.

4️⃣ Añadimos atributos data-*

article.dataset.modalidad = job.data.modalidad
article.dataset.nivel = job.data.nivel
article.dataset.technology = job.data.technology

Esto genera en el HTML:

<article data-modalidad="remote" data-nivel="mid" data-technology="react">

Estos atributos son muy útiles para filtros.

5️⃣ Insertamos contenido HTML

article.innerHTML = `
  <h3>${job.titulo}</h3>
  <p>${job.descripcion}</p>
`

innerHTML nos permite insertar HTML dentro del elemento usando template strings.

6️⃣ Añadimos el elemento al DOM

container.appendChild(article)

Esto hace que el elemento aparezca en la página.

6️⃣ Mejorar la Experiencia: Estado de Carga

HTML - Mostrar un mensaje mientras se cargan datos

<p id="jobs-loading">Cargando empleos...</p>
<div class="jobs-listings"></div>

JavaScript - Seleccionar el elemento y ocultarlo después

const loading = document.querySelector('#jobs-loading')

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {
    // Cuando terminan de cargarse, eliminar el mensaje
    if (loading) loading.remove()

    // Resto del código...
  })

¿Qué pasa?

  1. Al principio se muestra: "Cargando empleos..."
  2. Cuando los datos llegan, loading.remove() lo elimina
  3. Los empleos aparecen en el contenedor

7️⃣ Manejar Errores

Si ocurre un problema, mostramos un mensaje

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {
    if (loading) loading.remove()
    // Mostrar empleos...
  })
  .catch((error) => {
    // Si falla, cambiar el mensaje
    if (loading) {
      loading.textContent = 'No se pudieron cargar los empleos'
    }
    console.error(error)
  })

Errores posibles

  • Archivo no encontrado (404)
  • Error de red
  • JSON inválido
  • Servidor no responde

Con .catch() los capturamos todos.

8️⃣ Caso Especial: No Hay Empleos

Comprobar si el array está vacío

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {

    if (loading) loading.remove()

    // Si no hay empleos
    if (jobs.length === 0) {
      container.innerHTML = '<p>No hay empleos disponibles ahora.</p>'
      return
    }

    // Si hay empleos, mostrarlos
    jobs.forEach((job) => {
      // ... crear elementos ...
    })

  })

¿Por qué es importante?

Mejora la experiencia del usuario. No queremos que vea una página vacía sin saber qué pasa.

9️⃣ Flujo Completo del Programa

El proceso paso a paso


fetch datos (./data.json)
      ↓
convertir a JSON (.json())
      ↓
recorrer array (.forEach())
      ↓
crear elementos HTML (createElement)
      ↓
insertarlos en el DOM (appendChild)
      ↓
Página actualizada

Esto es lo que hacen React, Vue, Angular internamente

La única diferencia es que estos frameworks optimizan el proceso.

🔟 Código Final Simplificado

Versión limpia y funcional

const container = document.querySelector('.jobs-listings')
const loading = document.querySelector('#jobs-loading')

fetch('./data.json')
  .then((response) => response.json())
  .then((jobs) => {

    // Eliminar el mensaje de carga
    if (loading) loading.remove()

    // Verificar si hay empleos
    if (jobs.length === 0) {
      container.innerHTML = '<p>No hay empleos disponibles</p>'
      return
    }

    // Recorrer y crear elementos
    jobs.forEach((job) => {
      const article = document.createElement('article')
      article.className = 'job-listing-card'

      article.innerHTML = `
        <h3>${job.titulo}</h3>
        <small>${job.empresa} | ${job.ubicacion}</small>
        <p>${job.descripcion}</p>
      `

      container.appendChild(article)
    })

  })
  .catch((error) => {
    console.error('Error al cargar empleos:', error)
  })

1️⃣1️⃣ Puntos Clave que Debes Recordar

✅ fetch permite cargar datos desde APIs o archivos JSON

Funciona con URLs locales y remotas.

✅ response.json() convierte la respuesta a JavaScript

Transforma JSON en objetos y arrays que podemos usar.

✅ Los datos JSON llegan como arrays de objetos

Casi siempre necesitarás recorrer con .forEach()

✅ Podemos crear elementos HTML dinámicamente

createElement() crea elementos, innerHTML añade contenido.

✅ appendChild añade elementos al DOM

Hace que los elementos creados aparezcan en la página.

✅ Es buena práctica manejar loading y errores

Mejora mucho la experiencia del usuario.

1️⃣2️⃣ Concepto Importante: La Base de las Apps Modernas

💡 Esto es lo que hacen React, Vue, Angular, Next.js

Internamente, todas las aplicaciones modernas hacen exactamente esto:

  1. Pedir datos con fetch o axios
  2. Transformarlos (opcional)
  3. Renderizar la UI dinámicamente

La diferencia

Los frameworks optimizan el proceso y ofrecen herramientas para hacerlo más fácil.

Pero el concepto fundamental es el mismo que acabas de aprender.

1️⃣3️⃣ Ejemplo Completo con Atributos data-*

Si quieres añadir filtros (como en el tutorial anterior)

jobs.forEach((job) => {
  const article = document.createElement('article')
  article.className = 'job-listing-card'

  // Añadir atributos data-* para filtros
  article.dataset.modalidad = job.data.modalidad
  article.dataset.nivel = job.data.nivel
  article.dataset.technology = job.data.technology

  article.innerHTML = `
    <h3>${job.titulo}</h3>
    <p>${job.descripcion}</p>
  `

  container.appendChild(article)
})

Luego puedes usar JavaScript (como aprendiste en el tutorial anterior) para filtrar por estos atributos.
