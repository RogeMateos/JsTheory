Fundamentos del DOM en JavaScript

Selección de elementos y métodos esenciales

1️⃣ ¿Qué es el DOM y por qué es importante?

Antes de tocar código, necesitamos una idea clara.

El DOM (Document Object Model) es una representación en memoria del HTML que el navegador crea cuando carga una página web.

JavaScript no interactúa directamente con el HTML, sino con este modelo intermedio: el DOM.

Piensa en el DOM como un árbol de nodos, donde cada etiqueta HTML es un objeto que JavaScript puede leer y modificar.

👉 Conclusión clave:

Si JavaScript quiere cambiar un texto, un botón o un estilo, primero tiene que acceder a ese nodo del DOM.

2️⃣ El objeto document: la puerta de entrada al DOM

En el navegador, JavaScript nos da acceso al DOM a través de un objeto global llamado:

document
  • document representa toda la página HTML
  • Desde él podemos:
    • Buscar elementos
    • Crear nuevos nodos
    • Modificar contenido y atributos

⚠️ Importante:

  • ✅ document solo existe en el navegador
  • ❌ En Node.js no existe, porque no hay HTML ni DOM

Por eso, si ejecutas JavaScript fuera del navegador y haces:

console.log(document);

Obtendrás un error: document is not defined.

3️⃣ Primer problema real: seleccionar elementos del DOM

Antes de modificar nada, tenemos que resolver siempre el mismo problema:

¿Cómo accedo desde JavaScript a un elemento HTML concreto?

Para eso existen los métodos de selección del DOM.

4️⃣ Métodos básicos (clásicos) de selección

🔹 getElementById

document.getElementById("mi-id");

Qué hace:

  • Devuelve un único elemento
  • Busca por el atributo id

Por qué devuelve uno solo:

  • Un id debe ser único dentro del HTML

Qué devuelve:

  • Un HTMLElement
  • O null si no existe

Cuándo usarlo:

  • Elementos clave: botones principales, contenedores raíz, formularios
const boton = document.getElementById("miBoton");
console.log(boton); // <button id="miBoton">...</button>

🔹 getElementsByClassName

document.getElementsByClassName("mi-clase");

Qué hace:

  • Devuelve varios elementos
  • Todos los que comparten esa clase

Qué devuelve:

  • Un HTMLCollection
  • No es un array real
  • Se actualiza automáticamente si el DOM cambia
const elementos = document.getElementsByClassName("tarjeta");
console.log(elementos.length); // 3

// Para recorrerla, necesitas convertirla a array
Array.from(elementos).forEach(el => {
  console.log(el);
});

👉 Esto refleja una buena práctica de diseño:

  • IDs → elementos únicos
  • Clases → grupos de elementos

🔹 getElementsByTagName

document.getElementsByTagName("p");

Qué hace:

  • Selecciona elementos por etiqueta (div, p, li, etc.)
  • Devuelve una colección

Uso actual:

  • Cada vez menos común
  • Útil solo en casos muy genéricos
const parrafos = document.getElementsByTagName("p");
console.log(parrafos); // HTMLCollection de todos los <p>

5️⃣ Limitaciones de los métodos clásicos

Los métodos anteriores funcionan, pero tienen problemas:

  • ❌ Son poco flexibles
  • ❌ No usan selectores CSS
  • ❌ Devuelven colecciones que no se comportan como arrays

Por eso, con la evolución de JavaScript, aparecieron métodos más modernos.

6️⃣ Métodos modernos: querySelector

🔹 querySelector

document.querySelector(".mi-clase");

Idea clave:

querySelector utiliza selectores CSS.

Puedes usar:

  • .clase
  • #id
  • div p
  • ul > li
  • [data-id="123"]

Qué devuelve:

  • El primer elemento que coincida
  • Un Element o null
// Por clase
const card = document.querySelector(".card");

// Por ID
const header = document.querySelector("#header");

// Selector complejo
const firstLink = document.querySelector("nav ul li a");

console.log(firstLink); // Primer enlace dentro de nav > ul > li

👉 Es más flexible que getElementById y se usa muchísimo hoy en día.

🔹 querySelectorAll

document.querySelectorAll(".mi-clase");

Qué hace:

  • Devuelve todos los elementos que coinciden con el selector

Qué devuelve:

  • Un NodeList
  • Se puede recorrer con forEach
const botones = document.querySelectorAll(".btn");

botones.forEach(boton => {
  console.log(boton.textContent);
});

Esto encaja perfectamente con JavaScript moderno.

7️⃣ Diferencia importante: Elemento vs Colección

Cuando trabajamos con el DOM podemos recibir:

  • Un elemento → podemos modificarlo directamente
  • Una colección → tenemos que recorrerla

Resumen mental rápido:

Método Qué devuelve
getElementById Elemento
getElementsByClassName HTMLCollection
getElementsByTagName HTMLCollection
querySelector Elemento
querySelectorAll NodeList

8️⃣ Buenas prácticas actuales

✅ En código moderno:

  • Prioriza querySelector y querySelectorAll
  • Usa selectores CSS claros
  • Reserva getElementById para casos muy concretos

❌ Evita:

  • Mezclar muchos métodos distintos sin criterio
  • Asumir que las colecciones son arrays
// ✅ Recomendado
const header = document.querySelector("#header");
const cards = document.querySelectorAll(".card");

cards.forEach(card => {
  card.classList.add("active");
});

// ❌ Menos recomendado (menos flexible)
const header = document.getElementById("header");
const cards = document.getElementsByClassName("card");

// Necesitas convertir HTMLCollection a array
Array.from(cards).forEach(card => {
  card.classList.add("active");
});

9️⃣ Idea final para cerrar el tema

Dominar la selección de elementos es dominar la base de la interacción con la web.

Si sabes acceder a los nodos del DOM, ya tienes el 50% del trabajo hecho.

✅ Resumen

  • document es la puerta de entrada al DOM
  • Métodos clásicos: getElementById, getElementsByClassName, getElementsByTagName
  • Métodos modernos: querySelector, querySelectorAll
  • querySelector usa selectores CSS (más flexible)
  • querySelectorAll devuelve un NodeList (se puede recorrer con forEach)
  • HTMLCollection ≠ Array (necesitas convertirla)
  • Prioriza los métodos modernos en código nuevo
