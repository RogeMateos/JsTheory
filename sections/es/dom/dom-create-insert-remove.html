Crear, insertar y eliminar elementos HTML con JavaScript (DOM)

Manipulación dinámica de elementos del DOM

Introducción

En este tutorial vamos a aprender cómo crear elementos HTML dinámicamente con JavaScript, cómo insertarlos en distintas posiciones del DOM y cómo eliminarlos, usando tanto APIs modernas como las tradicionales.

El objetivo es que entiendas qué ocurre realmente en el DOM, no solo memorizar métodos.

1️⃣ Idea clave: crear ≠ insertar

Uno de los errores más comunes cuando empiezas con el DOM es este:

"He creado un elemento… ¿por qué no aparece en la página?"

La razón es simple:

  • document.createElement() crea un nodo en memoria
  • NO lo añade automáticamente al DOM
  • Hasta que no lo insertes explícitamente, no se renderiza

Piensa en ello como:

"Lo he fabricado, pero aún no lo he colocado en ningún sitio".

2️⃣ Crear un nuevo elemento HTML

Vamos a crear un párrafo (<p>).

const newParagraph = document.createElement("p");

En este punto:

  • ✅ Existe en memoria
  • ❌ No está en el DOM
  • ❌ No se ve en la página

3️⃣ Configurar el elemento (contenido, estilos, clases)

Añadir texto

La forma recomendada es textContent:

newParagraph.textContent = "Este es un nuevo párrafo creado desde JavaScript";

📌 Buenas prácticas

  • ✅ textContent es seguro (no interpreta HTML)
  • ✅ Evita problemas de seguridad (XSS)
  • ⚠️ Usa innerHTML solo cuando controles completamente el contenido

Añadir estilos

newParagraph.style.padding = "8px";

💡 En proyectos reales, lo ideal es usar clases CSS, no estilos inline:

newParagraph.classList.add("paragraph");

4️⃣ Insertar el elemento en el DOM

Ahora sí: vamos a añadirlo al HTML.

const container = document.querySelector(".container");
container.append(newParagraph);

🎉 En este momento:

  • ✅ El nodo pasa de memoria → DOM
  • ✅ El navegador lo renderiza
  • ✅ El usuario lo ve

5️⃣ Crear y añadir elementos a una lista (ul > li)

Supongamos que tenemos este HTML:

<ul class="items-list">
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

Acceder a la lista

const itemsList = document.querySelector(".items-list");

Crear un nuevo <li>

const newItem = document.createElement("li");
newItem.textContent = "Nuevo elemento";

6️⃣ Insertar en distintas posiciones

➕ Al final de la lista (append)

itemsList.append(newItem);

⬆️ Al principio (prepend)

itemsList.prepend(newItem);

7️⃣ Insertar en una posición concreta

Acceder a los hijos existentes

const secondItem = itemsList.children[1]; // índice 1 = segundo elemento

📌 Importante:

  • children → solo elementos HTML
  • childNodes → incluye nodos de texto (espacios, saltos de línea)

Insertar antes del segundo elemento (forma clásica)

itemsList.insertBefore(newItem, secondItem);

Insertar usando APIs modernas (before / after)

Forma más limpia y legible:

secondItem.before(newItem); // antes del segundo
// secondItem.after(newItem); // después del segundo

💡 Aquí ya no trabajas desde el padre, sino desde el elemento de referencia.

8️⃣ Mover vs clonar elementos (detalle importante)

Si insertas un nodo que ya existe en el DOM:

itemsList.append(existingItem);

⚠️ No se duplica, se mueve.

Si quieres copiarlo:

const clone = existingItem.cloneNode(true);
itemsList.append(clone);

Nota sobre cloneNode:

  • cloneNode(true) → clona el elemento y todos sus hijos (clonación profunda)
  • cloneNode(false) → clona solo el elemento sin sus hijos

9️⃣ Eliminar elementos del DOM

Forma moderna (recomendada)

newParagraph.remove();

Simple, clara y directa.

Forma tradicional (legacy)

const parent = newParagraph.parentElement;
parent.removeChild(newParagraph);

📌 Antes era necesario:

  1. Subir al padre
  2. Pedirle al padre que eliminara al hijo

Hoy en día, remove() hace todo eso por ti.

🔟 Rendimiento: crear muchos elementos (nivel senior)

Si necesitas crear muchos elementos, evita insertar uno a uno.

Usar DocumentFragment

const fragment = document.createDocumentFragment();

for (let i = 1; i <= 100; i++) {
  const li = document.createElement("li");
  li.textContent = `Item ${i}`;
  fragment.append(li);
}

itemsList.append(fragment);

Ventajas:

  • ✅ Menos repintados
  • ✅ Mejor rendimiento
  • ✅ Código más profesional

1️⃣1️⃣ Resumen de métodos de inserción

Método Posición API
append() Al final del contenedor Moderna
prepend() Al principio del contenedor Moderna
before() Antes del elemento de referencia Moderna
after() Después del elemento de referencia Moderna
insertBefore() Antes de un hijo específico Clásica
appendChild() Al final (legacy) Clásica

1️⃣2️⃣ Ejemplo completo (listo para probar)

// Crear elemento
const newItem = document.createElement("li");
newItem.textContent = "Nuevo item dinámico";
newItem.classList.add("item");

// Seleccionar contenedor
const list = document.querySelector(".items-list");

// Verificar que existe
if (list) {
  // Insertar al final
  list.append(newItem);

  // Después de 2 segundos, eliminarlo
  setTimeout(() => {
    newItem.remove();
  }, 2000);
}

1️⃣3️⃣ Ejemplo con eventos: añadir y eliminar dinámicamente

const addButton = document.querySelector("#add-item");
const list = document.querySelector(".items-list");

if (!addButton || !list) return;

// Añadir nuevo elemento
addButton.addEventListener("click", () => {
  const newItem = document.createElement("li");
  newItem.textContent = `Item ${list.children.length + 1}`;

  // Añadir botón de eliminar
  const deleteBtn = document.createElement("button");
  deleteBtn.textContent = "Eliminar";
  deleteBtn.addEventListener("click", () => {
    newItem.remove();
  });

  newItem.append(deleteBtn);
  list.append(newItem);
});

✅ Checklist de buenas prácticas

  • ✔️ createElement crea en memoria, no en el DOM
  • ✔️ Usa textContent por defecto
  • ✔️ Inserta con append, prepend, before, after
  • ✔️ Para posiciones concretas, usa children
  • ✔️ remove() es la forma moderna de eliminar
  • ✔️ Para listas grandes, usa DocumentFragment
  • ✔️ Verifica que los elementos existen antes de manipularlos
  • ✔️ Recuerda: insertar un elemento existente lo mueve, no lo duplica

🧠 Ejercicio recomendado

  1. Crea un botón
  2. Al hacer click:
    • añade un nuevo <li> en segunda posición
  3. Al hacer click sobre un <li>:
    • elimínalo del DOM

1️⃣4️⃣ Errores comunes

  • ❌ Crear un elemento y esperar que aparezca automáticamente
  • ❌ No verificar si el contenedor existe antes de insertar
  • ❌ Usar innerHTML para añadir múltiples elementos (pierde event listeners)
  • ❌ Olvidar que insertar un elemento existente lo mueve
  • ❌ No usar DocumentFragment al crear muchos elementos

✅ Resumen

  • createElement() crea elementos en memoria
  • textContent para añadir texto de forma segura
  • append() inserta al final, prepend() al principio
  • before() y after() para posiciones relativas
  • insertBefore() para posiciones específicas (clásico)
  • remove() elimina elementos (moderno)
  • cloneNode(true) para copiar elementos
  • DocumentFragment para optimizar múltiples inserciones
  • Insertar un elemento existente lo mueve, no lo duplica
