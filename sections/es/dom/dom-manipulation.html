Manipulación de elementos del DOM en JavaScript

Cómo modificar elementos una vez seleccionados

Objetivo del tutorial

Aprender a modificar elementos del DOM una vez ya los hemos seleccionado:

  • ✅ Cambiar texto
  • ✅ Cambiar estructura HTML
  • ✅ Entender qué es una referencia
  • ✅ Usar las APIs correctas y seguras
  • ✅ Evitar errores típicos de principiante

Este punto es clave, porque aquí es donde JavaScript empieza a afectar visualmente a la página.

Contexto previo: selección ≠ modificación

Hasta ahora ya sabemos seleccionar elementos del DOM (getElementById, querySelector, etc.).

El siguiente paso natural es:

"Vale, ya tengo el elemento… ¿y ahora cómo lo cambio?"

Aquí entra la manipulación del DOM.

HTML de ejemplo (escenario base)

No es una clase de HTML, pero necesitamos contexto visual.

<h1 id="title">Título original</h1>

<div id="container">
  <button>Click</button>
</div>

Paso 1 – Seleccionar un elemento (la idea de referencia)

const title = document.getElementById("title");

Concepto clave (muy importante)

  • ❌ title no es el texto
  • ❌ title no es una copia
  • ✅ title es una referencia a un objeto del DOM (un Element)

Esto explica por qué podemos modificarlo aunque esté declarado con const.

Aclaración importante sobre const

const title = document.getElementById("title");

title = null;            // ❌ NO permitido (reasignar)
title.textContent = "";  // ✅ SÍ permitido (mutar el objeto)

const impide reasignar la variable, no modificar el objeto.

Paso 2 – Modificar texto con textContent (forma recomendada)

title.textContent = "Hola, JavaScript";

¿Qué hace textContent?

  • Cambia el texto interno del elemento
  • No interpreta HTML
  • Es seguro y predecible

Cuándo usarlo

  • ✅ Cuando solo quieres cambiar texto
  • ✅ Cuando el contenido puede venir de variables o del usuario
  • ✅ Cuando no quieres riesgos de seguridad

👉 Regla general:

Si es texto → textContent

Paso 3 – Manipular contenedores (estructura interna)

Ahora trabajemos con el contenedor.

const container = document.querySelector("#container");

Este elemento no es "solo texto", sino un contenedor de otros elementos.

Paso 4 – innerHTML: qué es y para qué sirve

container.innerHTML = "<p>Esto es un nuevo párrafo</p>";

¿Qué está pasando aquí?

  1. Se borra todo el contenido interno del contenedor
  2. Se recrea usando el string HTML
  3. El navegador interpreta ese HTML

Cuándo puede ser útil

  • Prototipos rápidos
  • Ejemplos simples
  • HTML totalmente controlado por ti

⚠️ Advertencia importante (muy senior)

  • ❌ innerHTML elimina event listeners
  • ❌ innerHTML puede causar XSS si el contenido no es seguro

Ejemplo del problema:

const button = document.querySelector("#container button");
button.addEventListener("click", () => console.log("hola"));

container.innerHTML = "<p>Nuevo</p>"; // el botón y su listener desaparecen

Paso 5 – Alternativa recomendada: crear nodos con la API del DOM

Esta es la forma correcta y profesional.

const container = document.querySelector("#container");

const p = document.createElement("p");
p.textContent = "Esto es un nuevo párrafo";

container.replaceChildren(p);

Ventajas

  • ✅ No ejecutas HTML como string
  • ✅ Más seguro
  • ✅ No pierdes control del DOM
  • ✅ Más fácil de mantener y depurar

👉 Buenas prácticas modernas evitan innerHTML siempre que sea posible.

textContent vs innerHTML (resumen rápido)

Situación Usa
Solo texto textContent
HTML dinámico controlado createElement
Prototipo rápido innerHTML (con cuidado)

Nota extra: innerText vs textContent

  • textContent → rápido, no depende de CSS
  • innerText → depende de visibilidad y estilos

👉 Para tutoriales y lógica: usa textContent.

Paso 6 – Manejo seguro de elementos que pueden no existir

const title = document.getElementById("title");

if (title) {
  title.textContent = "Hola";
}

Esto evita errores cuando el DOM cambia o el script se reutiliza.

Ejemplo final completo (versión recomendada)

// Selección
const title = document.getElementById("title");
const container = document.querySelector("#container");

// Modificar texto
if (title) {
  title.textContent = "Hola, JavaScript";
}

// Modificar estructura sin innerHTML
if (container) {
  const p = document.createElement("p");
  p.textContent = "Esto es un nuevo párrafo";

  container.replaceChildren(p);
}

Errores típicos que debes evitar

  • ❌ Pensar que const hace el DOM inmutable
  • ❌ Usar innerHTML para todo
  • ❌ Insertar datos del usuario con innerHTML
  • ❌ Perder event listeners sin saber por qué

Mini-ejercicios (recomendados)

  1. Cambia el texto del <h1> cuando se haga click en un botón
  2. Reemplaza el contenido de #container por:
    • un <p>
    • y debajo un <button> que cambie el texto del <p>
  3. Haz lo mismo sin usar innerHTML

Idea clave para cerrar

Manipular el DOM no es "cambiar cosas al azar".

Es trabajar con referencias, mutar objetos y usar la API correcta según el caso.

✅ Resumen

  • Las variables con const pueden apuntar a objetos mutables del DOM
  • textContent para cambiar texto de forma segura
  • innerHTML puede ser peligroso (XSS, pérdida de listeners)
  • createElement + replaceChildren es la forma profesional
  • Siempre verifica que el elemento existe antes de modificarlo
  • Usa textContent en lugar de innerText para lógica
