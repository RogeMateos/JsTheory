Tutorial: Introducción al DOM en JavaScript

Document Object Model - Conceptos fundamentales

1️⃣ Contexto: ¿por qué estamos hablando del DOM?

Antes de entrar en materia, es importante aclarar algo:

Este no es un curso de desarrollo web, pero sí es un curso de JavaScript a nivel intermedio.

Y aquí viene el punto clave:

👉 JavaScript nació para la web.

Aunque hoy lo usemos para muchas más cosas (APIs, servidores, automatización, etc.), una de sus misiones originales fue interactuar con páginas web.

Ya hemos visto en el curso:

  • ✅ Cómo JavaScript se comunica con servidores (APIs)
  • ✅ Cómo maneja datos
  • ✅ Cómo trabaja con asincronía

El siguiente paso natural es entender cómo JavaScript interactúa con una página web, y ahí es donde entra el DOM.

2️⃣ Qué es el DOM (explicación clara y directa)

DOM significa Document Object Model.

Pero más importante que el nombre es la idea:

El DOM es una representación en memoria de la página web, creada por el navegador, que JavaScript puede leer y modificar.

⚠️ Punto importante:

  • ❌ El DOM no es el HTML
  • ✅ El DOM es lo que el navegador construye a partir del HTML

3️⃣ HTML, CSS y JavaScript: roles claros

Para entender el DOM, primero hay que entender cómo se divide una web:

🧱 HTML – Estructura

Define qué existe en la página:

  • Textos
  • Botones
  • Imágenes
  • Formularios
  • Tablas

Es el esqueleto de la web.

🎨 CSS – Estilos

Define cómo se ve:

  • Colores
  • Tamaños
  • Posiciones
  • Animaciones

Es la apariencia.

⚙️ JavaScript – Comportamiento

Define qué hace la página:

  • Responder a clicks
  • Cambiar textos
  • Mostrar u ocultar elementos
  • Reaccionar a eventos

Y aquí viene lo importante:

JavaScript no modifica el HTML directamente.
JavaScript modifica el DOM.

4️⃣ El DOM como árbol (visualización mental)

El navegador transforma el HTML en una estructura jerárquica, parecida a un árbol.

<!DOCTYPE html>
<html>
  <head>
    <title>Mi Página</title>
  </head>
  <body>
    <h1>Título</h1>
    <p>Párrafo</p>
  </body>
</html>

Se convierte en:

document
  └── html
      ├── head
      │   └── title
      │       └── "Mi Página"
      └── body
          ├── h1
          │   └── "Título"
          └── p
              └── "Párrafo"

Cómo leer este árbol

  • document es el nodo raíz
  • Cada etiqueta HTML es un nodo
  • Los elementos están relacionados entre sí (padre, hijo, hermanos)

📌 Analogía útil:

El HTML es el plano de una casa.
El DOM es la casa ya construida, con la que puedes interactuar.

5️⃣ ¿Por qué el DOM fue tan importante?

Antes del DOM

  • ❌ La web era estática
  • ❌ Para cambiar algo → recargar la página
  • ❌ Experiencia muy limitada

Con el DOM

  • ✅ Cambiar contenido sin recargar
  • ✅ Crear interfaces dinámicas
  • ✅ Responder a acciones del usuario

👉 La web dejó de ser solo documentos y pasó a ser aplicaciones.

6️⃣ Qué puede hacer JavaScript con el DOM

Cuando trabajamos con el DOM, JavaScript suele hacer cuatro cosas principales:

1️⃣ Seleccionar elementos

Buscar elementos concretos dentro del documento:

  • Un párrafo
  • Un botón
  • Un input
  • Una lista

2️⃣ Leer o modificar contenido

  • Cambiar texto
  • Cambiar atributos
  • Actualizar valores

Ejemplo conceptual: Cambiar el texto de un párrafo cuando pasa algo.

3️⃣ Cambiar estilos o clases

  • Aplicar o quitar clases CSS
  • Cambiar colores, tamaños, visibilidad

Ejemplo: Resaltar un elemento cuando el usuario interactúa con él.

4️⃣ Escuchar eventos

  • Clicks
  • Teclas
  • Movimiento del ratón
  • Envío de formularios

Ejemplo: Ejecutar una acción cuando el usuario hace click en un botón.

7️⃣ Ejemplo práctico explicado (sin código todavía)

Imaginemos una página con:

  • Un párrafo
  • Un botón

Queremos que:

Al hacer click en el botón, el texto del párrafo cambie.

¿Qué ocurre realmente?

  1. El navegador crea el DOM a partir del HTML
  2. JavaScript accede al DOM
  3. JavaScript localiza el párrafo
  4. JavaScript espera un evento (click)
  5. Cuando ocurre el evento:
    • Modifica el nodo del párrafo
    • El navegador actualiza la pantalla

⚠️ Importante:

  • ✅ No se recarga la página
  • ✅ Solo se modifica el DOM

8️⃣ El DOM NO es parte de JavaScript (detalle importante)

Esto suele confundir mucho al principio, así que conviene dejarlo claro:

El DOM no forma parte del lenguaje JavaScript.

El DOM es:

  • Una API del navegador
  • Expuesta para que JavaScript pueda usarla

Por eso:

  • ✅ document existe en el navegador
  • ❌ En Node.js no existe el DOM

Este detalle es clave para entender por qué JavaScript puede ejecutarse en tantos entornos distintos.

9️⃣ JavaScript hoy: mucho más que el DOM

Hoy en día JavaScript:

  • ✅ Consume APIs
  • ✅ Maneja datos
  • ✅ Corre en servidores
  • ✅ Se usa en apps móviles y de escritorio

Pero aun así:

Una de sus funciones más importantes sigue siendo interactuar con la web mediante el DOM.

Y algo muy importante para el futuro:

Frameworks como React, Vue o Angular no reemplazan el DOM.
Lo que hacen es organizar y abstraer su uso.

🔚 Resumen final

Qué debes quedarte de esta lección:

  • ✅ El DOM es la representación viva de la página web
  • ✅ JavaScript interactúa con la web a través del DOM
  • ✅ El DOM permite modificar contenido sin recargar
  • ✅ Todo frontend moderno termina interactuando con el DOM
  • ✅ Entender el DOM es clave antes de usar frameworks
