Manipulación del DOM con querySelector, clases CSS y estilos inline

Cómo modificar la apariencia de elementos con JavaScript

Introducción

En este bloque vamos a aprender cómo seleccionar elementos del DOM y modificar su apariencia usando JavaScript moderno.

Esto es una de las operaciones más comunes en cualquier aplicación frontend.

⚠️ No es un curso de CSS, pero sí necesitamos entender cómo JavaScript interactúa con CSS a través del DOM.

1. Seleccionar elementos con querySelector

Hoy en día, la forma más habitual de trabajar con el DOM es usando selectores CSS.

JavaScript nos proporciona:

  • document.querySelector() → devuelve el primer elemento que coincida
  • document.querySelectorAll() → devuelve todos los elementos que coincidan

Ejemplo básico

const box = document.querySelector(".box");

Aquí estamos diciendo:

  • Busca en el documento
  • El primer elemento que tenga la clase .box
  • Guárdalo en la variable box

Tipos de selectores más comunes

  • .box → clase
  • #main → id
  • button → etiqueta HTML
  • [data-role="save"] → atributo (muy usado en apps modernas)

⚠️ Importante:

Si el elemento no existe, querySelector devuelve null.

if (!box) return; // evita errores

2. Manipular clases CSS con classList (forma recomendada)

Una vez tenemos un elemento, podemos acceder a su lista de clases HTML usando classList.

Las clases suelen representar estados visuales.

Métodos principales

box.classList.add("selected");    // añade una clase
box.classList.remove("selected"); // elimina una clase
box.classList.toggle("selected"); // alterna la clase

¿Qué hace realmente toggle?

  • Si la clase no existe → la añade
  • Si la clase existe → la elimina

Es como un interruptor (ON / OFF).

Variante avanzada (muy útil)

box.classList.toggle("selected", true);  // fuerza ON
box.classList.toggle("selected", false); // fuerza OFF

Esto evita errores cuando quieres controlar el estado, no alternarlo a ciegas.

Otros métodos útiles de classList

// Comprobar si tiene una clase
box.classList.contains("selected"); // true o false

// Reemplazar una clase por otra
box.classList.replace("old-class", "new-class");

3. Conectar la lógica con un evento real (clic)

Los cambios visuales suelen ocurrir porque algo pasa: un clic, un submit, una respuesta del servidor, etc.

Ejemplo con un botón:

const box = document.querySelector(".box");
const button = document.querySelector("button");

if (!box || !button) return;

button.addEventListener("click", () => {
  box.classList.toggle("selected");
});

Qué está pasando aquí

  1. Escuchamos un clic en el botón
  2. Cuando ocurre, alternamos la clase selected
  3. El CSS reacciona y repinta el elemento

4. Cambiar estilos directamente con style (inline styles)

Además de usar clases, todos los elementos HTML tienen la propiedad style.

Esto modifica el estilo inline, como si escribieras: 

<button style="background-color: blue">

Ejemplo

button.style.backgroundColor = "blue";
button.style.color = "white";
button.style.padding = "10px";

Relación CSS ↔ JavaScript

En CSS usamos kebab-case:

  • background-color
  • font-size
  • border-radius

En JavaScript usamos camelCase:

  • backgroundColor
  • fontSize
  • borderRadius

⚠️ Los valores suelen ser strings con unidades:

button.style.padding = "10px"; // ✅ correcto
button.style.padding = 10;     // ❌ incorrecto

5. ¿Clases CSS o estilos inline? (muy importante)

Usa clases CSS cuando:

  • ✅ Representan estados (is-active, is-open, has-error)
  • ✅ El estilo no depende de cálculos dinámicos
  • ✅ Quieres mantener separación entre lógica y diseño

Usa style inline cuando:

  • ✅ El valor es dinámico (posición, tamaño, porcentaje)
  • ✅ Viene de cálculos JS (ej. drag & drop, animaciones)

👉 Regla general:

  • Estados → clases
  • Valores dinámicos → style

6. Ejemplo completo (listo para demo)

HTML

<div class="box">Caja</div>
<button data-action="toggle-box">Toggle</button>

CSS (conceptual)

.box {
  padding: 16px;
  border: 1px solid #ccc;
}

.box.selected {
  background: red;
  color: white;
}

JavaScript

const box = document.querySelector(".box");
const button = document.querySelector('[data-action="toggle-box"]');

if (!box || !button) return;

button.addEventListener("click", () => {
  box.classList.toggle("selected");
});

7. Ejemplo con estilos dinámicos

Cuando necesitas calcular valores dinámicamente:

const slider = document.querySelector('input[type="range"]');
const box = document.querySelector('.box');

if (!slider || !box) return;

slider.addEventListener('input', (e) => {
  const value = e.target.value;

  // Estilo dinámico basado en el valor del slider
  box.style.width = `${value}%`;
  box.style.opacity = value / 100;
});

8. Combinar clases y estilos inline

A veces necesitas ambos enfoques:

const card = document.querySelector('.card');

// Estado visual con clase
card.classList.add('is-loading');

// Posición dinámica con style
card.style.transform = `translateY(${offset}px)`;

// Después de cargar
setTimeout(() => {
  card.classList.remove('is-loading');
  card.classList.add('is-loaded');
}, 2000);

9. Errores comunes (pitfalls)

❌ Olvidar el . en clases

// ❌ Incorrecto
querySelector("box")

// ✅ Correcto
querySelector(".box")

❌ No comprobar si el elemento existe (null)

// ❌ Peligroso
const box = document.querySelector(".box");
box.classList.add("active"); // Error si box es null

// ✅ Seguro
const box = document.querySelector(".box");
if (box) {
  box.classList.add("active");
}

❌ Confundir querySelectorAll con un solo elemento

// ❌ Incorrecto (devuelve una lista, no tiene classList directamente)
const boxes = document.querySelectorAll(".box");
boxes.classList.add("active"); // Error

// ✅ Correcto
const boxes = document.querySelectorAll(".box");
boxes.forEach(box => {
  box.classList.add("active");
});

❌ Usar números sin unidades en style

// ❌ Incorrecto
element.style.width = 200;

// ✅ Correcto
element.style.width = "200px";
element.style.width = "50%";

10. Mini ejercicios para practicar

  1. Cambia selected por is-active
  2. Haz que el botón cambie su texto según el estado
  3. Añade un segundo botón que fuerce el estado activo usando toggle(name, true)
  4. Crea un sistema de pestañas donde solo una puede estar activa a la vez
  5. Implementa un tema oscuro/claro agregando/quitando una clase en body

11. Bonus: Múltiples clases a la vez

// Añadir varias clases
element.classList.add("class1", "class2", "class3");

// Eliminar varias clases
element.classList.remove("class1", "class2");

✅ Resumen

  • querySelector() selecciona el primer elemento que coincide
  • querySelectorAll() selecciona todos los elementos que coinciden
  • classList.add(), remove(), toggle() para manipular clases
  • toggle(name, boolean) para forzar un estado específico
  • element.style.property para estilos inline dinámicos
  • CSS usa kebab-case, JavaScript usa camelCase
  • Clases para estados, style para valores dinámicos
  • Siempre verifica que el elemento existe antes de manipularlo
