Introducción al DOM (Document Object Model)

Cómo JavaScript interactúa con páginas web

¿Qué es el DOM?

DOM significa Document Object Model (Modelo de Objeto del Documento). Es la representación estructurada de una página web que permite a JavaScript interactuar con el contenido HTML.

⚠️ Nota importante sobre este curso

Este no es un curso de desarrollo web como tal. Sin embargo, cuando hablamos de JavaScript a nivel intermedio-avanzado, es imposible ignorar una de sus principales misiones desde su creación: ser un lenguaje de programación para la web.

🌐 Los tres pilares de la web

Una página web moderna se compone de tres tecnologías fundamentales:

1. HTML (Estructura)

  • Define la estructura de la página
  • Crea elementos: párrafos, botones, tablas, formularios, etc.
  • Es como el "esqueleto" de la página
<p>Hola mundo</p>
<button>Haz clic</button>
<table>...</table>

2. CSS (Estilo)

  • Define la apariencia visual
  • Colores, tamaños, posiciones, animaciones
  • Es como la "ropa" de la página
p {
  color: blue;
  font-size: 16px;
}

3. JavaScript (Interactividad)

  • Aporta interactividad y comportamiento
  • Responde a acciones del usuario
  • Modifica contenido dinámicamente
  • Es como el "cerebro" de la página

🎯 La misión original de JavaScript

Hace 30 años, cuando JavaScript fue creado, las páginas web eran estáticas. Solo podías leer contenido, como si fuera un documento de papel.

El problema:

  • La web no hacía nada por sí misma
  • No se transformaba ni modificaba
  • No respondía a las acciones del usuario
  • Era simplemente "modo lectura"

La solución: JavaScript

JavaScript surgió para dar a las páginas web la capacidad de:

  • ✅ Responder a acciones del usuario (clics, teclas, scroll)
  • ✅ Modificar contenido dinámicamente
  • ✅ Añadir o eliminar elementos
  • ✅ Cambiar estilos y propiedades
  • ✅ Validar formularios
  • ✅ Comunicarse con servidores (APIs)

🔑 ¿Cómo funciona el DOM?

El navegador lee el HTML y crea una representación en forma de árbol llamada DOM. Esta representación es un objeto JavaScript que podemos manipular. 

<!-- HTML original -->
<div id="app">
  <h1>Título</h1>
  <p>Texto del párrafo</p>
</div>

El navegador lo convierte en una estructura de objetos accesible desde JavaScript:

// JavaScript puede acceder a estos elementos
const app = document.getElementById('app');
const titulo = app.querySelector('h1');
const parrafo = app.querySelector('p');

// Y modificarlos
titulo.textContent = 'Nuevo título';
parrafo.style.color = 'red';

📋 Ejemplos clásicos de manipulación del DOM

Ejemplo 1: Cambiar el texto de un párrafo

<p id="miParrafo">Texto original</p>
<button onclick="cambiarTexto()">Cambiar texto</button>
    
function cambiarTexto() {
  const parrafo = document.getElementById('miParrafo');
  parrafo.textContent = '¡Texto modificado con JavaScript!';
}

Ejemplo 2: Responder a un clic de botón

<button id="miBoton">Haz clic</button>
    
const boton = document.getElementById('miBoton');

boton.addEventListener('click', () => {
  alert('¡Botón clickeado!');
});

Ejemplo 3: Añadir elementos dinámicamente

const nuevoElemento = document.createElement('p');
nuevoElemento.textContent = 'Elemento creado con JavaScript';

document.body.appendChild(nuevoElemento);

💡 Capacidad nativa de JavaScript

Importante: Esta capacidad de interactuar con el DOM es nativa de JavaScript.

  • ✅ No necesitas librerías adicionales
  • ✅ No necesitas frameworks
  • ✅ Está disponible directamente en el navegador
  • ✅ Es parte del estándar web

Aunque hoy en día existen frameworks como React, Vue o Angular que facilitan el trabajo con el DOM, entender el DOM nativo es fundamental para cualquier desarrollador JavaScript.

🚀 JavaScript hoy en día

A día de hoy, JavaScript es un lenguaje tan extendido y potente que prácticamente podemos hacer lo que queramos con él:

  • Frontend (páginas web interactivas)
  • Backend (servidores con Node.js)
  • Aplicaciones móviles (React Native)
  • Aplicaciones de escritorio (Electron)
  • IoT (Internet de las Cosas)
  • Machine Learning (TensorFlow.js)

Pero una de sus primeras y más importantes misiones sigue siendo la manipulación del DOM para crear experiencias web interactivas.

✅ Resumen

  • DOM: representación estructurada de una página web
  • JavaScript: lenguaje que permite interactuar con el DOM
  • HTML: estructura de la página
  • CSS: estilos visuales
  • JS + DOM: interactividad y comportamiento dinámico
  • Nativo: no necesitas librerías para manipular el DOM
