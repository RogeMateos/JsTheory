Manejar evento change en JavaScript

Escuchando cambios en elementos de formulario con addEventListener

🔄 ¿Qué es el evento change?

Contexto

En la clase anterior, vimos cómo escuchar el evento click para detectar cuando el usuario hace click en un botón. Ahora vamos a escuchar el evento change para ver cuando el usuario cambia el valor de un <select>.

💡 ¿Cuándo se dispara?

El evento change se dispara cuando el usuario cambia el valor seleccionado de un elemento de formulario como un <select>, <input> o <textarea>.

📝 El HTML base

Formulario con select

Con un HTML como este:

<form class="search-filters">
  <label for="filter-location">Ubicación</label>
  <select id="filter-location">
    <option value="">Todas</option>
    <option value="remoto">Remoto</option>
    <option value="cdmx">Ciudad de México</option>
    <option value="guadalajara">Guadalajara</option>
  </select>
</form>

🎯 Escuchando el evento change

✅ Usando addEventListener

Podemos escuchar el evento change para ver cuando el usuario cambia el valor del select:

const filterLocation = document.getElementById('filter-location')

filterLocation.addEventListener('change', function () {
  console.log('Ubicación seleccionada:', filterLocation.value)
})

⚠️ value vs texto visible

Tené en cuenta que el valor del select es el valor del option seleccionado… ¡no el nombre de la opción!

Por lo que si el usuario selecciona "Ciudad de México", el valor de filterLocation.value será "cdmx".

No confundas el value del option con el texto que ve el usuario.

🔍 Entendiendo la diferencia

<option value="cdmx">Ciudad de México</option>
<!--          ^^^^    ^^^^^^^^^^^^^^^^^
         value (JS)    texto visible (usuario) -->
filterLocation.value        // "cdmx" ← esto obtenés con .value
filterLocation.selectedOptions[0].text  // "Ciudad de México" ← el texto visible

♿ Nota sobre accesibilidad

🏷️ El label es obligatorio

Como podés ver en el ejemplo, el <select> tiene asociado un <label> mediante el atributo for que apunta al id del select.

Esto es esencial para la accesibilidad, ya que permite a los lectores de pantalla identificar correctamente el propósito del campo.

<!-- ✅ Correcto: label asociado al select -->
<label for="filter-location">Ubicación</label>
<select id="filter-location">...</select>

<!-- ❌ Incorrecto: select sin label -->
<select id="filter-location">...</select>

En los ejemplos de este curso incluimos los labels cuando es relevante para el contexto, pero siempre debés asegurarte de usarlos en producción.
