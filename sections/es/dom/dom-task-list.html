Tutorial: Crear una lista de tareas con JavaScript y el DOM (desde cero)

Mini aplicación práctica con JavaScript puro y el DOM

Introducción

En este ejercicio vamos a crear una mini aplicación de lista de tareas usando JavaScript puro y el DOM. No es desarrollo web avanzado ni frameworks: el objetivo es entender cómo JavaScript interactúa con HTML.

Al final del tutorial sabrás:

  • Seleccionar elementos del DOM
  • Escuchar eventos (click, Enter)
  • Crear y eliminar elementos HTML dinámicamente
  • Evitar errores comunes al trabajar con inputs
  • Entender por qué estas técnicas son clave en frontend

🎯 Objetivo del ejercicio

Construir una app muy simple donde:

  • El usuario escribe una tarea en un input
  • Pulsa un botón o Enter
  • La tarea se añade a una lista
  • El input se limpia automáticamente
  • Si haces click sobre una tarea, se elimina
  • No se permiten tareas vacías

🧱 Paso 1: Estructura HTML mínima

Creamos un archivo llamado tasklist.html.

¿Qué necesita nuestra interfaz?

  • Un título
  • Un input de texto
  • Un botón
  • Una lista (ul) donde irán las tareas
<!doctype html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Lista de tareas</title>

    <!-- defer asegura que el DOM esté cargado antes de ejecutar JS -->
    <script defer src="tasklist.js"></script>
  </head>
  <body>
    <h1>Mis tareas</h1>

    <input
      id="taskInput"
      type="text"
      placeholder="Escribe una tarea"
    />

    <button id="addTaskBtn">Agregar tarea</button>

    <ul id="taskList"></ul>
  </body>
</html>

🔎 Nota importante (muy senior):

Usamos defer en el script para asegurarnos de que el DOM esté cargado antes de acceder a los elementos. Esto evita muchos bugs típicos en proyectos reales.

🧠 Paso 2: ¿Con qué elementos vamos a interactuar?

Desde JavaScript necesitamos acceder a:

  • El input → leer y limpiar texto
  • El botón → detectar clic
  • La lista → añadir y eliminar tareas

Creamos tasklist.js.

const taskInput = document.getElementById("taskInput");
const addTaskBtn = document.getElementById("addTaskBtn");
const taskList = document.getElementById("taskList");

💡 Buena práctica:

Guardamos las referencias una sola vez en constantes.

⚙️ Paso 3: Función principal – añadir tarea

Toda la lógica debe vivir en una función reutilizable.

function addTask() {
  const text = taskInput.value.trim();

  // Si el input está vacío, no hacemos nada
  if (text === "") return;

  const li = document.createElement("li");
  li.textContent = text;

  taskList.appendChild(li);

  // Limpiamos el input
  taskInput.value = "";
  taskInput.focus();
}

¿Qué está pasando aquí?

  1. Leemos el valor del input
  2. Usamos trim() para evitar textos vacíos
  3. Creamos dinámicamente un <li>
  4. Lo añadimos al <ul>
  5. Limpiamos el input y devolvemos el foco

👉 Esto es DOM puro en acción.

🖱️ Paso 4: Evento click en el botón

Ahora conectamos el botón con la función.

addTaskBtn.addEventListener("click", addTask);

✔️ El botón no contiene lógica, solo dispara la acción.

⌨️ Paso 5: Añadir tarea pulsando Enter

Queremos que el usuario pueda pulsar Enter dentro del input.

taskInput.addEventListener("keydown", (e) => {
  if (e.key === "Enter") {
    addTask();
  }
});

📌 Usamos keydown y no keypress (mejor soporte y práctica actual).

🗑️ Paso 6: Eliminar tareas haciendo click

Aquí usamos una técnica muy importante en frontend:
👉 delegación de eventos

En lugar de añadir un listener a cada <li>, añadimos uno solo al <ul>.

taskList.addEventListener("click", (e) => {
  if (e.target.tagName === "LI") {
    e.target.remove();
  }
});

¿Por qué esto es buena práctica?

  • Funciona incluso con elementos creados dinámicamente
  • Menos listeners = mejor rendimiento
  • Es muy usado en proyectos reales

🧪 Resultado final

Ahora podemos:

  • Añadir tareas con botón o Enter
  • Verlas aparecer dinámicamente
  • Eliminarlas con un click
  • Evitar tareas vacías

Todo esto sin frameworks, solo JavaScript y DOM.

⚠️ Errores comunes (y cómo evitarlos)

Error Motivo Solución
Aparece [object HTMLInputElement] Usas el nodo, no su valor Usa .value
Se crean tareas vacías No validas el texto Usa trim()
No funciona al cargar DOM no listo Usa defer
Enter no funciona Evento incorrecto Usa keydown

🧠 Conclusión

Este ejercicio no es "hacer una web", sino entender por qué JavaScript es tan potente en frontend:

  • Manipula el DOM
  • Responde a eventos del usuario
  • Modifica la interfaz en tiempo real

Todo framework moderno (React, Vue, Angular) se apoya en estas bases.
