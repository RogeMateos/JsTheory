Manipulación de atributos en el DOM (JavaScript)

Leer, modificar, comprobar y eliminar atributos HTML

Objetivo del tutorial

Aprender a leer, modificar, comprobar y eliminar atributos HTML desde JavaScript usando el DOM, entendiendo qué ocurre realmente por debajo y evitando errores comunes.

1. ¿Qué es un atributo en HTML?

Un atributo es información adicional que vive dentro de una etiqueta HTML.

Ejemplo:

<a href="/home" target="_blank">Home</a>

Aquí:

  • href → indica la URL del enlace
  • target → indica cómo se abre el enlace

Desde JavaScript podemos leerlos, cambiarlos, comprobar si existen o eliminarlos.

2. Paso 1: seleccionar el elemento correcto

Antes de tocar un atributo, primero hay que seleccionar el elemento.

Seleccionar un solo enlace

const link = document.querySelector('a');

⚠️ Importante:

querySelector solo devuelve el primer elemento que coincida.

Seleccionar todos los enlaces

const links = document.querySelectorAll('a');

Esto devuelve una NodeList (una lista de elementos).

👉 Buena práctica: usa selectores específicos.

const link = document.querySelector('.nav-link');

3. Paso 2: leer un atributo (getAttribute)

Para obtener el valor de un atributo HTML, usamos getAttribute.

const link = document.querySelector('.nav-link');
const hrefValue = link.getAttribute('href');

console.log(hrefValue);

🔹 Esto devuelve un string con el valor del atributo.

🔹 Si el atributo no existe → devuelve null.

⚠️ Ojo con el nombre del atributo:

Es href, no hrf.

4. Paso 3: modificar o crear un atributo (setAttribute)

Con setAttribute podemos crear o sobrescribir un atributo.

link.setAttribute('href', 'https://example.com');

Regla mental:

  • Si existe → lo sobrescribe
  • Si no existe → lo crea

Ejemplo práctico:

link.setAttribute('target', '_blank');

5. Paso 4: comprobar si un atributo existe (hasAttribute)

Antes de tocar un atributo, muchas veces interesa comprobar si existe.

const hasTarget = link.hasAttribute('target');
console.log(hasTarget); // true o false

Ejemplo real:

if (!link.hasAttribute('target')) {
  link.setAttribute('target', '_blank');
}

🔹 hasAttribute no devuelve el valor, solo un boolean.

6. Paso 5: eliminar un atributo (removeAttribute)

Si queremos volver al comportamiento por defecto:

link.removeAttribute('target');

Esto elimina completamente el atributo del HTML.

7. Atributos vs Propiedades del DOM (MUY IMPORTANTE)

Aquí suele haber confusión.

Atributo HTML

link.getAttribute('href');
  • Devuelve el valor tal como está en el HTML
  • Puede ser relativo (/home)

Propiedad del DOM

link.href;
  • Devuelve la URL normalizada y absoluta
  • Refleja el estado real del elemento

Ejemplo:

<a href="/home"></a>
    
link.getAttribute('href'); // "/home"
link.href;                 // "https://tusitio.com/home"

👉 En la práctica:

  • Usa atributos si quieres leer el HTML "original"
  • Usa propiedades si quieres trabajar con el estado real del elemento

8. Ejemplo real completo (muy de trabajo)

Objetivo

Todos los enlaces externos:

  • Se abren en nueva pestaña
  • Son seguros (rel="noopener noreferrer")
document.querySelectorAll('a').forEach(link => {
  const href = link.getAttribute('href');

  if (!href) return;
  if (href.startsWith('#')) return;
  if (href.startsWith('/')) return;

  link.setAttribute('target', '_blank');
  link.setAttribute('rel', 'noopener noreferrer');
});

💡 Este patrón se usa muchísimo en proyectos reales.

9. Errores comunes que debes evitar

  • ❌ Asumir que querySelector devuelve varios elementos
  • ❌ No comprobar si el elemento existe (null)
  • ❌ Confundir href con hrf
  • ❌ No entender la diferencia entre atributo y propiedad

Ejemplo seguro:

const link = document.querySelector('.nav-link');

if (link) {
  link.setAttribute('href', 'https://example.com');
}

10. Resumen mental rápido

  3. Convierte todos los enlaces externos en seguros automáticamente.

12. Atributos comunes y sus usos

Atributo Elemento Uso
href <a> URL del enlace
src <img>, <script> Ruta del recurso
alt <img> Texto alternativo
class Cualquiera Clases CSS
id Cualquiera Identificador único
value <input> Valor del campo
disabled <button>, <input> Deshabilitar elemento
data-* Cualquiera Datos personalizados

13. Caso especial: atributos booleanos

Algunos atributos son booleanos (existen o no existen):

  • disabled
  • checked
  • selected
  • hidden
// Añadir atributo booleano
button.setAttribute('disabled', '');

// Mejor: usar la propiedad
button.disabled = true;

// Comprobar
if (button.hasAttribute('disabled')) {
  console.log('El botón está deshabilitado');
}

// Eliminar
button.removeAttribute('disabled');
// o
button.disabled = false;

✅ Resumen

  • getAttribute() lee atributos tal como están en el HTML
  • setAttribute() crea o modifica atributos
  • hasAttribute() comprueba existencia (retorna boolean)
  • removeAttribute() elimina atributos
  • Atributos ≠ Propiedades: atributos son HTML, propiedades son DOM
  • Usa propiedades para atributos booleanos (disabled, checked)
  • Siempre verifica que el elemento existe antes de manipularlo
  • Los enlaces externos deben tener target="_blank" y rel="noopener noreferrer"
