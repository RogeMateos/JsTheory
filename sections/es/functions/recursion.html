Recursión

Idea clave

Recursión = una función que se pide ayuda a sí misma…
pero deja una nota de "cuándo parar".

  • Sin esa nota → caos 😅
  • Con esa nota → todo funciona.

📦 Ejemplo de la vida real (MUY simple)

🪜 Subir escaleras

Imagínate que estás en el escalón 5 y quieres llegar al suelo (0).

Tú haces esto mentalmente:

  • "Para bajar del 5… primero bajo del 4"
  • "Para bajar del 4… primero bajo del 3"
  • "Para bajar del 3… primero bajo del 2"
  • "Para bajar del 2… primero bajo del 1"
  • "Para bajar del 1… ya estoy abajo" ✅

👉 Eso es recursión

🔁 Ahora en código (sin complicarlo)

function bajarEscalon(n) {
  if (n === 0) return;   // 🛑 nota de parar
  console.log("Estoy en el escalón", n);
  bajarEscalon(n - 1);  // me llamo a mí mismo
}

bajarEscalon(3);

Qué pasa en tu cabeza:

bajarEscalon(3)
→ bajarEscalon(2)
→ bajarEscalon(1)
→ bajarEscalon(0) 🛑

🧠 Regla de ORO (memorízala)

Una función recursiva SIEMPRE tiene 2 partes:

  1. 🛑 Caso base → cuándo paro
  2. 🔁 Paso recursivo → me llamo a mí mismo, pero más cerca del final

Si falta una → no es recursión correcta.

🍕 Otro ejemplo ultra sencillo

function comerPorciones(n) {
  if (n === 0) {
    console.log("No queda pizza");
    return;
  }

  console.log("Me como una porción");
  comerPorciones(n - 1);
}

comerPorciones(3);

Salida:

Me como una porción
Me como una porción
Me como una porción
No queda pizza

🧩 Factorial (ya no debería dar miedo)

function factorial(n) {
  if (n === 1) return 1;      // 🛑
  return n * factorial(n-1); // 🔁
}

Piensa así:

"El factorial de 5 es
5 × el factorial de 4
y el factorial de 4 ya sabrá qué hacer…"

🎯 Frase mágica para entrevistas

"Recursion is when a function solves a problem by delegating a smaller version of the same problem to itself, and stops at a base case."
