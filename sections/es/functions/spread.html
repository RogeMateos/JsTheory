Entendiendo los Operadores Spread y Rest en JavaScript

En JavaScript, los operadores spread (...) y rest (...) usan la misma sintaxis pero hacen cosas opuestas dependiendo de dónde se usen. Entender esta diferencia hace que trabajar con arrays y objetos sea mucho más fácil y legible.

Spread Operator

El operador spread (...) se usa para expandir un array u objeto en elementos o propiedades individuales.

👉 Piensa en spread como "sacar cosas de una caja".

Comúnmente usas spread para:

  • Copiar arrays u objetos
  • Combinar arrays u objetos
  • Pasar valores de un array como argumentos individuales de función

Ejemplo: Expandiendo Arrays


    const arr1 = [1, 2, 3];
    const arr2 = [4, 5, 6];

    const combinedArray = [...arr1, ...arr2];
    console.log(combinedArray);
    // Output: [1, 2, 3, 4, 5, 6]

Qué está pasando aquí:

  • ...arr1 se expande a 1, 2, 3
  • ...arr2 se expande a 4, 5, 6
  • Estos valores se colocan en un nuevo array

Así que JavaScript ve: [1, 2, 3, 4, 5, 6]

Ejemplo: Expandiendo Objetos


    const person = { name: 'Alice', age: 25 };
    const additionalInfo = { country: 'UK', job: 'Developer' };

    const mergedPerson = { ...person, ...additionalInfo };
    console.log(mergedPerson);
    // Output: { name: 'Alice', age: 25, country: 'UK', job: 'Developer' }

Qué está pasando aquí:

  • ...person expande cada propiedad (name, age)
  • ...additionalInfo expande sus propiedades
  • Todas las propiedades se copian en un nuevo objeto
⚠️ Importante: Si dos objetos tienen la misma clave, el último gana.

🧠 Regla Clave para Recordar

Spread → expande valores
Rest → recolecta valores

O simplemente:

  • Spread = desarmar
  • Rest = armar

Rest Operator

El REST operator (...) sirve para recoger muchos valores en una sola variable (array).

Ejemplo MÁS SIMPLE posible


    function sumar(...numeros) {
      console.log(numeros);
    }

    sumar(1, 2, 3);  // Imprime: [1, 2, 3]
    sumar(5, 10);    // Imprime: [5, 10]

📌 ...numeros = "mete todos los argumentos en un array"

Diferencia clara: SIN vs CON rest operator


    // SIN ... → recibes valores sueltos
    function sumar(a, b) {
      console.log(a, b);
    }
    sumar(5, 10);  // Imprime: 5 10

    // CON ... → recibes un array con todos los valores
    function sumar(...numeros) {
      console.log(numeros);
    }
    sumar(5, 10);  // Imprime: [5, 10]
🧠 Frase CLAVE:
Sin ... → recibes valores sueltos
Con ... → recibes un array con todos los valores

Ahora sumamos sin bucles ni magia


    function sumar(...numeros) {
      return numeros[0] + numeros[1];
    }

    console.log(sumar(5, 10));  // 15
    // No hay bucles, ni métodos, ni magia

Escenario sin REST operator:


    // ❌ Función limitada - solo suma 3 números
    function sumarTresNumeros(a, b, c) {
      return a + b + c;
    }

    console.log(sumarTresNumeros(1, 2, 3)); // 6
    console.log(sumarTresNumeros(1, 2, 3, 4, 5)); // 6 (ignora 4 y 5!)
    // Problema: ¿Y si quiero sumar 5 números? ¿10 números? ¿100 números?

Solución con REST operator:


    // ✅ Función flexible - suma cualquier cantidad de números
    function sum(...numbers) {
      console.log(numbers); // numbers es un ARRAY

      let total = 0;
      for (const num of numbers) {
        total += num;
      }
      return total;
    }

    console.log(sum(1, 2, 3));           // 6
    console.log(sum(1, 2, 3, 4, 5));     // 15
    console.log(sum(10, 20, 30, 40, 50)); // 150

Ejemplo con reduce:


    function sum(...numbers) {
      return numbers.reduce((acc, curr) => acc + curr, 0);
    }

    console.log(sum(1, 2, 3, 4)); // Output: 10

Ejemplo: rest en objetos


    const person = { name: 'Alice', age: 25, country: 'UK', job: 'Developer' };

    const { name, ...rest } = person;
    console.log(name); // Output: Alice
    console.log(rest); // Output: { age: 25, country: 'UK', job: 'Developer' }

Diferencia entre Spread y Rest Operators

Mismo símbolo ..., pero momento diferente:

1️⃣ REST → recoge valores y los mete en un array

👉 Se usa en la definición de la función


    function mostrar(...numeros) {
      console.log(numeros);
    }

    mostrar(1, 2, 3);  // [1, 2, 3]
    mostrar(5, 10);    // [5, 10]

    // Qué pasa realmente:
    // mostrar(1, 2, 3)  → numeros = [1, 2, 3]
    // mostrar(5, 10)    → numeros = [5, 10]

📌 REST = muchos valores → 1 array

2️⃣ SPREAD → saca valores de un array

👉 Se usa al llamar a la función


    function mostrar(a, b, c) {
      console.log(a, b, c);
    }

    const nums = [1, 2, 3];
    mostrar(...nums);  // 1 2 3

    // Qué pasa realmente:
    // mostrar(...nums)
    // → mostrar(nums[0], nums[1], nums[2])
    // → mostrar(1, 2, 3)

📌 SPREAD = 1 array → muchos valores

🔍 Entendiendo: ¿Por qué existe esta línea?

// → mostrar(nums[0], nums[1], nums[2])

Esta línea NO es código que escribas.
Es una traducción mental de lo que SPREAD hace internamente.

Paso 1️⃣ Qué es nums realmente
const nums = [1, 2, 3];

En memoria, piénsalo así:

índice: 0   1   2
valor:  1   2   3

Entonces: nums[0] → 1, nums[1] → 2, nums[2] → 3

Paso 2️⃣ Qué necesita una llamada de función
function mostrar(a, b, c) { ... }

Esta función quiere tres valores separados, no un array:

✅ mostrar(a, b, c)
❌ mostrar([1, 2, 3]) → No entiende esto

Paso 3️⃣ Qué hace ...nums realmente

Cuando JavaScript ve: mostrar(...nums);

Hace esto internamente:

  1. Mira nums
  2. Toma los valores en orden
  3. Los pasa uno por uno como argumentos

Lo cual se convierte en:

mostrar(nums[0], nums[1], nums[2]);

Y como nums[0] = 1, nums[1] = 2, nums[2] = 3

Finalmente se convierte en:

mostrar(1, 2, 3);
Paso 4️⃣ Por qué JavaScript debe hacer esto

Las funciones de JavaScript no desempaquetan arrays mágicamente.

Sin spread: mostrar(nums); → UN argumento
Con spread: mostrar(...nums); → TRES argumentos

Paso 5️⃣ Aclaración muy importante ❗

Esta línea: // mostrar(nums[0], nums[1], nums[2])

  • ✔️ es conceptual
  • ✔️ es cómo se comporta spread
  • ❌ no es algo que normalmente escribas
  • ❌ no es una característica diferente
💡 Momento "clic" en una frase

Spread (...) convierte un array en argumentos separados pasando cada índice como parámetro en orden.

🎯 Regla mental final (guarda esto para siempre)
  • Arrays almacenan valores por índice
  • Funciones reciben valores por posición
  • Spread une ambos

3️⃣ MISMO ... pero distinto momento

Dónde está ... Es Qué hace
En parámetros REST Junta valores en un array
Al llamar SPREAD Separa un array en valores

4️⃣ Ejemplo mínimo lado a lado


    // REST - empaqueta 📦
    function ejemploRest(...args) {
      console.log(args);
    }
    ejemploRest(1, 2, 3); // [1, 2, 3]

    // SPREAD - desempaqueta 🎁
    function ejemploSpread(a, b, c) {
      console.log(a, b, c);
    }
    const args = [1, 2, 3];
    ejemploSpread(...args); // 1 2 3

🧠 Truco mental DEFINITIVO

👉 REST = empaqueta 📦
👉 SPREAD = desempaqueta 🎁

Sin ... → recibes valores sueltos
Con ... → recibes un array con todos los valores
