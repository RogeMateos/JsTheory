Funciones Parciales

¿Qué es una Función Parcial?

Una función parcial es una función que "congela" o "fija" algunos parámetros y devuelve una nueva función que espera el resto de los parámetros.

Es como preparar parte de una receta de antemano para completarla después.

El Problema del Mundo Real

Imagina que trabajas en una tienda online y tienes esta función para calcular precios:


// Función normal: recibe TODO de una vez
const calcularPrecioFinal = (precioBase, descuento, impuesto) => {
  const conDescuento = precioBase - (precioBase * descuento / 100);
  const conImpuesto = conDescuento + (conDescuento * impuesto / 100);
  return conImpuesto;
};

// La usas así:
console.log(calcularPrecioFinal(100, 10, 21)); // 94.5
console.log(calcularPrecioFinal(200, 10, 21)); // 189
console.log(calcularPrecioFinal(50, 10, 21));  // 47.25

Problema

Estás repitiendo 10 (descuento) y 21 (IVA) en cada llamada. ¿Y si siempre usas el mismo descuento e IVA?

La Solución con Función Parcial

Idea: Crear una función que "recuerde" el descuento e IVA, y solo te pida el precio.


// Función parcial: congela descuento e impuesto
const crearCalculadoraConDescuento = (descuento, impuesto) => {
  // Esta función "recuerda" descuento e impuesto
  return (precioBase) => {
    const conDescuento = precioBase - (precioBase * descuento / 100);
    const conImpuesto = conDescuento + (conDescuento * impuesto / 100);
    return conImpuesto;
  };
};

// Ahora creamos UNA calculadora con los valores fijos
const calcularConDescuentoCliente = crearCalculadoraConDescuento(10, 21);

// Y la usamos muchas veces solo pasando el precio:
console.log(calcularConDescuentoCliente(100)); // 94.5
console.log(calcularConDescuentoCliente(200)); // 189
console.log(calcularConDescuentoCliente(50));  // 47.25

¿Qué pasó aquí?

  • crearCalculadoraConDescuento(10, 21) → Fijamos descuento y IVA
  • Nos devuelve una NUEVA función que solo necesita el precio
  • Esa nueva función "recuerda" el 10% y el 21%

Visualicemos el Concepto


// PASO A PASO:

// 1. Definimos la función "madre"
const crearCalculadoraConDescuento = (descuento, impuesto) => {
  console.log(`📦 Guardando descuento: ${descuento}% y impuesto: ${impuesto}%`);

  // 2. Devolvemos una función "hija" que recuerda esos valores
  return (precioBase) => {
    console.log(`💰 Calculando precio final para: ${precioBase}€`);
    const conDescuento = precioBase - (precioBase * descuento / 100);
    const conImpuesto = conDescuento + (conDescuento * impuesto / 100);
    return conImpuesto;
  };
};

// 3. Creamos la función parcial
const calculadora = crearCalculadoraConDescuento(10, 21);
// Console: 📦 Guardando descuento: 10% y impuesto: 21%

// 4. Usamos la función parcial
console.log(calculadora(100));
// Console: 💰 Calculando precio final para: 100€
// Resultado: 94.5

La Analogía de la Vida Real

Piensa en una función parcial como preparar café:


// ❌ Sin función parcial (hacer todo cada vez):
const hacerCafe = (tipoLeche, azucar, tipoCafe, cantidad) => {
  return `${cantidad}ml de ${tipoCafe} con ${tipoLeche} y ${azucar}g de azúcar`;
};

hacerCafe('soja', 0, 'espresso', 30);
hacerCafe('soja', 0, 'espresso', 30);
hacerCafe('soja', 0, 'espresso', 30);
// Repetitivo ↑
    

// ✅ Con función parcial (preparar tu receta):
const crearRecetaCafe = (tipoLeche, azucar, tipoCafe) => {
  return (cantidad) => {
    return `${cantidad}ml de ${tipoCafe} con ${tipoLeche} y ${azucar}g de azúcar`;
  };
};

// Mi receta personal (una sola vez):
const miCafe = crearRecetaCafe('soja', 0, 'espresso');

// Ahora solo digo cuánto quiero:
console.log(miCafe(30));  // "30ml de espresso con soja y 0g de azúcar"
console.log(miCafe(60));  // "60ml de espresso con soja y 0g de azúcar"
console.log(miCafe(120)); // "120ml de espresso con soja y 0g de azúcar"

Ejemplos Progresivos

Ejemplo 1: Saludos Personalizados


// Función normal
const saludar = (saludo, nombre) => {
  return `${saludo}, ${nombre}!`;
};

console.log(saludar('Hola', 'Ana'));
console.log(saludar('Hola', 'Pedro'));
console.log(saludar('Hola', 'María'));


// Función parcial
const crearSaludo = (saludo) => {
  return (nombre) => {
    return `${saludo}, ${nombre}!`;
  };
};

const saludoEspañol = crearSaludo('Hola');
const saludoIngles = crearSaludo('Hello');
const saludoFrances = crearSaludo('Bonjour');

console.log(saludoEspañol('Ana'));   // "Hola, Ana!"
console.log(saludoIngles('Peter'));  // "Hello, Peter!"
console.log(saludoFrances('Marie')); // "Bonjour, Marie!"

Ejemplo 2: Multiplicadores


// Función parcial simple
const crearMultiplicador = (factor) => {
  return (numero) => {
    return numero * factor;
  };
};

// Creamos multiplicadores específicos
const duplicar = crearMultiplicador(2);
const triplicar = crearMultiplicador(3);
const porDiez = crearMultiplicador(10);

console.log(duplicar(5));   // 10
console.log(triplicar(5));  // 15
console.log(porDiez(5));    // 50

// ¡El factor (2, 3, 10) está "congelado" en cada función!

Ejemplo 3: Validadores de Formularios


// Función parcial para validar longitud
const crearValidadorLongitud = (minimo) => {
  return (texto) => {
    if (texto.length >= minimo) {
      return { valido: true, mensaje: 'OK' };
    } else {
      return {
        valido: false,
        mensaje: `Debe tener al menos ${minimo} caracteres`
      };
    }
  };
};

// Creamos validadores específicos
const validarPassword = crearValidadorLongitud(8);
const validarNombre = crearValidadorLongitud(3);
const validarCodigoPostal = crearValidadorLongitud(5);

console.log(validarPassword('abc'));
// { valido: false, mensaje: 'Debe tener al menos 8 caracteres' }

console.log(validarPassword('abc12345'));
// { valido: true, mensaje: 'OK' }

console.log(validarNombre('Jo'));
// { valido: false, mensaje: 'Debe tener al menos 3 caracteres' }

Sintaxis con Arrow Functions (Versión Corta)

Puedes escribir funciones parciales de forma más compacta:


// Versión larga (más clara):
const crearMultiplicador = (factor) => {
  return (numero) => {
    return numero * factor;
  };
};

// Versión corta (mismo resultado):
const crearMultiplicador = (factor) => (numero) => numero * factor;

// Ambas hacen exactamente lo mismo:
const porCinco = crearMultiplicador(5);
console.log(porCinco(3)); // 15

Nota

Las dos versiones son iguales, usa la que te resulte más clara.

Caso Real - Formatear Precios


// ❌ Sin función parcial:
const formatearPrecio = (moneda, decimales, cantidad) => {
  return new Intl.NumberFormat('es-ES', {
    style: 'currency',
    currency: moneda,
    minimumFractionDigits: decimales,
    maximumFractionDigits: decimales
  }).format(cantidad);
};

// Tienes que repetir 'EUR' y 2 cada vez:
console.log(formatearPrecio('EUR', 2, 123.45));
console.log(formatearPrecio('EUR', 2, 678.90));
console.log(formatearPrecio('EUR', 2, 999.99));
    

// ✅ Con función parcial:
const crearFormateadorPrecio = (moneda, decimales) => {
  return (cantidad) => {
    return new Intl.NumberFormat('es-ES', {
      style: 'currency',
      currency: moneda,
      minimumFractionDigits: decimales,
      maximumFractionDigits: decimales
    }).format(cantidad);
  };
};

// Una sola vez: configuras el formateador
const formatearEuros = crearFormateadorPrecio('EUR', 2);

// Muchas veces: solo pasas la cantidad
console.log(formatearEuros(123.45)); // "123,45 €"
console.log(formatearEuros(678.90)); // "678,90 €"
console.log(formatearEuros(999.99)); // "999,99 €"

¿Cuándo Usar Funciones Parciales?

Úsalas cuando

1. Repites los mismos parámetros muchas veces


// En vez de esto:
api.get('/users', { auth: token, format: 'json' });
api.get('/products', { auth: token, format: 'json' });
api.get('/orders', { auth: token, format: 'json' });

// Haz esto:
const apiConAuth = crearApiConConfig(token, 'json');
apiConAuth('/users');
apiConAuth('/products');
apiConAuth('/orders');

2. Quieres crear "versiones especializadas" de una función


const calcularImpuesto = (tasa) => (precio) => precio * tasa / 100;

const ivaEspaña = calcularImpuesto(21);
const ivaUK = calcularImpuesto(20);
const ivaAlemania = calcularImpuesto(19);

3. Trabajas con configuraciones que no cambian


const logger = crearLogger('produccion', 'errores.log');
logger('Error 404');
logger('Error 500');
// No tienes que repetir 'produccion' y 'errores.log' cada vez

NO las uses cuando

  • Solo llamas a la función una o dos veces
  • Todos los parámetros cambian siempre
  • Hace el código más difícil de entender

Resumen Final

Definición

Una función parcial es una función que "congela" algunos parámetros y devuelve una nueva función que espera los parámetros restantes.

Patrón General


// Estructura:
const crearFuncionParcial = (parametrosQueSeCongelan) => {
  return (parametrosQueCambian) => {
    // Lógica que usa AMBOS grupos de parámetros
  };
};

// Uso:
const funcionEspecializada = crearFuncionParcial(valoresFijos);
funcionEspecializada(valoresVariables);

Beneficios

  • Menos repetición de código
  • Funciones más especializadas y claras
  • Código más mantenible y reutilizable
  • Configuración separada del uso
