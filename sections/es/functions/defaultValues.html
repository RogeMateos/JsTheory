Asignar valores por defecto

Operador OR (`||`) como fallback

Podemos usar || para asignar un valor cuando el argumento es undefined, null u otro falsy.

Sirve para que la función sea predecible aunque falten argumentos.

Ejemplo básico:


        function greet(name) {
          name = name || 'Your name here';
          console.log('Hello ' + name);
        }
  
        greet('Tony'); // Output: Hello Tony
        greet();       // Output: Hello Your name here

Si no llega name, usa "Your name here" porque || devuelve el primer valor truthy.

Cómo funciona OR

Evalúa de izquierda a derecha y devuelve el primer truthy; si no hay, devuelve el último.


  // Example 1
  console.log(true || false);  // Output: true
  
  // Example 2
  console.log(undefined || 'hello'); // Output: hello
  
  // Example 3
  console.log(0 || 'default');  // Output: default

En los ejemplos: true es truthy, undefined es falsy, 0 es falsy.

Asignar valor por defecto en funciones

Si el parámetro es undefined, || usa el valor de respaldo.


        function greet(name) {
          name = name || 'Your name here';
          console.log('Hello ' + name);
        }
  
        greet('Tony');       // Output: Hello Tony
        greet(undefined);    // Output: Hello Your name here

Si es undefined, null o cadena vacía, cae al valor por defecto.

Problema

0, false o '' son falsy y disparan el valor por defecto:


        greet(0);  // Output: Hello Your name here

Para permitirlos, usa el operador de fusión nula (??) que solo cae en null o undefined:


        function greet(name) {
          name = name ?? 'Your name here';
          console.log('Hello ' + name);
        }
  
        greet(0);  // Output: Hello 0

?? solo aplica cuando es null o undefined.
