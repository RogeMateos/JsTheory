Entorno léxico y contexto de ejecución

Léxico

Depende de dónde está escrito el código. Marca el alcance y visibilidad según la posición física.


      function outerFunction() {
          var outerVar = 'Estoy afuera';

          function innerFunction() {
              var innerVar = 'Estoy adentro';
              console.log(outerVar); // Accede a outerVar
          }

          innerFunction();
          console.log(innerVar); // Error: innerVar no está definida
      }

      outerFunction();

Explicación

  • outerVar vive en el entorno léxico de outerFunction y se ve en funciones internas.
  • innerVar vive solo dentro de innerFunction.

El entorno léxico define alcance según la posición en el código.

Contexto de ejecución

Es el “marco” que se crea cada vez que se invoca una función. Contiene qué variables y funciones están disponibles en ese instante.


      var globalVar = 'Soy global';

      function firstFunction() {
          var firstVar = 'Estoy en firstFunction';

          function secondFunction() {
              var secondVar = 'Estoy en secondFunction';
              console.log(globalVar);
              console.log(firstVar);
              console.log(secondVar);
          }

          secondFunction();
      }

      firstFunction();

Explicación

  • Al llamar firstFunction se crea su contexto con globalVar y firstVar.
  • Al llamar secondFunction, su contexto incluye también secondVar.

Cada llamada agrega un contexto a la pila; el activo está arriba.

Resumen

Entorno léxico:

  • Ubicación física en el código.
  • Alcance según dónde se escribe.
  • Estático.

Contexto de ejecución:

  • El código que se está ejecutando ahora.
  • Maneja qué variables/funciones están accesibles.
  • Dinámico: cambia por llamada.

    var globalVar = 'Soy global';

    function firstFunction() {
        var firstVar = 'Estoy en firstFunction';

        function secondFunction() {
            var secondVar = 'Estoy en secondFunction';

            function thirdFunction() {
                var thirdVar = 'Estoy en thirdFunction';
                console.log(globalVar);
                console.log(firstVar);
                console.log(secondVar);
                console.log(thirdVar);
            }

            thirdFunction();
        }

        secondFunction();
    }

    firstFunction();
