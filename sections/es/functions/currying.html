Currying en JavaScript

¿Qué es Currying?

Currying es una técnica que consiste en transformar una función que recibe varios parámetros en una serie de funciones que reciben un parámetro cada una.

Transformación

👉 Antes:

funcion(a, b, c)

👉 Después (curry):

funcion(a)(b)(c)

Ejemplo SIN Currying (normal)

Una función normal recibe todo de golpe:


function sumar(a, b, c) {
  return a + b + c;
}

sumar(1, 2, 3); // 6

Aquí

  • Tengo que pasar los 3 valores siempre
  • No puedo reutilizar "parte" de la función

El MISMO Ejemplo CON Currying (paso a paso)


function sumarCurry(a) {
  return function (b) {
    return function (c) {
      return a + b + c;
    };
  };
}

Esta función no calcula nada todavía
👉 Solo va guardando valores poco a poco

Cómo se Usa (muy claro)

Forma Encadenada


sumarCurry(1)(2)(3); // 6

Forma Paso a Paso (la más importante para entender)


const pasoB = sumarCurry(1); // guarda a = 1
const pasoC = pasoB(2);      // guarda b = 2
const resultado = pasoC(3);  // usa a + b + c

console.log(resultado); // 6

¿Qué Está Pasando Realmente? (clave mental)

Cada función recuerda lo que recibió antes

Ejemplo:

const pasoB = sumarCurry(1);

pasoB es:

  • Una función
  • Con una mochila donde dentro está: a = 1

Eso se llama closure.

Ejemplo MUY CLARO y Real (multiplicar)


const multiplicar = (a) => (b) => a * b;

Uso:


const por2 = multiplicar(2); // guarda a = 2

por2(5);  // 10
por2(8);  // 16
por2(10); // 20

Aquí se ve clarísimo

  • Creo una función especial "por2"
  • No vuelvo a pasar el 2
  • Reutilizo el comportamiento

Otro Ejemplo Cotidiano (saludos)


const saludar = (saludo) => (nombre) => {
  return `${saludo}, ${nombre}`;
};

const hola = saludar("Hola");
const adios = saludar("Adiós");

hola("Roge");  // Hola, Roge
hola("Ana");   // Hola, Ana
adios("Roge"); // Adiós, Roge

¿Por Qué Existe el Currying?

Sirve para

  • Reutilizar funciones
  • Guardar configuraciones
  • Crear funciones más específicas a partir de una general

👉 En vez de repetir:


sumar(1, 2, 3);
sumar(1, 2, 4);
sumar(1, 2, 10);

Haces:


const sumar12 = sumarCurry(1)(2);
sumar12(3);  // 6
sumar12(4);  // 7
sumar12(10); // 13

Más Ejemplos Prácticos

Ejemplo 1: Descuentos en Tienda


const aplicarDescuento = (descuento) => (precio) => {
  return precio - (precio * descuento / 100);
};

const descuento10 = aplicarDescuento(10);
const descuento20 = aplicarDescuento(20);

console.log(descuento10(100)); // 90
console.log(descuento10(50));  // 45
console.log(descuento20(100)); // 80

Ejemplo 2: Validadores


const crearValidador = (minLength) => (text) => {
  return text.length >= minLength;
};

const validarPassword = crearValidador(8);
const validarUsername = crearValidador(3);

console.log(validarPassword("abc"));      // false
console.log(validarPassword("abc12345")); // true
console.log(validarUsername("Jo"));       // false
console.log(validarUsername("Joe"));      // true

Ejemplo 3: Formateo de Mensajes


const crearMensaje = (tipo) => (usuario) => (contenido) => {
  return `[${tipo}] Usuario ${usuario}: ${contenido}`;
};

const error = crearMensaje("ERROR");
const info = crearMensaje("INFO");

const errorRoge = error("Roge");
const infoAna = info("Ana");

console.log(errorRoge("Archivo no encontrado"));
// [ERROR] Usuario Roge: Archivo no encontrado

console.log(infoAna("Operación exitosa"));
// [INFO] Usuario Ana: Operación exitosa

Currying vs Partial Functions

Diferencia Clave

Currying: Cada función recibe exactamente UN parámetro

const curry = (a) => (b) => (c) => a + b + c;

Partial Functions: Puedes fijar varios parámetros a la vez


const partial = (a, b) => {
  return (c) => a + b + c;
};

Resumen Ultra Corto (para memorizar)

Conceptos Clave

  • Currying = f(a, b, c) → f(a)(b)(c)
  • Cada función recibe un solo parámetro
  • Las funciones recuerdan valores anteriores (closure)
  • Sirve para reutilizar y especializar funciones

Ventajas

  • ✅ Código más reutilizable
  • ✅ Funciones más especializadas
  • ✅ Configuraciones guardadas
  • ✅ Composición de funciones más fácil
