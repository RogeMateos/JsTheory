Closures

¿Qué es un closure?

Una función recuerda y puede usar variables de su scope externo, incluso después de que esa función externa ya terminó.

Ocurre cuando una función interna puede acceder a las variables de la función externa incluso después de que la externa terminó de ejecutarse.


      function greet(name) {
          if (validateName()) {
              console.log('Hola ' + name);
          }

          function validateName() {
              return (name.length > 1);
          }
      }

      greet(''); // No output, name is too short
      greet('Miguel'); // Outputs: Hola Miguel

      validateName('pepe'); // Error: validateName is not defined
    

      function outerFunction() {
          let outerVariable = 'I am outside!';

          function innerFunction() {
              console.log(outerVariable);
          }

          return innerFunction;
      }

      const closure = outerFunction();
      closure();  // Output: I am outside!
