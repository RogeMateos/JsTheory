Tutorial de Promesas en JavaScript 🚀

¿Qué es una Promesa?

Una promesa es un objeto que representa un valor que puede estar disponible ahora, en el futuro, o nunca. Es como pedir comida a domicilio: cuando haces el pedido, obtienes una "promesa" de que tu comida llegará, pero aún no la tienes.

Estados de una Promesa

Una promesa puede estar en tres estados:

  1. Pendiente: La operación aún no se ha completado
  2. Resuelta: La operación se completó exitosamente
  3. Rechazada: La operación falló

Creando tu Primera Promesa

const myFirstPromise = new Promise((resolve, reject) => {
  // Simular una operación que tarda 2 segundos
  setTimeout(() => {
    const successful = true;

    if (successful) {
      resolve("¡Operación exitosa!"); // Todo salió bien
    } else {
      reject("Ocurrió un error"); // Algo falló
    }
  }, 2000);
});

Consumiendo una Promesa

Para trabajar con el resultado de una promesa, usamos .then(), .catch() y .finally(): 

myFirstPromise
  .then((result) => {
    console.log(result); // Se ejecuta si la promesa se resuelve
  })
  .catch((error) => {
    console.log(error); // Se ejecuta si la promesa es rechazada
  })
  .finally(() => {
    console.log("Esto siempre se ejecuta"); // Se ejecuta sin importar el resultado
  });

Ejemplo Práctico: Pedido de Pizza 🍕

function orderPizza(type) {
  return new Promise((resolve, reject) => {
    console.log(`Preparando tu pizza de ${type}...`);

    setTimeout(() => {
      const availablePizzas = ['pepperoni', 'margherita', 'hawaiana'];

      if (availablePizzas.includes(type)) {
        resolve(`¡Tu pizza de ${type} está lista! 🍕`);
      } else {
        reject(`Lo sentimos, no tenemos pizza de ${type} 😢`);
      }
    }, 3000);
  });
}

// Usando la promesa
orderPizza('pepperoni')
  .then((message) => {
    console.log(message); // ¡Tu pizza de pepperoni está lista! 🍕
  })
  .catch((error) => {
    console.log(error);
  });

Encadenando Promesas

Una de las grandes ventajas de las promesas es que podemos encadenarlas fácilmente: 

function step1() {
  return new Promise((resolve) => {
    setTimeout(() => {
      console.log("Paso 1 completado");
      resolve();
    }, 1000);
  });
}

function step2() {
  return new Promise((resolve) => {
    setTimeout(() => {
      console.log("Paso 2 completado");
      resolve();
    }, 1000);
  });
}

function step3() {
  return new Promise((resolve) => {
    setTimeout(() => {
      console.log("Paso 3 completado");
      resolve();
    }, 1000);
  });
}

// Encadenando las promesas
step1()
  .then(() => step2())
  .then(() => step3())
  .then(() => {
    console.log("¡Todos los pasos completados! 🎉");
  });

Salida:

Paso 1 completado
Paso 2 completado
Paso 3 completado
¡Todos los pasos completados! 🎉

Ejemplo Real: Cargando Datos de Usuario

function loadUser(id) {
  return new Promise((resolve, reject) => {
    console.log(`Buscando usuario ${id}...`);

    setTimeout(() => {
      const users = {
        1: { name: 'Ana', age: 25 },
        2: { name: 'Carlos', age: 30 },
        3: { name: 'María', age: 28 }
      };

      if (users[id]) {
        resolve(users[id]);
      } else {
        reject('Usuario no encontrado');
      }
    }, 2000);
  });
}

function loadOrders(user) {
  return new Promise((resolve) => {
    console.log(`Cargando pedidos de ${user.name}...`);

    setTimeout(() => {
      resolve([
        { product: 'Laptop', price: 1200 },
        { product: 'Mouse', price: 25 }
      ]);
    }, 1500);
  });
}

// Encadenando operaciones
loadUser(1)
  .then((user) => {
    console.log(`Usuario encontrado: ${user.name}`);
    return loadOrders(user);
  })
  .then((orders) => {
    console.log('Pedidos:', orders);
  })
  .catch((error) => {
    console.log('Error:', error);
  });

❌ Callback Hell vs ✅ Promesas

Antes (Callback Hell):

operation1(function(result1) {
  operation2(result1, function(result2) {
    operation3(result2, function(result3) {
      operation4(result3, function(result4) {
        // ¡Esto es difícil de leer! 😵
      });
    });
  });
});

Ahora (Con Promesas):

operation1()
  .then(result1 => operation2(result1))
  .then(result2 => operation3(result2))
  .then(result3 => operation4(result3))
  .then(result4 => {
    // ¡Mucho más limpio! 😊
  })
  .catch(error => console.log(error));

Los Dos Lados de una Promesa

Piensa en una promesa como un contrato entre dos partes:

🏭 Lado 1: EL CREADOR de la promesa (El Productor)

const myPromise = new Promise((resolve, reject) => {
  // DENTRO de aquí estoy CREANDO la promesa
  // Yo decido qué pasa

  setTimeout(() => {
    const successful = true;

    if (successful) {
      resolve("¡Funcionó!"); // Notifico que salió bien
    } else {
      reject("¡Error!"); // Notifico que salió mal
    }
  }, 2000);
});

🛍️ Lado 2: EL USUARIO de la promesa (El Consumidor)

myPromise
  .then((result) => {
    // Aquí RECIBO la notificación de que salió bien
    console.log(result);
  })
  .catch((error) => {
    // Aquí RECIBO la notificación de que salió mal
    console.log(error);
  })
  .finally(() => {
    // Esto SIEMPRE se ejecuta
    console.log("Terminé de esperar");
  });

📝 Analogía: Pedido de Comida

Déjame explicarlo con un ejemplo del mundo real:

👨‍🍳 EL RESTAURANTE (Crea la promesa)

function prepareFood(dish) {
  // El restaurante CREA una promesa
  return new Promise((resolve, reject) => {
    console.log(`Cocinando ${dish}...`);

    setTimeout(() => {
      const ingredientsAvailable = true;

      if (ingredientsAvailable) {
        // El chef NOTIFICA que está listo
        resolve(`¡Tu ${dish} está listo! 🍽️`);
      } else {
        // El chef NOTIFICA que hay un problema
        reject(`No tenemos ingredientes para ${dish} 😞`);
      }
    }, 3000);
  });
}

En este lado:

  • resolve = "✅ Está listo, aquí está tu comida"
  • reject = "❌ Lo sentimos, no pudimos hacerlo"

🙋‍♂️ EL CLIENTE (Usa la promesa)

prepareFood("pizza")
  .then((message) => {
    // El cliente RECIBE la buena noticia
    console.log(message); // "¡Tu pizza está lista! 🍽️"
    console.log("¡A comer!");
  })
  .catch((error) => {
    // El cliente RECIBE la mala noticia
    console.log(error);
    console.log("Tendré que pedir otra cosa...");
  })
  .finally(() => {
    // Pase lo que pase, el cliente hace esto
    console.log("Gracias por el servicio");
  });

En este lado:

  • .then() = "Recibo mi comida y estoy feliz"
  • .catch() = "Me notificaron que hubo un problema"
  • .finally() = "De cualquier forma, agradezco el servicio"

🔄 Paso a Paso: Flujo Completo

// PASO 1: Crear la promesa
function doSomething() {
  console.log("🏭 CREANDO la promesa...");

  return new Promise((resolve, reject) => {
    console.log("⏳ Trabajando en segundo plano...");

    setTimeout(() => {
      const randomNumber = Math.random();

      if (randomNumber > 0.5) {
        console.log("✅ RESOLVIENDO la promesa");
        resolve("¡Éxito! Número: " + randomNumber);
      } else {
        console.log("❌ RECHAZANDO la promesa");
        reject("¡Error! Número muy bajo: " + randomNumber);
      }
    }, 2000);
  });
}

// PASO 2: Usar la promesa
console.log("🛍️ USANDO la promesa...");

doSomething()
  .then((result) => {
    console.log("😊 RECIBÍ éxito:", result);
  })
  .catch((error) => {
    console.log("😢 RECIBÍ error:", error);
  })
  .finally(() => {
    console.log("🏁 TERMINÉ de esperar");
  });

console.log("🚀 El código síncrono continúa...");

📊 Salida si sale BIEN (número > 0.5):

🛍️ USANDO la promesa...
🏭 CREANDO la promesa...
⏳ Trabajando en segundo plano...
🚀 El código síncrono continúa...
✅ RESOLVIENDO la promesa
😊 RECIBÍ éxito: ¡Éxito! Número: 0.7234
🏁 TERMINÉ de esperar

📊 Salida si sale MAL (número < 0.5):

🛍️ USANDO la promesa...
🏭 CREANDO la promesa...
⏳ Trabajando en segundo plano...
🚀 El código síncrono continúa...
❌ RECHAZANDO la promesa
😢 RECIBÍ error: ¡Error! Número muy bajo: 0.3421
🏁 TERMINÉ de esperar

🎯 Comparación Directa

Dentro de new Promise Fuera con .then/.catch
Yo CREO la promesa Yo USO la promesa
Yo DECIDO qué pasa Yo ESPERO a ser notificado
Yo llamo resolve() cuando sale bien Yo escribo .then() para recibir el éxito
Yo llamo reject() cuando sale mal Yo escribo .catch() para recibir el error
Yo soy el PRODUCTOR Yo soy el CONSUMIDOR

🔗 Ejemplo con Ambos Lados Claros

// ============================================
// 🏭 LADO PRODUCTOR: Crear la promesa
// ============================================
function verifyAge(age) {
  return new Promise((resolve, reject) => {
    console.log("Verificando edad...");

    setTimeout(() => {
      if (age >= 18) {
        // Yo (productor) notifico TODO ESTÁ BIEN
        resolve({
          message: "Acceso concedido",
          adult: true
        });
      } else {
        // Yo (productor) notifico HAY UN PROBLEMA
        reject({
          message: "Eres menor de edad",
          adult: false
        });
      }
    }, 1000);
  });
}

// ============================================
// 🛍️ LADO CONSUMIDOR: Usar la promesa
// ============================================
verifyAge(20)
  .then((response) => {
    // Yo (consumidor) recibo la buena noticia
    console.log("✅", response.message);
    console.log("Puedes entrar al sitio");
  })
  .catch((response) => {
    // Yo (consumidor) recibo la mala noticia
    console.log("❌", response.message);
    console.log("No puedes entrar");
  })
  .finally(() => {
    // Yo (consumidor) hago limpieza
    console.log("Verificación completada");
  });

Puntos Clave 🎯

  1. Las promesas son asíncronas: El código continúa ejecutándose mientras esperan
  2. Usa .then() para el éxito: Maneja el caso cuando todo sale bien
  3. Usa .catch() para errores: Captura cualquier error que ocurra
  4. .finally() siempre se ejecuta: Útil para limpiar recursos
  5. Las promesas se pueden encadenar: Evita el callback hell

💡 Resumen Final

  1. resolve y reject = Están DENTRO de la promesa. Los llamas para notificar qué pasó
  2. .then() y .catch() = Están FUERA de la promesa. Los usas para recibir las noticias
  3. Son complementarios: Uno crea, el otro consume
  4. Siempre trabajan juntos:
    • Si llamas resolve() → .then() se ejecuta
    • Si llamas reject() → .catch() se ejecuta

Ejercicio Práctico 💪

Intenta crear una función que simule descargar un archivo:

function downloadFile(fileName) {
  return new Promise((resolve, reject) => {
    console.log(`Descargando ${fileName}...`);

    setTimeout(() => {
      const success = Math.random() > 0.3; // 70% de tasa de éxito

      if (success) {
        resolve(`${fileName} descargado exitosamente ✓`);
      } else {
        reject(`Error descargando ${fileName} ✗`);
      }
    }, 2000);
  });
}

// ¡Pruébalo!
downloadFile('documento.pdf')
  .then(message => console.log(message))
  .catch(error => console.log(error));

¡Recuerda! Las promesas hacen el código asíncrono más fácil de leer y mantener. Son la base para entender async/await, que veremos más adelante. 🚀
