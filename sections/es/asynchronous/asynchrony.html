Resumen de conceptos clave

Tema central

Asincronía en JavaScript: de un hilo único a manejar varias tareas sin bloquear.

Conceptos clave

  • Single-thread: ejecuta línea a línea
  • Problema: operaciones largas bloquearían todo
  • Solución: APIs async + event loop para no bloquear
  • Entornos: navegador (Web APIs) y Node.js

Analogía

Restaurante:

  • Síncrono: un mesero atiende una mesa completa antes de la siguiente.
  • Asíncrono: toma pedidos, cocina en paralelo y sirve cuando estén listos.

Práctico: descargar un archivo grande sin impedir que el usuario siga navegando.

Código ilustrativo

// ❌ Bloqueante
function queryDatabase() {
  // Simula 5s bloqueando
  let start = Date.now();
  while (Date.now() - start < 5000) {
    // esperando...
  }
  return "Data retrieved";
}

// ✅ Asíncrono
function queryDatabaseAsync() {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve("Data retrieved");
    }, 5000);
  });
  // La app sigue corriendo mientras espera
}

Buenas prácticas

  1. No bloquear: usa async en tareas largas
  2. Aprovecha hardware: delega I/O al sistema
  3. UX: permite interacción mientras se espera
  4. Feedback: indicadores de carga

Ejercicios

1) Simular operación lenta

// Simula llamada a API sin bloquear
function simulateAPI() {
  console.log("Inicio petición...");

  setTimeout(() => {
    console.log("Datos recibidos!");
  }, 2000);

  console.log("Petición enviada, sigo con otras tareas");
}

Crea dos versiones de la misma función y compara su comportamiento.
