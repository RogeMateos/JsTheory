Event Loop: paso a paso

¿Qué es?

Es el ciclo que coordina la ejecución asíncrona. Revisa continuamente qué ejecutar en un solo hilo.

Componentes

  • Call Stack: ejecuta código síncrono
  • Web APIs/Node.js: manejan operaciones asíncronas
  • Task Queue / Microtask Queue: colas de callbacks

Flujo

1. Ejecuta el Call Stack

Corre el código síncrono en orden.

2. Encuentra operaciones async

fetch, timers, eventos… se delegan.

3. Delegación

Web APIs/Node.js gestionan esas tareas.

4. Terminan

Cuando acaban, generan un callback.

5. Encolado

Callbacks van a Task Queue o Microtask Queue.

6. ¿Stack vacío?

El loop revisa si el stack está libre.

7. Mover tareas

Si está vacío, mueve primero microtareas y luego tareas.

8. Repetir

Vuelve al paso 1.

Ejemplo

console.log('Start'); // 1. Stack

setTimeout(() => {
  console.log('Timeout'); // Task Queue
}, 0);

Promise.resolve().then(() => {
  console.log('Promise'); // Microtask
});

console.log('End'); // 2. Stack

// Output order:
// Start
// End
// Promise
// Timeout

¿Por qué ese orden?

  • Stack: Start, End
  • Microtareas primero: Promise
  • Luego tareas: Timeout

Claves

  • Loop infinito coordinando ejecución
  • Síncrono: Stack inmediato
  • Async delega a Web APIs/Node
  • Callbacks a colas (micro y macro)
  • Prioridad: microtareas > tareas
  • Solo mueve cuando el Stack está libre

Por qué importa

Explica el orden de ejecución y ayuda a escribir código async predecible.
