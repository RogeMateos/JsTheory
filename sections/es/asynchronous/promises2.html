Las Dos Caras de una Promesa

Entendiendo el lado productor y consumidor

Introducción

Piensa en una promesa como un contrato entre dos partes:

🏭 Lado 1: EL QUE CREA la promesa (El Productor)

const miPromesa = new Promise((resolve, reject) => {
  // Aquí DENTRO estoy CREANDO la promesa
  // Yo decido qué pasa

  setTimeout(() => {
    const exitoso = true;

    if (exitoso) {
      resolve("¡Funcionó!"); // YO aviso que salió bien
    } else {
      reject("¡Error!"); // YO aviso que salió mal
    }
  }, 2000);
});

🛍️ Lado 2: EL QUE USA la promesa (El Consumidor)

miPromesa
  .then((resultado) => {
    // Aquí RECIBO la notificación de que salió bien
    console.log(resultado);
  })
  .catch((error) => {
    // Aquí RECIBO la notificación de que salió mal
    console.log(error);
  })
  .finally(() => {
    // Esto se ejecuta SIEMPRE
    console.log("Terminé de esperar");
  });

📝 Analogía: Pedido de Comida

Déjame explicarlo con un ejemplo del mundo real:

👨‍🍳 EL RESTAURANTE (Crea la promesa)

function prepararComida(plato) {
  // El restaurante CREA una promesa
  return new Promise((resolve, reject) => {
    console.log(`Cocinando ${plato}...`);

    setTimeout(() => {
      const ingredientesDisponibles = true;

      if (ingredientesDisponibles) {
        // El chef AVISA que está listo
        resolve(`Tu ${plato} está listo! 🍽️`);
      } else {
        // El chef AVISA que hay un problema
        reject(`No tenemos ingredientes para ${plato} 😞`);
      }
    }, 3000);
  });
}

En este lado:

  • resolve = "✅ Está listo, aquí tienes tu comida"
  • reject = "❌ Lo siento, no pudimos hacerlo"

🙋‍♂️ EL CLIENTE (Usa la promesa)

prepararComida("pizza")
  .then((mensaje) => {
    // El cliente RECIBE la buena noticia
    console.log(mensaje); // "Tu pizza está listo! 🍽️"
    console.log("¡A comer!");
  })
  .catch((error) => {
    // El cliente RECIBE la mala noticia
    console.log(error);
    console.log("Tendré que pedir otra cosa...");
  })
  .finally(() => {
    // Pase lo que pase, el cliente hace esto
    console.log("Gracias por el servicio");
  });

En este lado:

  • .then() = "Recibo mi comida y estoy feliz"
  • .catch() = "Me avisaron que hubo un problema"
  • .finally() = "De todas formas, agradezco el servicio"

🔄 Paso a Paso: Flujo Completo

// PASO 1: Creo la promesa
function hacerAlgo() {
  console.log("🏭 CREANDO la promesa...");

  return new Promise((resolve, reject) => {
    console.log("⏳ Trabajando en segundo plano...");

    setTimeout(() => {
      const numeroAleatorio = Math.random();

      if (numeroAleatorio > 0.5) {
        console.log("✅ RESUELVO la promesa");
        resolve("¡Éxito! Número: " + numeroAleatorio);
      } else {
        console.log("❌ RECHAZO la promesa");
        reject("Error! Número muy bajo: " + numeroAleatorio);
      }
    }, 2000);
  });
}

// PASO 2: Uso la promesa
console.log("🛍️ USANDO la promesa...");

hacerAlgo()
  .then((resultado) => {
    console.log("😊 RECIBÍ éxito:", resultado);
  })
  .catch((error) => {
    console.log("😢 RECIBÍ error:", error);
  })
  .finally(() => {
    console.log("🏁 TERMINÉ de esperar");
  });

console.log("🚀 Código síncrono continúa...");

🛍️ USANDO la promesa...
🏭 CREANDO la promesa...
⏳ Trabajando en segundo plano...
🚀 Código síncrono continúa...
✅ RESUELVO la promesa
😊 RECIBÍ éxito: ¡Éxito! Número: 0.7234
🏁 TERMINÉ de esperar

📊 Salida si sale MAL (número < 0.5):

🛍️ USANDO la promesa...
🏭 CREANDO la promesa...
⏳ Trabajando en segundo plano...
🚀 Código síncrono continúa...
❌ RECHAZO la promesa
😢 RECIBÍ error: Error! Número muy bajo: 0.3421
🏁 TERMINÉ de esperar

🎯 Comparación Directa

Dentro de new Promise Fuera con .then/.catch
Yo CREO la promesa Yo USO la promesa
Yo DECIDO qué pasa Yo ESPERO a que me avisen
Llamo a resolve() cuando sale bien Escribo .then() para recibir el éxito
Llamo a reject() cuando sale mal Escribo .catch() para recibir el error
Soy el PRODUCTOR Soy el CONSUMIDOR

🔗 Ejemplo con Ambos Lados Claros

// ============================================
// 🏭 LADO PRODUCTOR: Creo la promesa
// ============================================
function verificarEdad(edad) {
  return new Promise((resolve, reject) => {
    console.log("Verificando edad...");

    setTimeout(() => {
      if (edad >= 18) {
        // YO (productor) aviso que TODO BIEN
        resolve({
          mensaje: "Acceso permitido",
          adulto: true
        });
      } else {
        // YO (productor) aviso que HAY PROBLEMA
        reject({
          mensaje: "Eres menor de edad",
          adulto: false
        });
      }
    }, 1000);
  });
}

// ============================================
// 🛍️ LADO CONSUMIDOR: Uso la promesa
// ============================================
verificarEdad(20)
  .then((respuesta) => {
    // YO (consumidor) recibo la buena noticia
    console.log("✅", respuesta.mensaje);
    console.log("Puedes entrar al sitio");
  })
  .catch((respuesta) => {
    // YO (consumidor) recibo la mala noticia
    console.log("❌", respuesta.mensaje);
    console.log("No puedes entrar");
  })
  .finally(() => {
    // YO (consumidor) hago limpieza
    console.log("Verificación completada");
  });

💡 Resumen Final

  1. resolve y reject = Están DENTRO de la promesa. Tú los llamas para avisar qué pasó
  2. .then() y .catch() = Están FUERA de la promesa. Tú los usas para recibir las noticias
  3. Son complementarios: Uno crea, el otro consume
  4. Siempre trabajan juntos:
    • Si llamas resolve() → se ejecuta .then()
    • Si llamas reject() → se ejecuta .catch()
