Código síncrono

Resumen

Diferencia entre código bloqueante y la necesidad de usar async.

Temas

  • Comportamiento síncrono
  • Problema de bloqueo en tareas lentas
  • Por qué usar asincronía

Ejemplo

// Síncrono básico
console.log("start");
console.log("end");

// Bloqueante
console.log("start");
for (let i = 0; i < 1000000000; i++) {
  // Time-consuming operation
}
console.log("end");

Idea: una tarea lenta congela todo lo demás.

Analogía

Cocina:

  1. Pones agua a hervir
  2. Te quedas mirando la olla sin hacer nada
  3. Recién después cortas las verduras

Ineficiente: podrías cortar mientras hierve.

Buenas prácticas

  • Operaciones > 1s → hacerlas asíncronas
  • Consultas/HTTP siempre async
  • Evita congelar la UI

Ejercicios

  1. Simulador bloqueante: bucle hasta 100,000,000 y mide con console.time
  2. Identifica 3 operaciones que deban ser async (subir archivos, peticiones, etc.)

Conexión

  • React: useEffect y fetch async
  • UX: no congelar la interfaz
  • Loaders/estilos dinámicos sin bloquear
