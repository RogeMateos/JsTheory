Diferencia entre ?. y ?? (Optional Chaining vs Nullish Coalescing)

Dos operadores diferentes que siempre aparecen juntos en JavaScript moderno

🎯 Definición Simple para Entrevistas

Optional Chaining (?.)

?. = "si existe, continúa"

Evita errores cuando algo podría no existir.

Nullish Coalescing (??)

?? = "si es null o undefined, usa esto"

Proporciona un valor por defecto.

1️⃣ Optional Chaining (?.)

¿Qué hace?

Evita errores cuando intentas acceder a propiedades que podrían no existir.

const user = null

// Sin ?.:
console.log(user.name)  // ❌ Error: Cannot read properties of null

// Con ?.:
console.log(user?.name) // ✅ undefined (sin error)

Traducción mental

?. = "si existe, accede a ello. Si no existe, devuelve undefined"

2️⃣ Nullish Coalescing (??)

¿Qué hace?

Proporciona un valor por defecto cuando algo es null o undefined.

const name = null

console.log(name ?? "Anonymous")  // "Anonymous"

const age = 0
console.log(age ?? 18)  // 0 (porque 0 no es null/undefined)

Traducción mental

?? = "si esto es null o undefined, usa el valor de la derecha"

📊 Comparación Directa

Optional Chaining (?.)
const user = {
  profile: {
    name: "Miguel"
  }
}

user?.profile?.name
// → "Miguel"

user?.profile?.city
// → undefined (sin error)
Nullish Coalescing (??)
const username = null

username ?? "Guest"
// → "Guest"

const price = 0

price ?? 100
// → 0

Punto clave

?. evita errores de acceso

?? proporciona un valor alternativo

🔥 Ejemplo Real: Usado Juntos

El caso más común

const user = {
  profile: {
    name: "Roge"
  }
}

const username = user?.profile?.name ?? "Anonymous"
console.log(username)  // "Roge"

Cómo JavaScript lo interpreta

  1. Intenta acceder a user.profile.name
  2. Si no existe, devuelve undefined (por el ?.)
  3. Entonces ?? comprueba: ¿es undefined?
  4. Si es undefined, usa "Anonymous"

⚠️ Cuando Falta Información

Ejemplo cuando user es null

const user = null

const username = user?.profile?.name ?? "Anonymous"
console.log(username)  // "Anonymous"

¿Por qué funciona?

user?.profile?.name    // → undefined
undefined ?? "Anonymous" // → "Anonymous"

🚨 Confusión Común: ?? vs ||

No es lo mismo || que ??

|| considera muchos valores como "falsy":

false
0
""
null
undefined

Ejemplo con ||

const price = 0

console.log(price || 10)  // 10
// ❌ Incorrecto: 0 es un valor válido

Ejemplo con ??

const price = 0

console.log(price ?? 10)  // 0
// ✅ Correcto: 0 no es null/undefined

⚡ Importante

?? solo revisa null y undefined

|| revisa cualquier valor falsy

💡 Ejemplo Práctico: API Response

Datos de una API que podrían estar incompletos

const response = {
  data: {
    user: {
      name: "Miguel",
      profile: {
        city: "Madrid"
      }
    }
  }
}

const city = response?.data?.user?.profile?.city ?? "Unknown city"
console.log(city)  // "Madrid"

Si faltan datos

const response = {
  data: null
}

const city = response?.data?.user?.profile?.city ?? "Unknown city"
console.log(city)  // "Unknown city"

🎯 Tabla de Decisión Rápida

Situación Usa Ejemplo
Acceder a propiedad que podría no existir ?. user?.name
Dar valor por defecto ?? name ?? "Guest"
Acceder seguro + valor por defecto ?. y ?? user?.name ?? "Guest"

🔥 Muy Común en React

Ejemplo típico en componentes

// En props que podrían no venir
const username = props?.user?.name ?? "Anonymous"

// En datos de API
const avatar = data?.user?.profile?.avatar ?? defaultAvatar

// En objetos opcionales
const city = user?.address?.city ?? "Unknown"

Esta combinación es extremadamente común en aplicaciones modernas.

📝 Regla Mental Definitiva

Memoriza esto:

?. = evita errores (acceso seguro)

?? = valor alternativo (por defecto)

?. y ?? = acceso seguro + valor por defecto

Ejemplo completo

const city = user?.address?.city ?? "Unknown city"

// Traducción:
// "Si existe user.address.city úsalo,
//  si no existe usa 'Unknown city'"

✅ Conclusión

Dos operadores, dos propósitos

  • ?. → Evita que la aplicación se rompa
  • ?? → Proporciona un fallback seguro

Juntos son una combinación poderosa para escribir código robusto.

💡 Consejo profesional

Esta combinación es uno de los patrones más importantes en JavaScript moderno y React.

Verás esto constantemente en código profesional:

data?.user?.profile?.avatar ?? defaultAvatar
