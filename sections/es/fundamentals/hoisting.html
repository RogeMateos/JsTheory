Hoisting

¿Qué es hoisting?

Significa que las declaraciones de variables y funciones se “mueven” al inicio de su contexto de ejecución antes de correr el código.

En la primera pasada, el motor guarda declaraciones en memoria; para variables solo sube la declaración, no la inicialización.

Por eso, si usas una variable antes de inicializarla con var, obtienes undefined en lugar de error.


console.log(x); // undefined
var x = 5;
console.log(x); // 5

Las funciones declaradas también se elevan completas, así que puedes invocarlas antes de escribirlas en el archivo.


hello(); // "Hello, world!"

function hello() {
  console.log("Hello, world!");
}

Funciona porque la declaración de hello ya está en memoria al iniciar la ejecución.

Dos ejemplos


console.log(greeting);
hello();
function hello(){
  console.log('hello');
}
var greeting = "Hi there";
console.log(greeting);

// undefined
// hello
// Hi there
    

function hello(){
  console.log('hello');
}
var greeting;
console.log(greeting);
hello();
greeting = "Hi there";
console.log(greeting);

// undefined
// hello
// Hi there
