Scope en JavaScript: dónde viven tus variables

Problema común

“Declaré una variable, pero no puedo acceder desde otro lado; a veces desaparece o pisa a otra.” Eso es confusión de scope.

Idea clave

El scope define dónde se ven y se usan las variables. Algunas existen en todo el archivo; otras solo dentro de una función o un bloque.

Scope global

🏛️ Plaza pública

Todo el mundo ve lo que está ahí. Úsalo para constantes compartidas, no para variables temporales.


const API_URL = 'https://api.miapp.com';
let appName = 'Mi App';

function mostrarConfig() {
  console.log(appName, API_URL);
}
❌ Demasiados globales

var userName = 'Ana';
var counter = 0;
// En otro archivo:
var counter = 10; // Sobrescribe
✅ Organiza

const APP = {
  userName: 'Ana',
  counter: 0,
};
          

const CONFIG = Object.freeze({
  API_BASE: 'https://api.ejemplo.com',
  RETRIES: 3,
});

Scope de función

🏠 Habitación privada

Lo que declaras dentro vive y muere dentro. Fuera no existe.


function calcularPedido() {
  const impuesto = 0.08;
  let subtotal = 0;

  function agregar(precio) {
    subtotal += precio;
  }

  agregar(20);
  agregar(10);
  const total = subtotal + subtotal * impuesto;
  return total;
}

calcularPedido(); // total
// impuesto, subtotal y agregar no existen fuera

Scope de bloque

📦 Caja temporal

let y const viven solo dentro de llaves.


if (true) {
  let mensaje = 'hola';
  const flag = true;
  console.log(mensaje, flag); // ok
}
// console.log(mensaje); // Error

var se eleva al scope de función


if (true) {
  var color = 'red';
}
console.log(color); // 'red' (sale del bloque)

Alcance léxico

Una función recuerda el entorno donde se definió, no donde se ejecuta.


const nombre = 'Ada';

function saludar() {
  console.log(nombre); // Usa el nombre de su entorno
}

function ejecutar(fn) {
  const nombre = 'Grace';
  fn(); // Imprime "Ada", no "Grace"
}

ejecutar(saludar);

Para entrevista

  • Global: visible en todo el archivo (evitar abusar)
  • Función: aislado dentro de la función
  • Bloque: let/const limitados a llaves
  • Alcance léxico: la función recuerda dónde nació
