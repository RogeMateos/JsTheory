Var, Let y Const

var

var tiene alcance de función y permite redeclarar. No respeta el bloque.


var x = 10;
if (x === 10) {
  var x = 20;
  console.log(x); // 20
}
console.log(x); // 20 (se sobrescribió)

let

let es de bloque y no se puede redeclarar en el mismo scope.


let y = 10;
if (y === 10) {
  let y = 20;
  console.log(y); // 20
}
console.log(y); // 10

const

const es de bloque y no permite reasignar la referencia. Objetos/arrays sí pueden mutar internamente.


const z = 10;
// z = 11; // Error

const obj = { name: 'Alice' };
obj.name = 'Bob'; // ok

const arr = [1, 2];
arr.push(3); // ok

Comparación rápida

  • var: función, hoisting, se redeclara
  • let: bloque, se reasigna, no se redeclara
  • const: bloque, no se reasigna (la referencia)
