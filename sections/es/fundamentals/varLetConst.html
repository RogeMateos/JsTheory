Var, Let y Const

var

var tiene alcance de función y permite redeclarar. No respeta el bloque.


var x = 10;
if (x === 10) {
  var x = 20;
  console.log(x); // 20
}
console.log(x); // 20 (se sobrescribió)

🔄 let - Variable que se puede reasignar

let permite declarar una variable cuyo valor puede cambiar:


let edad = 25
console.log(edad) // 25

// Puedes reasignar el valor
edad = 26
console.log(edad) // 26

edad = 27
console.log(edad) // 27

Ejemplo práctico con let


let contador = 0
console.log(contador) // 0

contador = contador + 1 // Incrementar
console.log(contador) // 1

contador = contador + 1
console.log(contador) // 2

let es de bloque y no se puede redeclarar en el mismo scope.


let y = 10;
if (y === 10) {
  let y = 20;
  console.log(y); // 20
}
console.log(y); // 10

🔒 const - Variable que NO se puede reasignar

const declara una variable cuyo valor no puede cambiar (es constante):


const PI = 3.14159
console.log(PI) // 3.14159

// ❌ Esto causará un error
PI = 3.14 // TypeError: Assignment to constant variable

Ejemplo práctico con const


const nombre = 'Miguel'
const apellido = 'Ángel'

console.log(nombre) // Miguel
console.log(apellido) // Ángel

// ❌ Esto causará un error
nombre = 'Juan' // TypeError: Assignment to constant variable

const es de bloque y no permite reasignar la referencia. Objetos/arrays sí pueden mutar internamente.


const z = 10;
// z = 11; // Error

const obj = { name: 'Alice' };
obj.name = 'Bob'; // ok

const arr = [1, 2];
arr.push(3); // ok

📊 ¿Cuándo usar let y cuándo const?

Usa const cuando:

  • El valor no va a cambiar
  • Es un valor constante (PI, configuración, etc.)
  • Quieres evitar reasignaciones accidentales

const MAX_USUARIOS = 100
const API_URL = 'https://api.ejemplo.com'
const NOMBRE_APP = 'MiApp'

Usa let cuando:

  • El valor va a cambiar
  • Necesitas reasignar la variable
  • Es un contador, acumulador, etc.

let contador = 0
let suma = 0
let usuarioActual = null

🎯 Regla práctica

Usa const por defecto. Solo cambia a let si descubres que necesitas reasignar el valor.


// ✅ Buena práctica: empieza con const
const nombre = 'Miguel'
const edad = 25

// Si necesitas cambiar el valor, usa let
let contador = 0
contador = contador + 1

Comparación rápida

  • var: función, hoisting, se redeclara
  • let: bloque, se reasigna, no se redeclara
  • const: bloque, no se reasigna (la referencia)
