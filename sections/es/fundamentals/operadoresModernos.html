5 Operadores Modernos de JavaScript

Los operadores que usan los desarrolladores senior en 2024

🎯 Los 5 Operadores Clave

Operador Qué Hace Ejemplo
?. Evita errores si no existe user?.name
?? Valor por defecto si null/undefined name ?? "Guest"
||= Asigna si es falsy user ||= "default"
&&= Asigna si es truthy user &&= true
??= Asigna si es null/undefined user ??= "default"

1️⃣ Optional Chaining (?.)

Traducción mental

?. = "si existe, continúa"

Ejemplo básico

const user = null

console.log(user?.name)  // undefined (sin error)

// Sin ?.:
console.log(user.name)   // ❌ Error: Cannot read properties of null

Caso real

const username = data?.user?.name

// Si data.user.name existe → devuelve el valor
// Si algo no existe → devuelve undefined

2️⃣ Nullish Coalescing (??)

Traducción mental

?? = "si es null o undefined, usa esto"

Ejemplo básico

const name = null

console.log(name ?? "Guest")  // "Guest"

const age = 0
console.log(age ?? 18)        // 0 (porque 0 no es null/undefined)

Caso real

const username = user?.name ?? "Anonymous"

// Si user.name existe → usa su valor
// Si es null/undefined → usa "Anonymous"

3️⃣ Logical OR Assignment (||=)

Traducción mental

||= = "asigna si es falsy"

Falsy: false, 0, "", null, undefined

Ejemplo básico

let username = ""

username ||= "Guest"
console.log(username)  // "Guest"

// Porque "" es falsy

Equivalente largo

if (!username) {
  username = "Guest"
}

// Mismo resultado, pero ||= es más elegante

Caso real en aplicaciones

let timeout = config.timeout

timeout ||= 3000  // Si timeout es 0, "", null → usa 3000

4️⃣ Logical AND Assignment (&&=)

Traducción mental

&&= = "asigna solo si es truthy"

Ejemplo básico

let user = { logged: true }

user.logged &&= false
console.log(user.logged)  // false

// Solo asignó porque user.logged era true

Equivalente largo

if (user.logged) {
  user.logged = false
}

// Mismo resultado, pero &&= es más elegante

Caso real

let isAdmin = user.role === "admin"

isAdmin &&= canManageUsers  // Solo cambia si es admin

5️⃣ Nullish Assignment (??=)

Traducción mental

??= = "asigna si es null o undefined"

Ejemplo básico

let username = null

username ??= "Guest"
console.log(username)  // "Guest"

// Pero mira esto:
let username2 = ""

username2 ??= "Guest"
console.log(username2)  // ""

// Porque "" NO es null/undefined

La diferencia clave

// ||= asigna si es falsy (0, "", null, undefined, false)
let a = 0
a ||= 10  // → 10

// ??= asigna SOLO si es null/undefined
let b = 0
b ??= 10  // → 0

Caso real

let theme = config.theme

theme ??= "dark"  // Solo si no está definido

📊 Comparación Visual

||= (Falsy)
let value = ""

value ||= "default"
// → "default"

// Porque "" es falsy
??= (Null/Undefined)
let value = ""

value ??= "default"
// → ""

// Porque "" NO es null

Esta es la confusión más común

No olvides: ??= SOLO revisa null/undefined

Mientras que ||= revisa cualquier falsy

💡 Ejemplo Real: Código Moderno

Típico en React/APIs

// Obtener datos con seguridad
const username = data?.user?.name ?? "Guest"

// Establecer valores por defecto
settings.theme ??= "dark"

// Configurar timeouts
config.timeout ||= 3000

// Cambiar estado solo si es verdadero
user.isAdmin &&= hasPermission

Traducción mental completa

Si existe data.user.name úsalo
Si no, usa "Guest"

Si settings.theme no existe usa "dark"

Si config.timeout es falsy usa 3000

Si user.isAdmin es true y hasPermission es true → true

🎯 Cuándo Usar Cada Uno

?. (Optional Chaining)

  • Acceder a propiedades que podrían no existir
  • Llamar métodos que podrían no existir
  • Leer arrays con índices que podrían no existir
user?.name
user?.getAge()
items?.[0]

?? (Nullish Coalescing)

  • Proporcionar valor por defecto seguro
  • Diferenciar entre null/undefined y otros valores falsy
price ?? 0      // Si price es null/undefined
timeout ?? 5000 // Si timeout no existe

||= (Logical OR Assignment)

  • Inicializar variables si están vacías/falsas
  • Cuando quieres excluir 0 y "" también
username ||= "Guest"   // Si username es ""
retries ||= 3          // Si retries es 0

&&= (Logical AND Assignment)

  • Cambiar valor solo si ya es verdadero
  • Operaciones condicionales compactas
user.premium &&= checkPayment()
isValid &&= validateForm()

??= (Nullish Assignment)

  • Inicializar variables que aún no existen
  • Permitir 0, "", false como valores válidos
config.theme ??= "dark"
settings.volume ??= 50

⚡ Patrones Comunes en React

Patrón 1: Datos seguro con valor por defecto

const avatar = user?.profile?.avatar ?? defaultAvatar

Patrón 2: Inicializar estado

let settings = loadSettings()
settings.theme ??= "light"
settings.language ??= "en"

Patrón 3: Validación condicional

user.hasPermission &&= validateToken()
data?.length &&= fetchMore()

Patrón 4: Valores por defecto seguros

const timeout = config?.timeout || 3000
const theme = user?.settings?.theme ?? "default"

✅ Resumen Práctico

Aprende estas primero:

  • ?. → evita errores
  • ?? → valor por defecto seguro (null/undefined)
  • || → valor por defecto (falsy)

Los otros (||=, &&=, ??=) son atajos para asignaciones.

💡 En código profesional verás más

  • ?. - Súper común
  • ?? - Súper común
  • || - Muy común (pero intenta evitar si puedes)
  • ||= - Ocasionalmente
  • &&= - Raro
  • ??= - Ocasionalmente
