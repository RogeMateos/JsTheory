Null y Undefined

Entendiendo Null y Undefined

Ambos representan ausencia de valor, pero con significados distintos:

undefined: ausencia porque aún no se asignó nada (variable declarada sin inicializar).

null: ausencia intencional. Se asigna explícitamente para indicar “vacío”.


let myVariable = null; // Vacío a propósito
let myOtherVariable;   // Declarada sin asignar → undefined

console.log(myVariable);       // null
console.log(myOtherVariable);  // undefined

Diferencias clave

Chequeo de tipo:

typeof null devuelve "object" (quirk histórico de JS).

typeof undefined devuelve "undefined".

Comparación:

Igualdad débil (==): null == undefined es true porque se consideran equivalentes en valor.

Igualdad estricta (===): null === undefined es false porque son tipos distintos.


console.log(undefined == null);  // true
console.log(undefined === null); // false

Buenas prácticas

  • Usa === para evitar coerción inesperada.
  • Usa undefined para variables sin inicializar.
  • Usa null para expresar “sin valor” de forma intencional.

Prefiere === sobre == siempre que sea posible.
