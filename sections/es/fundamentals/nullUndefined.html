Null y Undefined

🧠 Idea Visual Fundamental

Ambos representan ausencia de valor, pero tienen significados completamente distintos:

undefined → JavaScript lo asigna automáticamente cuando no hay valor

null → Tú lo asignas intencionalmente para indicar "sin valor"

1. Undefined (Indefinido)

Una variable que ha sido declarada pero no tiene valor:


let usuario
console.log(usuario) // undefined

let direccion
console.log(direccion) // undefined

⚠️ Importante: undefined es lo que JavaScript asigna automáticamente a variables que no han sido inicializadas.

2. Null (Nulo)

Representa la ausencia intencional de un valor:


let respuesta = null // Intencionalmente sin valor
console.log(respuesta) // null

💡 Diferencia clave: null es asignado por ti explícitamente, mientras que undefined es asignado automáticamente por JavaScript.

📊 Diferencia entre undefined y null

undefined (Automático)
let sinDefinir // No se ha asignado valor
console.log(sinDefinir) // undefined
null (Intencional)
let sinValor = null // Intencionalmente vacío
console.log(sinValor) // null

Diferencias clave

Chequeo de tipo:

typeof null devuelve "object" (quirk histórico de JS).

typeof undefined devuelve "undefined".

Comparación:

Igualdad débil (==): null == undefined es true porque se consideran equivalentes en valor.

Igualdad estricta (===): null === undefined es false porque son tipos distintos.


console.log(undefined == null);  // true (igualdad débil)
console.log(undefined === null); // false (igualdad estricta)

console.log(typeof undefined)    // "undefined"
console.log(typeof null)         // "object"

🎯 Regla mental definitiva

undefined: JavaScript lo asigna automáticamente cuando no hay valor

null: Tú lo asignas intencionalmente para indicar "sin valor"

Es raro pero también puedes asignar undefined manualmente, aunque no es recomendable.

Buenas prácticas

  • Usa === para evitar coerción inesperada.
  • Usa undefined para variables sin inicializar (JavaScript lo hace automáticamente).
  • Usa null para expresar "sin valor" de forma intencional y explícita.
  • Prefiere === sobre == siempre que sea posible.
