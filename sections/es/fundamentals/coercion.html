Coerción: valores Truthy y Falsy

Uso de Truthy y Falsy para comprobar existencia

En JavaScript, la tipificación dinámica y la coerción permiten convertir valores automáticamente en ciertos contextos (por ejemplo, en condicionales). Conocer cómo el motor interpreta valores truthy y falsy ayuda a simplificar comprobaciones de existencia y escribir código más limpio. Los falsy más comunes son undefined, null, 0, "" (cadena vacía) y false. 


// Ejemplo: comprobación simple con valores falsy
var a;
if (a) {
  console.log('Hay algo');
} else {
  console.log('No hay nada');
}
// Muestra: "No hay nada" porque 'a' es undefined (falsy)
    

// Ejemplo: tratando 0 como valor válido
var a = 0;
if (a || a === 0) {
  console.log('Hay algo, incluyendo 0');
} else {
  console.log('No hay nada');
}
// Muestra: "Hay algo, incluyendo 0" porque 0 se considera válido aquí.
