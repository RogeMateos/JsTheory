Atributos data-* en HTML y JavaScript

Guardar información personalizada en elementos HTML para que JavaScript la lea

🎯 Definición Simple para Entrevistas

¿Qué son los atributos data-*?

Atributos data-* permiten guardar información personalizada dentro del HTML que JavaScript puede leer fácilmente.

No se muestran en la página, pero JavaScript puede acceder a ellos usando la propiedad dataset.

💡 Concepto Clave

Piensa en ellos como pequeñas etiquetas de información escondidas en el HTML

HTML → guarda datos

JavaScript → los lee con dataset

Se usan mucho en:

  • Filtros: Guardar categorías para filtrar elementos
  • Modales: Guardar información sobre qué modal abrir
  • Componentes UI: Guardar estados o IDs de componentes
  • Listas dinámicas: Guardar IDs de usuarios, productos, etc.
  • Frameworks: React, Vue, Angular los usan internamente

1️⃣ Qué son los Atributos data-*

Sintaxis en HTML

Los atributos data-* tienen esta estructura:

<div data-nombre="Miguel" data-edad="25"></div>

Aquí el div guarda dos datos:

Atributo Valor
data-nombre Miguel
data-edad 25

Reglas importantes

  • Siempre comienzan con data-
  • Después pueden tener cualquier nombre (kebab-case)
  • Los valores son siempre strings en HTML
  • No se muestran visualmente en la página

2️⃣ Cómo Leer los data-* en JavaScript

Usando la propiedad dataset (forma moderna)

JavaScript tiene una propiedad especial llamada dataset que convierte automáticamente los atributos data-* en propiedades.

const div = document.querySelector('div')

console.log(div.dataset.nombre)  // "Miguel"
console.log(div.dataset.edad)    // "25"

Lo que ocurre internamente

HTML: data-nombre="Miguel"

JavaScript: element.dataset.nombre

⚠️ Observa que se elimina el prefijo data-

3️⃣ Alternativa: getAttribute

También podemos leer atributos con getAttribute

Este método funciona para cualquier atributo (no solo data-*):

const div = document.querySelector('div')

console.log(div.getAttribute('data-nombre'))  // "Miguel"
console.log(div.getAttribute('data-edad'))    // "25"

Comparación de métodos

Método Cómo funciona
dataset Forma moderna y más cómoda
getAttribute Forma genérica para cualquier atributo

En JavaScript moderno normalmente se usa: dataset

4️⃣ Ejemplo Real: Filtrar una Lista de Empleos

Caso de uso práctico

Imaginemos una web con ofertas de trabajo donde queremos filtrar por modalidad (remoto, presencial, en ciudad).

Para eso guardamos la información en data-modalidad.

5️⃣ HTML de las Ofertas de Empleo

Estructura HTML

<div class="jobs-listings">
  <article data-technology="react" data-modalidad="remoto" class="job-listing-card">
    <h4>Desarrollador React</h4>
    <p>Trabajo remoto</p>
  </article>

  <article data-modalidad="cdmx" class="job-listing-card">
    <h4>Desarrollador Frontend</h4>
    <p>Presencial en CDMX</p>
  </article>

  <article data-modalidad="guadalajara" class="job-listing-card">
    <h4>Full Stack Developer</h4>
    <p>Presencial en Guadalajara</p>
  </article>

  <article data-modalidad="remoto" class="job-listing-card">
    <h4>Node.js Developer</h4>
    <p>Trabajo remoto</p>
  </article>
</div>

Cada oferta tiene su modalidad guardada en:

data-modalidad

6️⃣ Select para Filtrar

Elemento select con opciones

<select id="filter-modalidad">
  <option value="">Todas</option>
  <option value="remoto">Remoto</option>
  <option value="cdmx">CDMX</option>
  <option value="guadalajara">Guadalajara</option>
</select>

7️⃣ JavaScript para Filtrar los Trabajos

Código de filtrado

const filter = document.querySelector('#filter-modalidad')
const jobs = document.querySelectorAll('.job-listing-card')

filter.addEventListener('change', function () {
  const selectedValue = filter.value

  jobs.forEach((job) => {
    const modalidad = job.dataset.modalidad

    if (selectedValue === '' || selectedValue === modalidad) {
      job.style.display = 'flex'
    } else {
      job.style.display = 'none'
    }
  })
})

8️⃣ Cómo Funciona el Código

Paso a paso

  1. Escuchamos el cambio del select

    filter.addEventListener('change') - Cuando el usuario cambia el filtro

  2. Obtenemos el valor seleccionado

    const selectedValue = filter.value - Por ejemplo: "remoto"

  3. Recorremos todos los trabajos

    jobs.forEach(job => {})

  4. Leemos el atributo data-modalidad

    const modalidad = job.dataset.modalidad - Por ejemplo: "remoto"

  5. Comparamos valores

    selectedValue === modalidad - ¿Coinciden?

  6. Mostrar / ocultar

    Mostrar: job.style.display = 'flex'

    Ocultar: job.style.display = 'none'

9️⃣ Por Qué Usamos selectedValue === ''

El caso especial: "Todas"

Cuando el usuario selecciona la opción "Todas", el valor del select es una cadena vacía: ''

Entonces mostramos todos los trabajos.

if (selectedValue === '' || selectedValue === modalidad) {
  // Si está vacío O coincide → mostrar
}

1️⃣1️⃣ Cuándo Usar data-* (Muy Común en Front-end)

Se usan muchísimo en:

  • UI Components: data-id, data-user, data-state
  • Tracking: data-analytics, data-event
  • Filtros: data-category, data-modalidad
  • React / Frameworks: Muchas librerías las usan internamente

Ejemplo en un carrito de compras

<button data-product-id="123" data-price="29.99" class="add-to-cart">
  Añadir al carrito
</button>
document.querySelector('.add-to-cart').addEventListener('click', (e) => {
  const productId = e.target.dataset.productId
  const price = e.target.dataset.price
  // Añadir al carrito...
})

1️⃣3️⃣ Ejercicio Rápido (Muy Bueno para Aprender)

Crea botones que cambien el color de un div

HTML:
<button data-color="red">Rojo</button>
<button data-color="blue">Azul</button>
<button data-color="green">Verde</button>

<div id="box" style="width: 100px; height: 100px; background: gray;"></div>
JavaScript:
const buttons = document.querySelectorAll('button')
const box = document.querySelector('#box')

buttons.forEach(button => {
  button.addEventListener('click', () => {
    const color = button.dataset.color
    box.style.backgroundColor = color
  })
})

¿Cómo funciona?

  1. Cada botón tiene un data-color diferente
  2. Cuando haces click, se lee el dataset.color
  3. El color se aplica al div

1️⃣4️⃣ Con data-* en Atributos Complejos

Puedes guardar múltiples datos en un elemento

<div
  data-user-id="42"
  data-user-name="Juan"
  data-user-role="admin"
  data-user-status="active"
  class="user-card"
>
  Perfil de Usuario
</div>
const card = document.querySelector('.user-card')

console.log(card.dataset.userId)     // "42"
console.log(card.dataset.userName)   // "Juan"
console.log(card.dataset.userRole)   // "admin"
console.log(card.dataset.userStatus) // "active"

⚠️ Importante: Nombres en camelCase

En HTML usas: data-user-id

En JavaScript se convierte a: dataset.userId (camelCase)

Los guiones se convierten a mayúsculas.
