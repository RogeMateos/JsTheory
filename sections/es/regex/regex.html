Expresiones Regulares (RegEx) en JavaScript

Guía completa para buscar y validar patrones en texto

¿Qué es una Expresión Regular?

Una expresión regular (regex) es un patrón que se usa para buscar, validar o extraer información de texto. Es como una búsqueda avanzada con superpoderes.

Paso 1: Literal regex + test()

La forma más común de definir una regex es con barras /patrón/:

const regex = /ABC/;
const text = "Hola, ABC JavaScript";

console.log(regex.test(text)); // true
console.log(/ABCD/.test(text)); // false
console.log(/AB/.test(text));   // true

💡 Idea clave: .test() solo responde: "¿existe coincidencia? sí/no".

Paso 2: Constructor RegExp (cuándo usarlo)

Hay dos formas de crear expresiones regulares:

1. Literal (con barras) - Más común

const regex = /ABC/;

2. Constructor RegExp - Cuando el patrón es dinámico

const pattern = "ABC";
const regex2 = new RegExp(pattern);

console.log(regex2.test("Hola, ABC JavaScript")); // true

📌 Cuándo usar new RegExp():

  • Cuando el patrón viene de una variable o configuración
  • Cuando necesitas construir el patrón dinámicamente

⚠️ Importante con RegExp constructor:

Debes escapar las barras invertidas dos veces:

const digits = "\\d+";  // nota el doble backslash
const regex = new RegExp(digits);

Paso 3: Clases de caracteres (\d) y cuantificadores (+)

Diferencia importante:

  • \d = "un dígito" (0-9)
  • d = "la letra d"
const text2 = "Mi edad es 37";

console.log(/\d/.test(text2));   // true (hay algún dígito)
console.log(/\d+/.test(text2));  // true (hay una secuencia de dígitos)

¿Qué cambia con el +?

  • /\d/ → "hay al menos 1 dígito"
  • /\d+/ → "hay una secuencia de 1 o más dígitos"

Extraer lo encontrado con .match()

console.log(text2.match(/\d+/)); // ["37"]

Paso 4: Rangos con corchetes [ ]

Los corchetes definen un conjunto de caracteres permitidos:

const text3 = "Mi edad es 37";

console.log(/[0-2]/.test(text3)); // false (no hay 0,1,2)
console.log(/[3-6]/.test(text3)); // true  (hay 3)
console.log(/[4-6]/.test(text3)); // false (no hay 4,5,6)

Importante: [3-6] significa "un carácter que sea 3, 4, 5 o 6".

Paso 5: Anclas (^ inicio, $ fin)

⚠️ Cuidado con ^: tiene dos significados diferentes

  • Fuera de [ ] → ^ es ancla de inicio de string
  • Dentro de [ ] (al principio) → ^ significa negación

^ como ancla de inicio

console.log(/^\d/.test("37 años")); // true (empieza por dígito)
console.log(/^\d/.test("Edad 37")); // false (no empieza por dígito)

$ como ancla de fin

console.log(/\d$/.test("Edad 37")); // true (termina en dígito)
console.log(/\d$/.test("37 años")); // false (no termina en dígito)

^ dentro de [ ] como negación

console.log(/[^0-2]/.test("012")); // false (todos son 0,1,2)
console.log(/[^0-2]/.test("013")); // true (hay un 3, que NO es 0,1,2)

Paso 6: "La trampa" típica con flags (g) y .test()

⚠️ Nota senior (muy importante):

Con flag g, una regex mantiene estado con lastIndex y .test() puede alternar true/false si la reutilizas.

const r = /\d/g;
const s = "a1b2";

console.log(r.test(s)); // true
console.log(r.test(s)); // true
console.log(r.test(s)); // false  <-- porque lastIndex avanzó y llegó al final
console.log(r.test(s)); // true   <-- vuelve a empezar

📌 Recomendación:

  • Para .test(), evita g al principio
  • Usa g cuando quieras "todas las coincidencias" con .match()
console.log("a1b2".match(/\d/g)); // ["1","2"]

Métodos principales con RegEx

1. .test() - Devuelve boolean

const regex = /\d+/;
console.log(regex.test("Hay 5 manzanas")); // true

2. .match() - Devuelve array o null

const text = "Pedido 12, caja 7, lote 301";
console.log(text.match(/\d+/g)); // ["12", "7", "301"]

3. .replace() - Reemplaza coincidencias

const text = "Hola    mundo    JS";
const cleaned = text.replace(/\s+/g, " ");
console.log(cleaned); // "Hola mundo JS"

4. .exec() - Match con grupos (útil en loops con g)

const regex = /\d+/g;
const text = "a1b2c3";
let match;

while ((match = regex.exec(text)) !== null) {
  console.log(`Encontrado: ${match[0]} en índice ${match.index}`);
}
// Encontrado: 1 en índice 1
// Encontrado: 2 en índice 3
// Encontrado: 3 en índice 5

Casos de uso prácticos

1. Validar solo números

function esNumero(str) {
  return /^\d+$/.test(str);
}

console.log(esNumero("123"));    // true
console.log(esNumero("12a3"));   // false
console.log(esNumero(""));       // false

2. Extraer números de un texto

const input = "Total: 149€";
const amount = input.match(/\d+/)?.[0];
console.log(amount); // "149"

3. Validar email (simple)

function esEmailSimple(email) {
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
}

console.log(esEmailSimple("user@example.com")); // true
console.log(esEmailSimple("user@"));            // false

⚠️ Advertencia importante:

Regex no es para validar todo al 100% (emails perfectos son muy complejos). Úsalo para reglas razonables, no para validaciones críticas de seguridad.

4. Limpiar espacios múltiples

const text = "Hola     mundo    JS";
const cleaned = text.replace(/\s+/g, " ").trim();
console.log(cleaned); // "Hola mundo JS"

Clases de caracteres más comunes

Patrón Significado Ejemplo
\d Dígito (0-9) /\d+/ coincide "123"
\w Palabra (a-z, A-Z, 0-9, _) /\w+/ coincide "hola_123"
\s Espacio en blanco /\s+/ coincide " "
\D NO dígito /\D+/ coincide "abc"
\W NO palabra /\W+/ coincide "!@#"
\S NO espacio /\S+/ coincide "texto"
. Cualquier carácter (excepto \n) /a.c/ coincide "abc", "a*c"

Cuantificadores

Patrón Significado Ejemplo
+ Una o más veces /\d+/ coincide "123"
* Cero o más veces /\d*/ coincide "", "123"
? Cero o una vez (opcional) /colou?r/ coincide "color", "colour"
{n} Exactamente n veces /\d{3}/ coincide "123"
{n,} n o más veces /\d{2,}/ coincide "12", "123"
{n,m} Entre n y m veces /\d{2,4}/ coincide "12", "123", "1234"

Flags (modificadores)

Flag Significado Ejemplo
g Global (todas las coincidencias) /\d/g
i Case insensitive (ignora mayús/minús) /abc/i coincide "ABC"
m Multiline (^ y $ por línea) /^test/m

Ejercicios prácticos 💪

  1. Escribe una regex que detecte si un string empieza con "Hola"
  2. Extrae todos los números de: "Pedido 12, caja 7, lote 301"
  3. Comprueba si un string es solo dígitos (pista: ^ y $ + \d+)
  4. Reemplaza múltiples espacios por uno solo en: "Hola mundo JS"
  5. Valida un número de teléfono con formato: 123-456-7890

Soluciones

// 1. Empieza con "Hola"
console.log(/^Hola/.test("Hola mundo")); // true

// 2. Extraer todos los números
console.log("Pedido 12, caja 7, lote 301".match(/\d+/g)); // ["12", "7", "301"]

// 3. Solo dígitos
console.log(/^\d+$/.test("12345")); // true
console.log(/^\d+$/.test("123a5")); // false

// 4. Limpiar espacios múltiples
console.log("Hola    mundo    JS".replace(/\s+/g, " ")); // "Hola mundo JS"

// 5. Validar teléfono
console.log(/^\d{3}-\d{3}-\d{4}$/.test("123-456-7890")); // true

Errores comunes

  • ❌ Confundir \d con d
  • ❌ Olvidar escapar caracteres especiales: . → \.
  • ❌ Usar g con .test() sin saber del lastIndex
  • ❌ No usar ^ y $ para validaciones exactas
  • ❌ Confundir ^ fuera de [ ] con ^ dentro de [ ]

✅ Resumen

  • Las regex se definen con /patrón/ o new RegExp()
  • .test() devuelve boolean, .match() devuelve array
  • \d, \w, \s son clases de caracteres
  • +, *, ? son cuantificadores
  • ^ y $ son anclas de inicio/fin
  • Flag g con .test() mantiene estado (cuidado)
  • Usa regex para reglas razonables, no para todo
