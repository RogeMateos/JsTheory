Tutorial: replace y Expresiones Regulares en JavaScript

Entendiendo el reemplazo de texto con regex

🎯 Objetivo del capítulo

Entender cómo funciona replace, cómo se combina con expresiones regulares, y por qué a veces solo reemplaza una coincidencia aunque parezca que la regex encuentra varias.

Este es uno de esos puntos donde mucha gente se confunde, así que vamos despacio y con ejemplos claros.

1️⃣ ¿Qué es replace?

replace es un método de los strings, no de las expresiones regulares.

Su trabajo es:

Buscar una coincidencia dentro de un texto y reemplazarla por otro valor.

Sintaxis básica

texto.replace(busqueda, reemplazo)
  • busqueda → puede ser un string o una RegExp
  • reemplazo → un string o una función

2️⃣ replace usando un string literal

Cuando sabes exactamente qué texto quieres cambiar:

const text = "Hola, JavaScript";
const result = text.replace("JavaScript", "JS");

console.log(result);
// "Hola, JS"

📌 Importante:

  • Solo reemplaza la primera coincidencia
  • No entiende patrones, solo texto exacto

3️⃣ replace usando una expresión regular

Cuando quieres buscar patrones, no texto fijo:

const text = "Hola, JavaScript";
const result = text.replace(/JavaScript/, "JS");

console.log(result);
// "Hola, JS"

Hasta aquí parece igual, pero ahora tenemos mucho más poder.

4️⃣ Primer error común: ❌ "¿Por qué solo reemplaza uno?"

Ejemplo típico:

const text = "Estoy contando 1 2 3 4 5";

const result = text.replace(/\d/, "Número");
console.log(result);
// "Estoy contando Número 2 3 4 5"

👉 La regex funciona, encuentra un número…
👉 Pero replace solo reemplaza la primera coincidencia.

Esto no es un problema de la regex.

Es el comportamiento por defecto de replace.

5️⃣ El flag g: reemplazo global

Si quieres que se reemplacen todas las coincidencias, necesitas el flag g.

const text = "Estoy contando 1 2 3 4 5";

const result = text.replace(/\d/g, "Número");
console.log(result);
// "Estoy contando Número Número Número Número Número"

🧠 Regla mental clave:

  • Sin g → primera coincidencia
  • Con g → todas las coincidencias

6️⃣ Cuantificadores (+) ≠ búsqueda global

Aquí suele venir la confusión.

/\d+/   // uno o más dígitos SEGUIDOS

Esto no significa "encuentra todos los números del texto".

Ejemplo:

const text = "Tengo 12 perros y 300 gatos";

console.log(text.replace(/\d+/, "NUM"));
// "Tengo NUM perros y 300 gatos"

¿Por qué?

  • \d+ define qué es una coincidencia
  • g define cuántas coincidencias buscar

✅ Versión correcta:

console.log(text.replace(/\d+/g, "NUM"));
// "Tengo NUM perros y NUM gatos"

7️⃣ Greedy (+) vs Global (g) — diferencia clara

Concepto Qué controla
+ / * / {} Cuánto texto captura una coincidencia
g Cuántas coincidencias se buscan en el string

👉 Son cosas distintas y complementarias.

8️⃣ ¿Y replaceAll?

replaceAll existe, pero tiene reglas claras.

Funciona con strings

"1 2 3".replaceAll("1", "X");

Con regex EXIGE g

"1 2 3".replaceAll(/\d/g, "X"); // ✅
"1 2 3".replaceAll(/\d/, "X");  // ❌ TypeError

📌 Si usas regex, mejor sigue usando replace + g.

9️⃣ Reemplazo avanzado: usar una función

Aquí subimos de nivel 🚀

const text = "Estoy contando 1 2 3";

const result = text.replace(/\d/g, (match) => {
  return `Número(${match})`;
});

console.log(result);
// "Estoy contando Número(1) Número(2) Número(3)"

👉 match es el valor exacto que encontró la regex.

Esto es muy usado para:

  • formatear datos
  • normalizar textos
  • transformar valores dinámicamente

Ejemplo más avanzado: convertir a mayúsculas

const text = "hola mundo js";

const result = text.replace(/\b\w/g, (match) => {
  return match.toUpperCase();
});

console.log(result);
// "Hola Mundo Js"

Ejemplo: formatear números

const text = "Precio: 1000 EUR";

const result = text.replace(/\d+/g, (match) => {
  return parseInt(match).toLocaleString();
});

console.log(result);
// "Precio: 1,000 EUR"

🔟 Resumen final (para fijarlo bien)

  • replace es un método de String
  • Acepta strings o regex
  • Sin g → solo reemplaza la primera coincidencia
  • g hace la búsqueda global
  • Los cuantificadores (+, *) no sustituyen al g
  • replaceAll con regex requiere g

🧠 Ejercicio rápido (recomendado)

Convierte:

"Precio: 20€, descuento: 5€, total: 15€"

En:

"Precio: X€, descuento: X€, total: X€"

👉 Pista: \d+ + g en regex

Solución:

const text = "Precio: 20€, descuento: 5€, total: 15€";
const result = text.replace(/\d+/g, "X");
console.log(result);
// "Precio: X€, descuento: X€, total: X€"

Ejercicios adicionales 💪

  1. Reemplaza todos los espacios múltiples por uno solo
  2. Convierte "hello world" en "Hello World" (primera letra mayúscula)
  3. Reemplaza todos los números por su valor multiplicado por 2
  4. Elimina todos los símbolos especiales de un texto

Soluciones

// 1. Reemplazar espacios múltiples
"Hola    mundo    JS".replace(/\s+/g, " ");
// "Hola mundo JS"

// 2. Primera letra mayúscula
"hello world".replace(/\b\w/g, m => m.toUpperCase());
// "Hello World"

// 3. Números multiplicados por 2
"Tengo 5 manzanas y 3 naranjas".replace(/\d+/g, m => parseInt(m) * 2);
// "Tengo 10 manzanas y 6 naranjas"

// 4. Eliminar símbolos especiales
"Hola! ¿Cómo estás? #JavaScript".replace(/[^\w\s]/g, "");
// "Hola Cómo estás JavaScript"

Errores comunes

  • ❌ Olvidar el flag g cuando quieres reemplazar todas las coincidencias
  • ❌ Confundir cuantificadores (+) con búsqueda global (g)
  • ❌ Usar replaceAll con regex sin g
  • ❌ No validar que replace devuelve un nuevo string (no modifica el original)

✅ Puntos clave

  • replace no modifica el string original, devuelve uno nuevo
  • El flag g es esencial para reemplazos múltiples
  • Puedes usar funciones para transformaciones complejas
  • Los cuantificadores controlan el tamaño de cada coincidencia
  • El flag g controla cuántas coincidencias se buscan
