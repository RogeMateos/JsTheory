Ordenación de Arrays en JavaScript

sort, reverse y criterios de comparación

Introducción

Ordenar datos es una de las operaciones más comunes en JavaScript. Sin embargo, sort() tiene comportamientos que suelen confundir, especialmente cuando trabajamos con números.

En este tutorial vamos a verlo paso a paso, entendiendo qué pasa por dentro, por qué ocurre y cómo hacerlo bien.

1️⃣ El Caso Más Simple: Ordenar un Array

Vamos a empezar con un array desordenado de números:


const unsorted = [3, 4, 1, 6, 10];
const sorted = unsorted.sort();

console.log(sorted);

❌ Resultado Inesperado

[1, 10, 3, 4, 6]

A primera vista parece incorrecto… ¿por qué 10 va antes que 3?

2️⃣ ¿Por Qué sort() No Funciona Bien con Números?

Por defecto, sort() convierte los elementos a string y los compara como texto.

Es decir, compara así:

"1" < "10" < "3"

Por eso el orden es lexicográfico (alfabético), no numérico.

3️⃣ Cuándo sort() SÍ Funciona Sin Configuración

Si usamos strings, el comportamiento por defecto tiene sentido:


const letters = ["B", "A", "D", "P"];
const sortedLetters = letters.sort();

console.log(sortedLetters);

✅ Resultado Correcto

["A", "B", "D", "P"]

Esto confirma algo importante:

🔑 sort() ordena bien strings, pero no números, si no le indicamos un criterio.

4️⃣ Cómo Funciona Realmente sort(): La Función Comparadora

sort() puede recibir una función de comparación que decide el orden.


array.sort((a, b) => {
  // devuelve un número
});

📌 Regla Fundamental del Comparador

  • Si devuelve un número negativo → a va antes que b
  • Si devuelve 0 → se consideran iguales
  • Si devuelve un número positivo → a va después de b

5️⃣ Ordenar Números Correctamente (Ascendente)

Para números, el criterio más simple es restar:


const numbers = [3, 4, 1, 6, 10];

const sortedNumbers = numbers.sort((a, b) => a - b);

console.log(sortedNumbers);

✅ Resultado

[1, 3, 4, 6, 10]

❌ Error Común

Esto NO funciona bien:

numbers.sort((a, b) => a < b);

¿Por qué?
Porque devuelve true o false, y sort() necesita un número, no un boolean.

6️⃣ ⚠️ Importante: sort() MUTA el Array Original

Esto es clave y suele causar bugs.


const nums = [3, 4, 1];
const sorted = nums.sort((a, b) => a - b);

console.log(nums);    // ⚠️ ya está ordenado
console.log(sorted); // es el mismo array

⚠️ Advertencia

👉 sort() no crea un nuevo array, modifica el original.

7️⃣ Forma Correcta y Segura (Sin Mutar)

Si quieres mantener el array original intacto:


const nums = [3, 4, 1, 6, 10];

const sorted = [...nums].sort((a, b) => a - b);

console.log(nums);   // original
console.log(sorted); // ordenado

💡 Importante

Esto es fundamental en React y programación funcional.

8️⃣ Orden Descendente

Dos opciones válidas:

Opción 1: Invertir la Resta


const desc = [...nums].sort((a, b) => b - a);

Opción 2: reverse() (⚠️ muta)


const asc = [...nums].sort((a, b) => a - b);
asc.reverse();

9️⃣ reverse(): Qué Hace Exactamente


const arr = [1, 2, 3];
arr.reverse();

console.log(arr);

🔁 Resultado

[3, 2, 1]

⚠️ Advertencia

reverse() también muta el array y devuelve la misma referencia.

🔟 Caso Real: Ordenar Arrays de Objetos

Esto es lo más habitual en aplicaciones reales.


const users = [
  { name: "Ana", age: 30 },
  { name: "Luis", age: 25 },
  { name: "Eva", age: 25 },
];

const byAge = [...users].sort((a, b) => a.age - b.age);

Orden con Criterio Secundario (Desempate)


const byAgeThenName = [...users].sort((a, b) => {
  if (a.age !== b.age) return a.age - b.age;
  return a.name.localeCompare(b.name);
});

1️⃣1️⃣ Strings y Acentos: localeCompare

Para texto en español:


const words = ["ñu", "nube", "árbol", "avión"];

const sorted = [...words].sort((a, b) =>
  a.localeCompare(b, "es")
);

console.log(sorted);

✅ Resultado

Esto respeta correctamente el orden alfabético del idioma.

1️⃣2️⃣ Alternativa Moderna (Sin Mutar): toSorted() y toReversed()

Versiones modernas de JavaScript:


const nums = [3, 4, 1, 6, 10];

const asc = nums.toSorted((a, b) => a - b);
const desc = nums.toSorted((a, b) => b - a);

console.log(nums); // intacto

🧠 Resumen Mental (Para Entrevistas y Uso Diario)

Conceptos Clave

  • sort() ordena como strings por defecto
  • Para números → usa un comparador (a, b) => a - b
  • sort() y reverse() mutan el array
  • Usa [...array] si quieres seguridad
  • Para texto → localeCompare
  • Para objetos → compara propiedades
  • Moderno → toSorted()
