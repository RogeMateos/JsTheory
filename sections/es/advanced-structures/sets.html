Sets Avanzados en JavaScript

Operaciones de conjuntos: eliminar duplicados, unión, intersección y diferencia

1️⃣ ¿Qué es un Set en JavaScript?

Un Set es una estructura de datos que representa una colección de valores únicos.

👉 Características principales:

  • No admite duplicados
  • Mantiene el orden de inserción
  • Es ideal para eliminar repetidos y comprobar existencia rápidamente

const numbers = new Set([1, 2, 2, 3, 3, 4]);
console.log(numbers); // Set {1, 2, 3, 4}

2. Array vs Set (Idea Clave Para No Confundirse)

Característica Array Set
Permite duplicados ✅ ❌
Tiene índice ([0]) ✅ ❌
Métodos map/filter ✅ ❌
Comprobar existencia includes (lento) has (rápido)
Uso principal Transformar datos Unicidad / Conjuntos

👉 Regla Mental

  • Array = transformación
  • Set = pertenencia y conjuntos

3. Crear un Set a Partir de un Array (Eliminar Duplicados)

Problema Real

Tenemos un array con duplicados:


const numbersArray = [2, 2, 3, 4, 5, 6];

Solución con Set


const numbersSet = new Set(numbersArray);

console.log(numbersSet);
// Set {2, 3, 4, 5, 6}

📌 Resultado

El Set elimina automáticamente los repetidos.

4. Volver de Set a Array (Muy Común)

Muchas veces necesitamos seguir trabajando con un array.


const uniqueArray = [...numbersSet];

console.log(uniqueArray);
// [2, 3, 4, 5, 6]

¿Qué hace el spread (...) aquí?

  • "Extrae" cada valor del Set
  • Lo coloca dentro de un nuevo array

Alternativa Equivalente:


Array.from(numbersSet);

5. Operaciones Básicas de Set (Necesarias)


const s = new Set();

s.add(1);        // añadir
s.has(1);        // true
s.delete(1);     // eliminar
s.size;          // número de elementos
s.clear();       // vaciar

💡 Importante

has es el equivalente a includes, pero mucho más eficiente.

5️⃣ Iterar un Set (Sin Convertirlo a Array)

Opción 1: forEach


const numbers = new Set([2, 3, 4, 5, 6]);

numbers.forEach(n => {
  console.log(n * 2);
});
// 4, 6, 8, 10, 12

Opción 2: for...of


for (const num of numbers) {
  console.log(num);
}

💡 Ventaja

No necesitas convertir a array para recorrerlo.

6️⃣ Qué NO Tiene un Set (Y Por Qué)

⚠️ Set NO tiene:

  • map()
  • filter()
  • reduce()

Razón: Un Set no está pensado para transformaciones, sino para unicidad y pertenencia.

👉 Si necesitas transformar:

Debes convertir a Array primero.

6. Operaciones de Conjuntos (La Gran Ventaja de los Sets)

Vamos a trabajar con dos conjuntos:


const setA = new Set([1, 2, 3]);
const setB = new Set([2, 3, 4, 5]);

7. Unión (A ∪ B)

¿Qué es?

Todos los elementos de ambos conjuntos, sin duplicados.


const union = new Set([...setA, ...setB]);

console.log(union);
// Set {1, 2, 3, 4, 5}

Por Qué Funciona

  • [...] combina los valores
  • new Set() elimina duplicados automáticamente

8. Intersección (A ∩ B)

¿Qué es?

Los elementos comunes entre ambos sets.


const intersection = new Set(
  [...setA].filter(value => setB.has(value))
);

console.log(intersection);
// Set {2, 3}

Paso a Paso

  1. Convertimos setA en array
  2. Filtramos solo los valores que existen en setB
  3. Creamos un nuevo Set para mantener unicidad

9. Diferencia (A − B)

¿Qué es?

Elementos que están en A pero NO en B


const difference = new Set(
  [...setA].filter(value => !setB.has(value))
);

console.log(difference);
// Set {1}

Importante ⚠️

La diferencia no devuelve "los no comunes",
devuelve los de un conjunto que no están en el otro.

10. (Bonus) Diferencia Simétrica

Elementos que están en uno u otro, pero no en ambos.


const symmetricDifference = new Set([
  ...[...setA].filter(x => !setB.has(x)),
  ...[...setB].filter(x => !setA.has(x))
]);

console.log(symmetricDifference);
// Set {1, 4, 5}

10️⃣ Usar filter, map, reduce con Set

Si necesitas transformar un Set, primero conviértelo a Array.

Patrón Común:


const numbers = new Set([1, 2, 3, 4, 5, 6]);

// Queremos solo pares, multiplicados por 2
const result = new Set(
  [...numbers]
    .filter(n => n % 2 === 0)
    .map(n => n * 2)
);

console.log(result);
// Set {4, 8, 12}

Proceso:

  1. Set → Array: [...numbers]
  2. Filtrar: .filter(...)
  3. Transformar: .map(...)
  4. Array → Set: new Set(...)

Ejemplo con reduce:


const sum = [...numbers].reduce((acc, n) => acc + n, 0);
console.log(sum); // 21

💡 Importante

Si el resultado final necesita ser único, vuelve a convertirlo en Set.

11. Casos Importantes Que Debes Conocer (Nivel Senior)

🔹 NaN es Único en Set


new Set([NaN, NaN]).size; // 1

🔹 Objetos se Comparan por Referencia


new Set([{a:1}, {a:1}]).size; // 2

⚠️ Importante

Aunque "se vean iguales", son objetos distintos.

12. Rendimiento (Por Qué Usar Set)

  • array.includes(x) → O(n)
  • set.has(x) → O(1) promedio

👉 Para búsquedas frecuentes, Set es mucho más eficiente.

13. Cuándo Usar Set y Cuándo Array

✔ Usa Set cuando:

  • Necesitas unicidad
  • Comprobar existencia rápido
  • Operaciones de conjuntos

✔ Usa Array cuando:

  • Necesitas transformar datos
  • Orden y posición importan
  • map, filter, reduce

13️⃣ Errores Comunes

❌ Error 1: Intentar acceder por índice


const s = new Set([1, 2, 3]);
console.log(s[0]); // undefined ❌

✅ Solución:

Convierte a array primero:


const arr = [...s];
console.log(arr[0]); // 1 ✅

❌ Error 2: Esperar que el Set filtre objetos "iguales"


const s = new Set([
  { id: 1 },
  { id: 1 }
]);

console.log(s.size); // 2 (no 1)

⚠️ Razón:

Los objetos se comparan por referencia, no por contenido.

❌ Error 3: Usar .map() directamente


const s = new Set([1, 2, 3]);
s.map(x => x * 2); // ❌ TypeError

✅ Solución:


const doubled = new Set([...s].map(x => x * 2)); // ✅

15. Resumen Mental Final

Conceptos Clave

Set no es un Array mejorado
Set es una herramienta distinta para problemas distintos

  • Unicidad
  • Pertenencia (has)
  • Conjuntos (unión, intersección, diferencia)
