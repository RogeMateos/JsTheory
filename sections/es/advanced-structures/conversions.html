Conversión entre Estructuras en JavaScript

Arrays · Sets · Maps · Objects - Cómo y cuándo convertir entre ellas

1️⃣ ¿Por Qué Convertir Estructuras?

Porque no existe una estructura perfecta para todo.

👉 Cada estructura tiene ventajas distintas:

Arrays → ideales para:

  • map, filter, reduce
  • ordenar, recorrer, renderizar listas (React)

Sets → ideales para:

  • eliminar duplicados
  • operaciones de conjuntos

Maps → ideales para:

  • trabajar con pares clave → valor
  • búsquedas rápidas
  • mantener orden de inserción

Objects → ideales para:

  • datos de APIs (JSON)
  • modelos de datos simples
  • interoperabilidad con librerías

📌 En la práctica

Convertimos constantemente entre estas estructuras para aprovechar lo mejor de cada una.

2️⃣ Recordatorio Rápido: ¿Qué es un Map?

Un Map es una colección de pares clave → valor.


const userMap = new Map([
  ["name", "Mour"],
  ["age", 37]
]);

Características:

  • Las claves no tienen que ser strings
  • Mantiene el orden de inserción
  • Tiene métodos propios (set, get, has, size)

3️⃣ Map → Array

¿Por Qué Hacerlo?

Porque los Arrays tienen métodos muy potentes como map, filter, reduce, sort.

🔸 Forma 1: Array.from(map)


const userMap = new Map([
  ["name", "Mour"],
  ["age", 37]
]);

const arrayFromMap = Array.from(userMap);
console.log(arrayFromMap);
// [["name", "Mour"], ["age", 37]]

📌 Importante

Cada elemento del array es un par [clave, valor].

🔸 Forma 2: Spread Operator (muy común)


const arrayFromMap = [...userMap];

✔️ Ventajas del spread:

  • Hace exactamente lo mismo
  • Muy usado en JavaScript moderno

🔸 Acceder Solo a Claves o Valores


const keys = [...userMap.keys()];
console.log(keys);
// ["name", "age"]

const values = [...userMap.values()];
console.log(values);
// ["Mour", 37]

Esto es muy habitual en proyectos reales, sobre todo en UI.

4️⃣ Map → Object (objeto plano)

¿Por Qué Hacerlo?

Porque:

  • Las APIs trabajan con objetos
  • JSON solo admite objetos
  • Muchas librerías esperan objetos

🔸 Conversión con Object.fromEntries


const userMap = new Map([
  ["name", "Mour"],
  ["age", 37]
]);

const objectFromMap = Object.fromEntries(userMap);
console.log(objectFromMap);
// { name: "Mour", age: 37 }

📌 Funciona porque:

  • Map es iterable
  • Cada iteración devuelve [key, value]
  • Object.fromEntries espera exactamente eso

⚠️ Advertencia Importante (Nivel Senior)

Al convertir a Object:

  • Todas las claves se convierten en strings
  • Puedes perder información

const map = new Map();
map.set(1, "number");
map.set("1", "string");

const obj = Object.fromEntries(map);
console.log(obj);
// { "1": "string" }  ❌ se pisa

👉 No conviertas a Object si necesitas claves no-string.

5️⃣ Object → Map

¿Cuándo Tiene Sentido?

Cuando:

  • Quieres claves más flexibles
  • Necesitas size
  • Haces muchas inserciones/borrados
  • Te importa el orden de inserción

🔸 Conversión Paso a Paso


const userObject = {
  name: "Mour",
  age: 37
};

const mapFromObject = new Map(Object.entries(userObject));
console.log(mapFromObject);
// Map(2) { "name" => "Mour", "age" => 37 }

📌 Object.entries() devuelve:


[
  ["name", "Mour"],
  ["age", 37]
]

Justo lo que new Map() necesita.

6️⃣ Ejemplos Prácticos (Mundo Real)

🔹 Filtrar Datos de un Map


const users = new Map([
  [1, { name: "Ana", active: true }],
  [2, { name: "Luis", active: false }],
  [3, { name: "María", active: true }]
]);

const activeUsers = [...users.values()].filter(u => u.active);
console.log(activeUsers);
// [{ name: "Ana", active: true }, { name: "María", active: true }]

✔️ Proceso:

  • Convertimos a array solo de valores
  • Aplicamos filter

🔹 Preparar Datos para una UI (React)


const items = new Map([
  ["a1", { title: "Item 1" }],
  ["b2", { title: "Item 2" }]
]);

const list = [...items].map(([id, data]) => ({
  id,
  ...data
}));

console.log(list);
// [{ id: "a1", title: "Item 1" }, { id: "b2", title: "Item 2" }]

💡 Ideal para React:


list.map(item => <li key={item.id}>{item.title}</li>)

7️⃣ Relación con Sets y Arrays (Visión Global)

Array → Set → Eliminar Duplicados


const array = [1, 2, 2, 3, 4, 4, 5];
const unique = [...new Set(array)];
console.log(unique);
// [1, 2, 3, 4, 5]

Set → Array → Usar Métodos Avanzados


const set = new Set([1, 2, 3, 4, 5]);
const arr = [...set];

const doubled = arr.map(n => n * 2);
// [2, 4, 6, 8, 10]

Map ↔ Object → Modelo de Datos vs Colección


// Object → Map (para operaciones potentes)
const map = new Map(Object.entries(obj));

// Map → Object (para APIs/JSON)
const obj = Object.fromEntries(map);

Map → Array → Procesamiento y Transformaciones


const map = new Map([["a", 1], ["b", 2]]);
const processed = [...map].map(([key, value]) => value * 2);
// [2, 4]

👉 La Clave

Combinar estructuras, no elegir solo una.

8️⃣ Tabla de Conversiones Rápidas

9️⃣ Resumen Final (Muy Importante)

Conceptos Clave

Arrays

  • Procesamiento de datos
  • map, filter, reduce

Sets

  • Valores únicos
  • Operaciones de conjunto

Maps

  • Clave → valor potente
  • Claves no-string
  • Orden + rendimiento

Objects

  • Datos planos
  • APIs y JSON

🎯 Un buen desarrollador sabe cuándo convertir y por qué.
