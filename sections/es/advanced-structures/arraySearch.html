Operaciones de Búsqueda en Arrays en JavaScript

Introducción

Cuando trabajamos con arrays, una necesidad muy común es buscar elementos:

  • Saber si un valor existe
  • Encontrar el primer elemento que cumpla una condición
  • Obtener la posición (índice) de un elemento

Vamos a ver cómo hacerlo correctamente, por qué existen varios métodos y cuándo usar cada uno.

1️⃣ El Problema "A la Vieja Usanza"

Imagina este array:


const numbers = [1, 2, 3, 4, 6, 10];

Si queremos saber si existe el número 4, sin métodos especiales tendríamos que hacer algo así:


let exists = false;

for (let i = 0; i < numbers.length; i++) {
  if (numbers[i] === 4) {
    exists = true;
    break;
  }
}

👉 Funciona, pero:

  • Es verboso
  • Es fácil cometer errores
  • No es expresivo

Por eso JavaScript nos ofrece métodos de búsqueda.

2️⃣ includes() – ¿Existe Este Valor?

👉 Qué Hace

Comprueba si un array contiene exactamente un valor.

👉 Qué Devuelve

  • true → existe
  • false → no existe

👉 Ejemplo Básico


const numbers = [1, 2, 3, 4, 6, 10];

console.log(numbers.includes(4)); // true
console.log(numbers.includes(5)); // false

👉 Cuándo Usarlo

  • Cuando ya sabes el valor exacto
  • Validaciones simples
  • Comprobaciones rápidas

👉 Detalle Útil

Puedes indicar desde qué índice empezar a buscar:


numbers.includes(4, 4); // empieza desde el índice 4

3️⃣ some() – ¿Existe ALGO Que Cumpla una Condición?

Aquí está un método que muchos olvidan, pero es clave.

👉 Qué Hace

Comprueba si algún elemento cumple una condición.

👉 Qué Devuelve

true o false

👉 Ejemplo


const hasEven = numbers.some(n => n % 2 === 0);
console.log(hasEven); // true

👉 Cuándo Usarlo

  • Cuando necesitas boolean
  • Cuando la búsqueda depende de una condición
  • Es el equivalente lógico de includes, pero con condiciones

4️⃣ find() – Dame el PRIMER Elemento Que Cumpla

Ahora damos un paso más.

👉 Qué Hace

Recorre el array y devuelve el primer elemento que cumple una condición.

👉 Qué Devuelve

  • El elemento encontrado
  • undefined si no encuentra nada

👉 Ejemplo: Primer Número Par


const firstEven = numbers.find(n => n % 2 === 0);
console.log(firstEven); // 2

⚠️ Punto Clave (Muy Importante)

find() depende del orden actual del array.

Si cambiamos el orden:


const reversed = [...numbers].reverse();
console.log(reversed); // [10, 6, 4, 3, 2, 1]

const firstEven = reversed.find(n => n % 2 === 0);
console.log(firstEven); // 10

👉 "Primer" significa primer en ese orden, no el menor ni el original.

👉 Caso: No Encuentra Nada


const oddNumbers = [3, 7, 11];

const result = oddNumbers.find(n => n % 2 === 0);
console.log(result); // undefined

👉 Patrón Seguro


if (result === undefined) {
  console.log("No se encontró ningún elemento");
}

👉 Ejemplo Realista con Objetos


const users = [
  { id: 1, name: "Ana" },
  { id: 2, name: "Roge" },
];

const user = users.find(u => u.id === 2);
console.log(user); // { id: 2, name: "Roge" }

✅ Importante

find es perfecto cuando necesitas el elemento completo.

5️⃣ findIndex() – ¿En Qué Posición Está?

👉 Qué Hace

Funciona igual que find, pero devuelve el índice.

👉 Qué Devuelve

  • Un número ≥ 0 → índice encontrado
  • -1 → no encontrado

👉 Ejemplo


const firstEvenIndex = numbers.findIndex(n => n % 2 === 0);
console.log(firstEvenIndex); // 1

👉 Caso: No Encuentra Nada


const oddNumbers = [3, 7, 11];

console.log(
  oddNumbers.findIndex(n => n % 2 === 0)
); // -1

💡 Importante

findIndex siempre devuelve un número.

👉 Uso Típico: Modificar/Eliminar


const idx = numbers.findIndex(n => n === 4);

if (idx !== -1) {
  numbers.splice(idx, 1);
}

console.log(numbers); // [1, 2, 3, 6, 10]

6️⃣ Diferencias Claras (Regla Mental)

Necesidad Método
Saber si existe un valor exacto includes
Saber si algo cumple una condición some
Obtener el elemento find
Obtener la posición findIndex

7️⃣ ⚠️ Importante: Mutación y Orden del Array

Métodos que MODIFICAN el Array Original:

  • sort()
  • reverse()
  • splice()

Ejemplo Peligroso:


numbers.reverse(); // cambia el array original

👉 Esto afecta directamente a find y findIndex.

✅ Solución Segura:


const reversed = [...numbers].reverse();

8️⃣ Conclusión como Desarrollador Senior

Conceptos Clave

  • No hay un método "mejor", hay métodos correctos según el contexto
  • Usa:
    • includes para valores directos
    • some para booleanos con condición
    • find cuando necesitas el dato
    • findIndex cuando necesitas la posición
  • Ten siempre en cuenta el orden actual del array
  • Ojo con métodos que mutan
