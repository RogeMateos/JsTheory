flat() y flatMap() en JavaScript

Objetivo del Tema

Hoy vas a aprender dos métodos de arrays en JavaScript que se usan mucho cuando trabajas con datos reales (APIs, UI, listas, etc.):

  • flat(depth): aplana (reduce niveles) de un array anidado.
  • flatMap(fn): hace un map y luego aplana 1 nivel.

⚠️ Importante

Ninguno de los dos modifica el array original. Devuelven uno nuevo.

1) Contexto Práctico (Por Qué Esto Importa)

En proyectos reales, los datos suelen venir anidados:

  • Una API devuelve categorías con listas de productos
  • Un post tiene comentarios (lista) y cada comentario tiene respuestas (otra lista)
  • Agrupas elementos por secciones y luego necesitas una lista "plana" para renderizar o filtrar

Cuando eso pasa, necesitas "aplanar" para poder:

  • Recorrer todo con un solo .map() de UI
  • Hacer un search global
  • Calcular totales
  • Aplicar filtros sin hacer bucles anidados

2) flat() — Qué Hace Exactamente

2.1 Definición Simple

  • flat(depth) aplana un array hasta una profundidad depth
  • depth es opcional
  • Si no pones nada, el valor por defecto es 1
  • Devuelve un array nuevo

2.2 Ejemplo Base: Array Anidado


const nested = [1, [2, [3, [4]]]];

Caso A: flat() sin parámetro (depth = 1)


const flat1 = nested.flat();

console.log(flat1);  // [1, 2, [3, [4]]]
console.log(nested); // [1, [2, [3, [4]]]]  (no cambia)

✅ ¿Qué pasó?

Se eliminó solo el primer nivel de anidación.

2.3 Aplanar Más Niveles con depth


console.log(nested.flat(2)); // [1, 2, 3, [4]]
console.log(nested.flat(3)); // [1, 2, 3, 4]

✅ Idea Clave

depth es "cuántos niveles" quieres bajar.

2.4 Cuando No Sabes Cuántos Niveles Hay: Infinity


console.log(nested.flat(Infinity)); // [1, 2, 3, 4]

Útil si el array viene de fuera (API) y no controlas cuán profundo es.

3) flatMap() — Qué Es y Por Qué Existe

3.1 Definición Correcta (La Regla Mental)

flatMap equivale a:


array.flatMap(fn) = array.map(fn).flat(1)

O sea:

  1. Aplica una función a cada elemento (como map)
  2. El resultado lo aplana solo 1 nivel

4) Ejemplo Claro: De Frases → Palabras

4.1 Datos


const phrases = ["hola mundo", "adiós mundo"];

4.2 Con map (te queda anidado)


const mapped = phrases.map(p => p.split(" "));

console.log(mapped);
// [ ["hola", "mundo"], ["adiós", "mundo"] ]

✅ ¿Qué pasó?

  • split(" ") devuelve un array
  • Como lo haces con map, terminas con un array de arrays

4.3 Con flatMap (resultado plano)


const words = phrases.flatMap(p => p.split(" "));

console.log(words);
// ["hola", "mundo", "adiós", "mundo"]

✅ ¿Qué hizo flatMap?

  1. Primero generó: [["hola","mundo"],["adiós","mundo"]]
  2. Luego lo aplanó 1 nivel: ["hola","mundo","adiós","mundo"]

5) Caso Real de Trabajo (UI / API)

Imagina una API que te da categorías con items:


const categories = [
  { name: "Fruta", items: ["manzana", "pera"] },
  { name: "Bebida", items: ["agua"] }
];

Si quieres renderizar todos los items en una lista única:


const allItems = categories.flatMap(c => c.items);
console.log(allItems); // ["manzana", "pera", "agua"]

📌 Esto es típico para:

  • Una lista global en UI
  • Un buscador
  • Un selector (dropdown)
  • Analytics ("cuántos items hay en total")

6) Advertencias Importantes (Errores Típicos)

6.1 flatMap Solo Aplana 1 Nivel

Si devuelves algo con más profundidad, no lo deja totalmente plano:


const arr = [1, 2];

const result = arr.flatMap(x => [x, [x]]);
console.log(result);
// [1, [1], 2, [2]]

Si de verdad quieres plano completo:


const fully = arr.flatMap(x => [x, [x]]).flat();
console.log(fully);
// [1, 1, 2, 2]

6.2 No Mutan el Original (Muy Importante)


const original = [1, [2]];
const copy = original.flat();

console.log(original); // [1, [2]]
console.log(copy);     // [1, 2]

⚠️ Importante

Ambos métodos devuelven un nuevo array sin modificar el original.

7) Cuándo Usar Cada Uno (Regla Rápida)

  • Solo quieres aplanar → flat(depth)
  • Quieres transformar y aplanar 1 nivel → flatMap(fn)
  • No sabes la profundidad → flat(Infinity)

8) Mini-Ejercicios (Para Fijar)

Ejercicio 1


const a = [1, [2, [3]]];
// Haz que salga: [1, 2, 3]

✅ Solución

a.flat(2);

Ejercicio 2


const names = ["Ana López", "Juan Pérez"];
// Quiero: ["Ana", "López", "Juan", "Pérez"]

✅ Solución

names.flatMap(n => n.split(" "));

9) Resumen Final

Conceptos Clave

  • flat(depth) aplana arrays anidados (depth por defecto = 1)
  • flatMap(fn) es como map(fn) + flat(1)
  • Ambos devuelven un array nuevo: no mutan el original
  • Muy útiles para transformar datos de APIs y renderizar listas en UI
