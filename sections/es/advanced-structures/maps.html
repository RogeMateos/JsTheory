Maps en JavaScript: Diccionarios Clave → Valor

Comparativa con Arrays y Sets, operaciones básicas e iteración

1️⃣ ¿Qué es un Map en JavaScript?

Un Map es una colección de pares clave → valor.

👉 Características principales:

  • Las claves pueden ser de cualquier tipo (strings, números, objetos, funciones)
  • Mantiene el orden de inserción
  • Tiene métodos explícitos: get, set, has, delete
  • Conoce su tamaño con .size

const myMap = new Map([
  ["name", "moure"],
  ["age", 37]
]);

console.log(myMap);
// Map { 'name' => 'moure', 'age' => 37 }

2️⃣ Array vs Set vs Map (Diferencias Clave)

Estructura Repetidos Clave-valor Uso principal
Array ✅ ❌ Listas, transformaciones
Set ❌ ❌ Valores únicos
Map ❌ ✅ Diccionarios, lookup

👉 Regla Mental

  • Array → listas y transformaciones
  • Set → unicidad
  • Map → relaciones clave → valor

3️⃣ Crear un Map

Estructura de Creación

Un Map se crea pasando un array de pares [clave, valor]:


const myMap = new Map([
  ["name", "moure"],
  ["age", 37],
  ["country", "ES"]
]);

📌 Formato:

  • [ … ] de fuera = array de elementos
  • Cada elemento es otro array de 2 posiciones: [key, value]

Map Vacío


const emptyMap = new Map();

4️⃣ Operaciones Básicas de Map

set() - Añadir o Actualizar


const myMap = new Map();

myMap.set("name", "moure");
myMap.set("age", 37);
myMap.set("country", "ES");

console.log(myMap);
// Map { 'name' => 'moure', 'age' => 37, 'country' => 'ES' }

get() - Obtener Valor


console.log(myMap.get("name")); // "moure"
console.log(myMap.get("age"));  // 37

has() - Verificar Existencia


console.log(myMap.has("age"));     // true
console.log(myMap.has("city"));    // false

delete() - Eliminar


myMap.delete("age");
console.log(myMap.has("age")); // false

size - Tamaño


console.log(myMap.size); // 2

clear() - Vaciar


myMap.clear();
console.log(myMap.size); // 0

5️⃣ Iteración con forEach (⚠️ MUY IMPORTANTE)

⚠️ Orden de Parámetros

En Map.forEach, el callback recibe primero el value y luego el key:


myMap.forEach((value, key) => {
  console.log(`${key}: ${value}`);
});

Esto es al revés de lo que muchos esperan.

Ejemplo Completo


const myMap = new Map([
  ["name", "moure"],
  ["age", 37],
  ["country", "ES"]
]);

myMap.forEach((value, key) => {
  console.log(`${key}: ${value}`);
});

// name: moure
// age: 37
// country: ES

6️⃣ Iteración con for...of (Muy Recomendada)

Iteración Simple


for (const [key, value] of myMap) {
  console.log(key, value);
}

// name moure
// age 37
// country ES

💡 Ventaja

Aquí usamos destructuring [key, value], muy común en JS moderno.

Iteración Explícita con .entries()


for (const [key, value] of myMap.entries()) {
  console.log(key, value);
}

Solo las Claves


for (const key of myMap.keys()) {
  console.log(key);
}

Solo los Valores


for (const value of myMap.values()) {
  console.log(value);
}

7️⃣ Map vs Object (Cuándo Usar Cada Uno)

✔ Usa Object cuando:

  • Tus claves son strings simples
  • Quieres JSON fácil
  • Necesitas algo rápido y simple

✔ Usa Map cuando:

  • Necesitas claves que NO sean strings (objetos, funciones)
  • Quieres saber el tamaño con .size
  • Vas a añadir/eliminar mucho
  • Te importa el orden de inserción de forma explícita

8️⃣ Ejemplo Real: Cache por Objeto

Problema con Object

Con objetos, las claves se convierten a string:


const cache = {};
const obj1 = { id: 1 };
const obj2 = { id: 2 };

cache[obj1] = "valor1";
cache[obj2] = "valor2";

console.log(cache);
// { '[object Object]': 'valor2' }
// ❌ Ambos objetos tienen la misma clave

Solución con Map


const cache = new Map();
const obj1 = { id: 1 };
const obj2 = { id: 2 };

cache.set(obj1, "valor1");
cache.set(obj2, "valor2");

console.log(cache.get(obj1)); // "valor1"
console.log(cache.get(obj2)); // "valor2"
// ✅ Cada objeto mantiene su propia clave

📌 Por Qué Funciona

Map puede usar objetos como claves porque no los convierte a string.

9️⃣ Ejemplo Real: Mapear ID → Usuario


const users = [
  { id: 1, name: "Ana" },
  { id: 2, name: "Luis" },
  { id: 3, name: "María" }
];

// Crear Map id → usuario
const userMap = new Map();

users.forEach(user => {
  userMap.set(user.id, user);
});

// Acceso rápido por ID
console.log(userMap.get(2));
// { id: 2, name: "Luis" }

💡 Ventaja

Búsqueda O(1) en lugar de O(n) con array.find()

🔟 Ejemplo Real: Contar Repeticiones

Usa un Map para contar cuántas veces aparece cada palabra:


const words = ["hola", "mundo", "hola", "javascript", "mundo", "hola"];

const wordCount = new Map();

words.forEach(word => {
  if (wordCount.has(word)) {
    wordCount.set(word, wordCount.get(word) + 1);
  } else {
    wordCount.set(word, 1);
  }
});

console.log(wordCount);
// Map { 'hola' => 3, 'mundo' => 2, 'javascript' => 1 }

Versión Más Elegante


words.forEach(word => {
  wordCount.set(word, (wordCount.get(word) || 0) + 1);
});

1️⃣1️⃣ Convertir Map a Array y Viceversa

Map → Array


const myMap = new Map([
  ["name", "moure"],
  ["age", 37]
]);

// Convertir a array de pares
const entries = [...myMap];
console.log(entries);
// [['name', 'moure'], ['age', 37]]

// O usando Array.from
const entries2 = Array.from(myMap);

Array → Map


const arr = [
  ["name", "moure"],
  ["age", 37]
];

const myMap = new Map(arr);

Conceptos Clave
