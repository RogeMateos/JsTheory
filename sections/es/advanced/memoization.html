Memoization

¿Qué es?

Técnica de optimización: guarda en caché resultados de llamadas costosas para no recalcular cuando los argumentos se repiten.

Ejemplo: función memoizada


    function memoizedAdd() {
      let cache = {};

      return function(num) {
        if (num in cache) {
          console.log('Fetching from cache:', num);
          return cache[num];
        } else {
          console.log('Calculating result:', num);
          let result = num + 10; // aquí iría el cálculo costoso
          cache[num] = result;
          return result;
        }
      };
    }

    const add = memoizedAdd();
    console.log(add(5)); // Calculating result: 15
    console.log(add(5)); // Fetching from cache: 15
    console.log(add(6)); // Calculating result: 16

La segunda llamada con 5 usa cache; con 6 recalcula y guarda.
