Precedencia y asociatividad de operadores

Precedencia

Define el orden de evaluación. Operadores con mayor precedencia se calculan antes (ej. * antes que +).


      let result = 3 + 4 * 5;
      console.log(result); // Output: 23

Primero 4 * 5 = 20; luego 3 + 20 = 23.


      result = (3 + 4) * 5;
      console.log(result); // Output: 35
  • Paréntesis fuerzan primero la suma (3 + 4 = 7).
  • Luego se multiplica: 7 * 5 = 35.

Asociatividad

Dirección de evaluación cuando tienen la misma precedencia: izquierda a derecha o derecha a izquierda.


      let a, b, c;
      a = 2;
      b = 3;
      c = 4;

      a = b = c;
      console.log(a); // Output: 4
      console.log(b); // Output: 4
      console.log(c); // Output: 4

Explicación

  • Asignación es derecha a izquierda: primero b = c (b vale 4).
  • Luego a = b (a vale 4).
  • Las tres variables terminan con 4.

Resumen

  • Precedencia: orden entre operadores distintos.
  • Asociatividad: orden cuando comparten precedencia.
  • Usa paréntesis para dejar claro el orden.
