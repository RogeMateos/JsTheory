Asincronía, callbacks, promesas y async/await

Asincronía en JS

JS es single-thread y por defecto síncrono, pero usa Web APIs + event loop para tareas que toman tiempo (peticiones, timers, I/O).

🍕 Analogía del restaurante

Síncrono: el mesero espera en cocina antes de atender al siguiente.

Asíncrono: toma pedidos y cocina en paralelo; trae cada plato cuando esté listo.

Callbacks

Función que se pasa como argumento y se ejecuta al terminar la operación.


function fetchUserData(userId, callback) {
  setTimeout(() => {
    if (userId > 0) {
      callback(null, { id: userId, name: 'John' });
    } else {
      callback(new Error('ID inválido'));
    }
  }, 1000);
}

fetchUserData(123, (err, user) => {
  if (err) return console.error(err.message);
  console.log('User data:', user);
});

console.log('Se ejecuta primero');

Problemas

  • Callback hell: anidación difícil de leer
  • Errores dispersos: manejar error en cada callback
  • Inversión de control: la lógica queda dentro de callbacks

Promesas

Representan un resultado futuro (éxito o fallo).

Pendiente
Resuelta
Rechazada

🎁 Analogía de envío

Pendiente: pedido en proceso; Resuelta: paquete llega; Rechazada: sin stock.


const myPromise = new Promise((resolve, reject) => {
  const ok = true;
  ok ? resolve('Listo') : reject('Fallo');
});

myPromise
  .then(res => console.log(res))
  .catch(err => console.error(err));

Encadenar


fetch('/api')
  .then(r => r.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

Async / Await

Azúcar sintáctica sobre promesas para escribir como si fuera código síncrono.

  • async hace que la función retorne una promesa.
  • await espera a que la promesa se resuelva/rechace sin bloquear el hilo.

function addToArray(data, array) {
  return new Promise((resolve, reject) => {
    if (!array) return reject(new Error("Array no existe"));
    setTimeout(() => {
      array.push(data);
      resolve(array);
    }, 500);
  });
}

async function processData(data, array) {
  try {
    const result = await addToArray(data, array);
    console.log("Array:", result);
  } catch (error) {
    console.error(error.message);
  }
}

Paralelo con Promise.all


async function loadAll(userId) {
  const [user, posts, friends] = await Promise.all([
    fetchUser(userId),
    fetchPosts(userId),
    fetchFriends(userId)
  ]);
  return { user, posts, friends };
}
